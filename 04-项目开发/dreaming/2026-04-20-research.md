# BrickHub 每日报告 — 2026-04-20

## 今日质检（审查文件：lib/llmPrompt.js, 898 LOC + 全项目 npm test）

### 🚨 头条发现：`buildSystemPrompt()` 模板字面量未正确闭合 — LLM 收到 18.8KB 污染 prompt

**现象**：`node -e` 调用 `buildSystemPrompt()`，返回字符串长度 **18,873 字符**（预期约 3.6KB）。
**根因**：`lib/llmPrompt.js:123` 的本意关闭符 `` `; `` 被写成 `` \`; ``（反引号被反斜杠转义成了字面字符），导致从第 11 行开始的模板字面量一直延伸到第 399 行才真正闭合。

后果：调用方（`lib/pipeline/index.js:100`）在 DSL 回退路径下拿到的 system prompt 里混入了本该是 JS 源码/文档的内容：
- 一个字面的 `` `; `` 和孤立的 `}` 字符
- 整个 `## VERIFIED EXAMPLE`、`## FORBIDDEN`、minifigure 表、`REFERENCE 1-4` 小节
- **89 行原始 LDraw 文本**（以 `1 <color>` 开头）

这与同一 prompt 内的核心指令直接冲突：
> "DO NOT output raw LDraw text lines. Use the DSL JSON format ONLY."

prompt 既要求 JSON DSL 又示范了 89 行裸 LDraw，回退路径的成功率和 token 成本都会受损。DSL 路径（`buildDSLSystemPrompt`）正常。
