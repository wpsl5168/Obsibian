### ⚠️ 待老王 review 的 P1 (4 项)

1. **dslWarnings 仅计数不外传** (line 117/121-124): warning 文本 silent-discard,只发数字。dslCompiler hardcoded fallback warning(如"形状被忽略,固定输出圆形")用户和监控完全看不到,产品决策错失。建议: 文本前 N 条传 hooks.onEvent + 关键 warning push noteFailureReason。
2. **extractLDraw 空字符串无 guard** (line 150-151): useDSLPath=false 路径下,LLM 输出垃圾文本无 type-0/1 行 → extractLDraw 返回空 → 通过 parseLDraw(空 errors) → telemetry 记 ldrawFallbackSuccesses=成功,**实际返回空 LDraw,前端渲染 0 块**。建议: 加 `if (!ldrawCode.trim()) retry/fallback`。
3. **previousValidationSignature 粒度过粗** (line 170-172): signature 用错误类型计数对比 `{matrix:3, part:2}`,两次 retry 错误类型分布相同但**具体行不同**(LLM 输出了新零件错误)就被误判 stalled,放弃可修好的 retry。建议: signature 加 `line` hash 或 N 次完全无改善才 stall。
4. **failureReasons 字典污染** (line 206-208 vs 179/217): 同一 dict 既存"按 error 条数累计"(matrix/format/part)又存"按请求次数累计"(upstream_error/dsl_compile_failed),分析时无法区分。建议: 拆 `errorTypeBreakdown` vs `requestFailureReasons`。

## 技术发现

- **next 2026-05 安全公告链路**: Vercel + Netlify 都强烈推 15.5.18/16.2.6,Netlify 明确"14.x 全版本受影响、无 WAF mitigation"。BrickHub 部署在 Vercel,**升级是不可推迟项**。
- **React Server Components CVE-2026-23870 (DoS)**: 影响 react 19.x,但 16.x Next.js App Router 间接受影响。BrickHub 用 Pages Router(`pages/`)+ React 18.3,**不直接命中**,但升 next 到 15.5.18 时建议 react 同升到 18.3.x 最新。
- **r3f v8 → v9 迁移核心 breaking**: `<orbitControls>` 用 `extend({OrbitControls})` 显式注册而非自动注入;`useThree` 部分字段重命名。BrickHub 用 OrbitControls(参考 `pages/sandbox.js`),升级前必跑 v9 migration guide。
