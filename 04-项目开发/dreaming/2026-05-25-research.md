### 🔥 重点：Next.js 安全升级建议

**受影响的具体威胁**（BrickHub 用 Pages Router）：
- High: Pages Router i18n default-locale 路径绕过 proxy 授权
- High: 动态路由参数注入绕过授权
- Moderate: Image Optimization API DoS（BrickHub 大量用 `next/image` 渲染缩略图）
- 其他：RSC DoS、SSRF via WebSocket、XSS via CSP nonce

**升级路径**（联动栈，要一起升）：
- **路径 A（保守）**：`next@15.5.18` + `react@19.x` — 留在 Pages Router，R3F v8 维持，破坏面较小，**强烈推荐先走这条**
- **路径 B（激进）**：`next@16.2.6` + `react@19.x` + R3F v9 + 调整 drei — 需大量 migration test
