## 1. 目前组件分工与模块梳理

BrickHub 项目目前的核心架构主要分为以下几个层次，旨在实现从自然语言到高质量 3D 乐高模型的生成与展示：

### 1.1 渲染引擎层
* **核心组件:** `components/BrickRenderer.js`
* **技术栈:** Three.js / WebGL
* **功能描述:**
  负责 LDraw 模型的解析与高保真 3D 渲染。目标是向 Mecabricks 的行业标准靠拢。
  目前已实现/修复的功能包括：
  * 正确处理积木块的旋转矩阵。
  * 动态加载外部扩展零件库，确保生成模型所需零件的可用性。

### 1.2 大模型接入与生成层
* **核心组件:** `pages/api/generate.js` 与 `lib/llmPrompt.js`
* **技术栈:** Claude 等主流 LLM API
* **功能描述:**
  负责将用户的自然语言描述转化为规范的 LDraw 代码。为了保证生成质量和可用性，采用了严苛的 Prompt 工程策略：
  * **组件库白名单:** 限制模型仅使用已支持和验证的乐高零件。
  * **强制思维链 (Chain of Thought):** 引导模型按步骤思考结构拼搭逻辑，提高生成合理性。
  * **物理与结构约束:** 引入防悬空机制，并特别强调反转 Y 轴约束（适应 LDraw 坐标系特性）。

### 1.3 质量与自动化测试层
* **核心组件:** `__tests__/` 目录下的测试套件
* **功能描述:**
  作为模型生成的最后一道防线，提供自动化的物理与结构验证机制。
  * **穿模检测:** 拦截零件之间的不合理空间重叠。
  * **坐标校验:** 识别并拒绝包含错误坐标或离谱尺寸的 LDraw 代码输出，确保生成结果的可拼搭性。

## 2. 演进路线图 (Roadmap) 细化

为了实现 BrickHub 的最终愿景，我们将项目发展划分为 4 个清晰的演进阶段：

### 阶段一：AI文本到积木基础生成 (当前目标)
1. **阶段目标**：实现从自然语言描述到单体积木模型（LDraw 格式）的稳定生成和网页端基础展示，确保结构合理无硬伤。
2. **验证标准**：Prompt 生成的 LDraw 代码通过自动化测试（无穿模、无悬空），能在 WebGL 中正确解析并渲染积木形状。
3. **所需资源**：LLM API (Claude/GPT-4)、Three.js / WebGL 基础渲染框架、LDraw 零件库白名单。
4. **行业对标**：基础 **LDraw Viewer** (重在准确解析和展示基本几何体)。

### 阶段二：专业级渲染与物理拼搭 (中期目标一)
1. **阶段目标**：大幅提升渲染画质，达到照片级真实感；引入物理引擎实现真实的碰撞检测、重力模拟和结构稳定性校验。
2. **验证标准**：渲染效果支持高光、材质细节；模型能够通过重力测试不散架；支持基础的鼠标交互拖拽拼搭验证。
3. **所需资源**：高级 WebGL 渲染技术 (PBR 材质、光线追踪)、WebAssembly 物理引擎 (如 Cannon.js/Ammo.js)、算力升级（用于复杂渲染）。
4. **行业对标**：**Mecabricks**（PBR 物理渲染、高光材质、指纹划痕细节）和 **BrickLink Studio**（专业级拼搭与结构验证）。

### 阶段三：动态步骤与图纸导出 (中期目标二)
1. **阶段目标**：自动将生成的完整模型拆解为符合人类直觉的按步骤拼搭说明，并支持一键导出标准图纸 (PDF/Web 交互版)。
2. **验证标准**：生成的图纸步骤逻辑清晰，无遮挡死角，能够指导真实物理积木的拼搭全过程。
3. **所需资源**：自动分步图纸算法 (拓扑排序与可见性分析)、PDF 生成库、交互式步骤展示 UI。
4. **行业对标**：**LEGO 官方 Builder App**（3D 交互式拼搭指引）和 **LPub3D**（自动分步图纸算法及排版）。

### 阶段四：UGC 与开源积木社区 (长期愿景)
1. **阶段目标**：构建一个玩家可以自由探索、分享、评价和二次创作的在线互动社区，形成 BrickHub 生态闭环。
2. **验证标准**：用户可以发布作品、进行点赞评论；支持一件作品的 Fork 修改；提供个人零件库管理与套内 MOC 推荐。
3. **所需资源**：全栈社区系统 (用户账户、动态流、评论系统)、零件库存匹配算法、云存储服务。
4. **行业对标**：**Rebrickable**（套内 MOC 匹配、个人零件清单比对）和 **LEGO Ideas**（玩家投票、二次创作 Fork 与社区化孵化）。
