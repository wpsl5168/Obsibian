## 关键新发现

1. **MCP 正在成为 Agent 工具调用的事实标准** — 协议层面的统一使得 Agent 不再绑定特定工具实现，竞争焦点正从"能不能调工具"转向"权限治理/审计/安全"
2. **Evals-Driven 开发是 AI 工程成熟度的分水岭** — 没有系统化评测的 Agent 项目本质上是在"凭感觉调参"，Evals 应该像单元测试一样成为开发标配
3. **记忆机制是 Agent 从 demo 到生产的关键瓶颈** — 短期记忆靠上下文窗口，长期记忆靠向量检索+摘要压缩，但两者的融合策略仍在快速演进中
4. **Human-in-the-loop 不是退步，是生产化的必要条件** — 置信度阈值触发的人机交接机制，是当前 Agent 安全落地的最佳实践
5. **SWE-Agent 正在验证"AI 写代码 + AI 测代码"的闭环可行性** — SWE-bench 上的持续进步表明，端到端自动化软件开发已经从学术研究走向工程可用
