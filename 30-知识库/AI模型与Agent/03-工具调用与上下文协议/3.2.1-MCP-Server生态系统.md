# MCP Server 生态系统

> 📚 上级页面：[[3.2-Model_Context_Protocol规范解析]]

## MCP Server 生态系统（2025-2026 年）

截至 2026 年初，MCP 生态已爆发式增长，社区已有 **1000+** MCP Server 实现。

### 官方与社区 Server

| 分类 | 代表性 Server | 说明 |
| :--- | :--- | :--- |
| 文件系统 | `@modelcontextprotocol/server-filesystem` | 安全的文件读写访问 |
| 数据库 | `@modelcontextprotocol/server-postgres`、`mcp-server-sqlserver` [待验证] | 数据库查询与管理 |
| Git/GitHub | `@modelcontextprotocol/server-github` | 仓库管理、PR 操作 |
| 浏览器 | `@anthropic/mcp-server-puppeteer`、Playwright MCP | 网页自动化 |
| 搜索 | Brave Search、Exa Search Server | 网络搜索能力 |
| 知识管理 | Notion、Obsidian MCP Server | 笔记和知识库访问 |
| 云服务 | AWS、GCP、Azure MCP Servers | 云资源管理 |
| 监控 | Sentry MCP Server | 错误跟踪与诊断 |
| 通信 | mcp-server-slack、mcp-server-email | 发消息、读邮件 |

### 配置示例（Claude Desktop）

```json
{
  "mcpServers": {
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "/path/to/db.sqlite"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx"
      }
    }
  }
}
```

> [!tip] .NET 类比
> 这就是 `appsettings.json` 里的连接字符串配置——每个 Server 对应一个 ConnectionString。
