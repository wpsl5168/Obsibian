# Voicebox

## 一句话
本地优先的开源 AI 语音工作室,**对标 ElevenLabs + WisprFlow**,基于 Qwen3-TTS,MIT 许可。

## 解决什么问题
- ElevenLabs:每月几十刀 + 必须上传音频到他们服务器(隐私)
- WisprFlow:听写好用但要付费 + 同样隐私顾虑
- Voicebox:全本地跑,零上传,免费

## 核心能力
- 🎙️ **语音克隆**:克隆任意人声
- 🗣️ **多语种 TTS**:7 种语言生成
- ⌨️ **听写**:Whisper-Turbo,替代 WisprFlow
- 🤖 **Agent 语音输出**:MCP 工具 `voicebox.speak`,Claude Code / Cursor / Cline 一行调用,用你克隆的声音说话(如"Deploy complete")

## API 示例
```bash
# 生成语音
curl -X POST localhost:xxxx/speak \
  -d '{"text":"Hello","profile_id":"abc123","language":"en"}'

# 转写音频
curl -X POST localhost:xxxx/transcribe \
  -F "audio=@recording.wav" -F "model=whisper-turbo"
```

## 关联本地项目
- **HermesPet 桌宠**:可考虑接入做 Live2D 语音输出(本地跑无延迟,隐私 ✓)
- **Hermes Agent TTS provider**:现有 edge/openai/xAI/MiniMax/ElevenLabs,可加 voicebox 作为本地选项
- **MCP 集成**:Hermes 原生支持 MCP,理论上 `voicebox.speak` 可直接挂载
