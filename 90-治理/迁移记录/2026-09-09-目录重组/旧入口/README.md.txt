# 老王的 Obsidian 知识库

> 本地优先的个人知识管理系统，采用 PARA 风格目录结构（编号制）。

## 顶级目录

| 目录 | 用途 |
|------|------|
| `00-收件箱/` | 临时草稿、待整理素材，定期清空到知识库或归档 |
| `10-知识库/` | 长期保留的结构化知识（AI/Agent、方法论、工具速查） |
| `20-项目/` | 正在进行的项目工作笔记（BrickHub / Hermes / 海马体 / Dreaming） |
| `40-调研报告/` | 深度调研、对比分析、决策报告 |
| `50-日报与动态/` | 每日动态、周报、外部内容订阅（DeepLearning.AI 课程跟踪、AI 日报） |
| `90-治理/` | 元规范：[[90-治理/写作规范.md]]、周报模板、迁移记录 |
| `assets/` | 图片、附件等二进制资源 |
| `.trash/` | 软删除区，定期清理 |

## 命名规范

- **顶级目录**：两位编号前缀 + 中文名（10/20/30/40/90 留出扩展空间）
- **子目录**：直接用中文/项目名，不带编号
- **笔记文件**：日期前缀（`2026-04-20-xxx.md`）或主题名，遵循 [[90-治理/写作规范.md]]

## 维护原则

1. 收件箱不过夜：每日整理到对应位置
2. 项目完结后归档到 `10-知识库/旧笔记归档/`
3. 调研报告完成后只读，不再修改
4. 重大重构操作前先 git commit
