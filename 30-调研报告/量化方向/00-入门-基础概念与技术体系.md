# A股量化交易：基础概念与核心技术体系

> 入库调研笔记 · 面向已熟悉 LLM/AI、初入量化的读者。
> 每个概念给出 **定义 + A股适用性说明**。术语保留英文。

## 一、量化交易：定义、与主观的区别、A股市场特殊性

### 1.1 什么是量化交易
**定义**：以**数学模型 + 数据 + 程序**代替人对单只标的的主观判断，做出"买什么、买多少、何时买、如何执行"的决策。

关键边界澄清（业内常混淆）：
- **量化投资 (Quantitative Investing)**：决策由模型产生，可能仍由人下单或半自动执行。
- **程序化交易 (Algorithmic / Program Trading)**：交易**指令的下达**由程序完成，不一定来自量化模型；做主观的人也可以用 VWAP 算法拆单。
- 两者交集大但不等价。监管语境中的"程序化交易"通常指**下单方式**而非**决策来源**。

### 1.2 与主观交易的核心区别

| 维度 | 主观 (Discretionary) | 量化 (Quantitative) |
|---|---|---|
| 决策依据 | 基本面研究、调研、经验直觉 | 历史数据回测出的统计规律 |
| 覆盖广度 | 几只到几十只深度研究 | 全市场 5000+ 股票同时打分 |
| 持仓集中度 | 集中（前十大 50%+ 常见） | 分散（几百到上千只） |
| 单票研究深度 | 高 | 低，依赖**统计显著性而非个股逻辑** |
| 换手率 | 通常低 | 中高频策略可达数十倍/年 |
| 容量上限 | 高（巴菲特型） | 受流动性约束明显，规模到一定程度 alpha 衰减 |
| 失败模式 | 个股黑天鹅、人性 | 模型失效、过拟合、拥挤交易 |

### 1.3 A股市场结构的四大特殊性（必须刻进策略里）

1. **T+1 交收**：今日买入次日才可卖。
   - 影响：**日内反转、做市策略受限**；只有融券或自有底仓才能做日内 T0。
   - 量化对策：底仓 + 融券双向 T0（监管已收紧，下方详述）。

2. **涨跌停板** ±10%（主板）/ ±20%（科创板、创业板）/ ±30%（北交所，上市首日不限）/ ST 股 ±5%。
   - 影响：涨停时**有价无市**，订单簿断裂，回测必须模拟"涨停打不进、跌停卖不出"。
   - 量化对策：撮合模拟时把涨跌停状态作为不可成交标记；信号触发涨停的票不计入实盘业绩。

3. **印花税**（单边，**卖出方**缴纳）：2023-08-28 起减半为 **0.5‰**（即 0.05%）。
   - 加上佣金 ~0.2‰‒0.3‰、过户费 0.01‰，单边卖出成本 ~0.7‰，**双边往返约 1‰**。
   - 影响：**直接吃掉高频策略的 alpha**。换手 20 倍/年的策略，仅税费就拖累约 20% 收益。
   - 与美股区别：美股无印花税，所以高频做市在 A 股经济性差很多。

4. **融券难 / 做空难**：
   - 个股层面券源稀缺、利率高（年化常 8‒15%+），且**T+1 还券**、限售股出借已被叫停（2024年初）。
   - 股指期货层面：IF/IH/IC/IM 四大合约可对冲，但常年**贴水**（年化 5‒15%），对冲成本不低。
   - 影响：**纯多空中性策略在 A 股极难做**，主流是"指数增强"（多头 + 股指期货空头），称作"中性策略"。
   - 2024 年初小微盘流动性危机：DMA、雪球、量化中性集中踩踏，融券限制是导火索之一。

## 二、主流策略类型

### 2.1 多因子选股 (Multi-Factor Stock Selection)
**核心思想**：股票收益可由若干"因子"暴露解释，找到对未来收益有预测力的因子组合，按因子分加权选股。

两大学术源头：
- **Fama-French 三/五因子**：MKT(市场)、SMB(小市值)、HML(价值)、RMW(盈利)、CMA(投资) ——学术界解释**截面收益**的基础模型。
- **Barra (MSCI) 风险模型**：MSCI 商用模型，**CNE5/CNE6** 是其 A 股版本。CNE5 含 10 个一级风格因子：Size、Beta、Momentum、Residual Volatility、Non-linear Size、Book-to-Price、Liquidity、Earnings Yield、Growth、Leverage，加约 30 个行业因子。**Barra 主要用于风险归因和组合优化的约束**（控制风格暴露），而非直接选股。

实践分类：
- **基本面因子**：估值（PE/PB/PS）、成长（营收/净利同比）、质量（ROE/ROA）、分红率。
- **量价因子**：动量、反转、波动率、换手率、资金流。**A股反转 > 动量**（与美股相反，散户主导市场过度反应）。
- **另类因子**：分析师一致预期、北向资金、龙虎榜、舆情、卫星图像。

A股适用性：多因子是国内公私募最主流的框架。但 2017 年后**传统价值/成长因子衰减**严重，业内转向**高频量价 + 机器学习挖因子**。

### 2.2 统计套利 (Statistical Arbitrage, StatArb)
**定义**：寻找价格存在统计意义上稳定关系的标的，价差偏离时做多/空两端，回归时获利。
- 经典形式：**配对交易 (Pairs Trading)**，如两只同行业股票协整。
- 进阶：篮子套利、ETF 与成份股套利、可转债与正股套利。

A股适用性：单股配对受 T+1 和融券约束，难做。**ETF 套利**（折溢价、跨市场）和**可转债套利**是 A 股做得多的方向。

### 2.3 CTA (Commodity Trading Advisor)
商品/金融期货策略，分两类：
- **趋势 (Trend Following)**：跟随均线/突破方向，"截断亏损让利润奔跑"，海外文艺复兴前身、AHL、Winton 都做这个。
- **套利 (Arbitrage)**：跨期、跨品种、跨市场。

A股适用性：A股 CTA 主战场是**中金所股指期货 + 上期所/大商所/郑商所商品期货**。商品期货 **T+0、双向、保证金 ~10%**，是 A 股环境里少见的"美式"市场，量化生态成熟。

### 2.4 高频做市 (HFT Market Making)
**定义**：同时挂买卖双边报价，赚买卖价差（bid-ask spread）和交易所返佣。
A股适用性：A股**没有做市商返佣机制**（科创板少数试点），加上 T+1、印花税，**纯做市极难盈利**。所谓"国内高频"实际多是**高频统计套利 + 高频日内 T0**，频率在秒到分钟级，不是美股微秒级 HFT。

### 2.5 事件驱动 (Event-Driven)
围绕特定事件构建策略：定增、并购重组、ST 摘帽、指数调样、解禁、分红除权、业绩超预期(PEAD)。
A股适用性：**指数调样**（沪深300/中证500/中证1000 半年度调样）是国内做得最成熟的事件策略之一。**业绩公告漂移 (PEAD)** 在 A 股长期有效但已显著衰减。

### 2.6 机器学习选股 (ML / DL based)
- **传统 ML**：LightGBM/XGBoost 做横截面收益预测，输入是因子矩阵；广发金工、华泰金工大量研报。
- **深度学习**：
  - 截面：MLP、AutoEncoder。
  - 时序：LSTM/GRU/TCN 处理量价序列。
  - 图：GAT/HGAT 建模股票关联。
  - 微软 **Qlib** 框架是入门首选，含 Alpha158/Alpha360、TabNet、ALSTM、HIST 等基线。
- **Transformer / 大模型**：近两年券商研报开始尝试，但**金融数据低信噪比 + 非平稳**使得大模型相对优势不如 NLP/CV 明显。

A股适用性：机器学习选股已是头部量化（九坤、明汯、幻方、衍复、灵均等）的标配。**量价 + ML 的有效性远高于美股**，被认为是 A 股散户结构带来的红利。

## 三、技术栈分层

### 3.1 数据层
- **行情数据**：
  - **日频**：开高低收量、复权因子（前复权/后复权处理分红送股）。
  - **分钟/Tick/Level-2**：L2 含十档买卖盘、逐笔成交、委托队列；机构标配。
  - 主要供应商：Wind、聚源、迅投、恒生、Tushare(免费/付费)、Choice、米筐 RQData。
- **基本面 / 财务**：利润表、资产负债表、现金流量表、分红、股本变动。注意**财报披露滞后**（一般滞后 1-3 个月），回测时要用 **PIT (Point-In-Time)** 数据避免未来函数。
- **另类数据 (Alternative Data)**：
  - 资金流：北向、龙虎榜、融资融券。
  - 舆情/新闻：东财股吧、研报、新闻情感。
  - 卫星、招聘、APP 下载、电商销量、车流（A股可得性比美股差）。
- **基础设施**：列式存储（Parquet/Arrow）、时序库（ClickHouse/QuestDB）、特征仓库；**前复权用于因子计算，后复权用于回测收益**。

### 3.2 因子层
- **WorldQuant Alpha101**（2015 公开论文）：101 个量价短周期 alpha，已被全市场充分挖掘，**容量衰减严重**，更多作为教学/启发用。
- **Qlib Alpha158**：微软 Qlib 内置，158 个基于 K/V (Kbar + Volume) 的技术因子，按"窗口×算子"组合而成；适合 ML 模型输入。
- **Qlib Alpha360**：把过去 60 天的 OHLCV 共 6×60=360 个原始值拉成特征向量，**几乎不做人工特征工程**，让模型自己学。
- **遗传规划 (GP) 挖因子**：gplearn、AlphaGen、AutoAlpha，用进化算法自动生成因子表达式。

### 3.3 模型层
- **线性**：OLS、Ridge、Lasso、ElasticNet；可解释性强、Barra 框架做归因好用。
- **树模型**：LightGBM、XGBoost、CatBoost。**当前 A 股选股最实用基线**。
- **深度学习**：LSTM/GRU、TCN、Transformer、GNN。
- **训练范式**：滚动窗口 (rolling)、扩展窗口 (expanding)；目标可以是未来 N 日收益、排序 (LambdaRank)、IC 最大化。
- **核心陷阱**：未来函数、survivorship bias、look-ahead bias、过拟合。

### 3.4 回测层
**关键是模拟交易摩擦，否则"回测神，实盘鬼"**：
- **撮合 (Matching)**：日频用收盘价/VWAP；分钟/Tick 级要建订单簿撮合。涨跌停打标。
- **滑点 (Slippage)**：实际成交价与信号触发价的偏离。常用：固定 bp、波动率比例、平方根模型。
- **冲击成本 (Market Impact)**：大单本身推动价格。**Almgren-Chriss** 模型为业界标准，冲击 ∝ √(下单量/日均成交量)。
- **手续费**：佣金 + 印花税 + 过户费，双边约 1‰。
- 框架：vnpy、Backtrader、bt、zipline-cn、聚宽/米筐云端、Qlib、自研。

### 3.5 组合优化 (Portfolio Optimization)
把"预测的 alpha"变成"实际持仓权重"，在风险/约束下求解：

- **Mean-Variance (Markowitz)**：最大化 E[R] − λ·σ²；需要协方差矩阵估计，原始 MV 对输入敏感、解不稳定。
- **Risk Parity (风险平价)**：每个资产对组合风险贡献相等，桥水"全天候"代表作；A股内多用于大类资产配置。
- **Black-Litterman**：MV + 贝叶斯先验，可融入主观观点。
- **行业实践**：以 Barra 风险模型做约束（控制行业/风格暴露 ≤ X），二次规划 (QP) 求解，目标函数 = 预测收益 − 风险厌恶 × 跟踪误差² − 交易成本。

### 3.6 风控 (Risk Management)
- **事前**：风格/行业/单票暴露上限、流动性约束（不超过日均成交量 X%）、停牌过滤。
- **事中**：实时监控敞口、最大回撤熔断、压力测试、VaR / CVaR。
- **事后**：业绩归因，把超额收益拆解到行业/风格/选股残差（Barra 归因）。

### 3.7 执行 (Execution / Algo Trading)
大单拆小单进市场，控制冲击成本：
- **TWAP (Time-Weighted Average Price)**：时间均匀切片下单。简单、可预测、忽略成交量分布。
- **VWAP (Volume-Weighted Average Price)**：按**历史成交量分布**切片（典型 U 型，开盘+收盘量大），让自己的成交价贴近全市场 VWAP。机构最常用、最常作为业绩基准。
- **POV (Percentage of Volume) / Participation**：始终占当前实时成交量的固定百分比（如 10%），市场活跃就多下、清淡就少下，**对价格冲击最小，但完成时间不确定**。
- **进阶**：IS (Implementation Shortfall)、Iceberg(冰山)、Sniper、Liquidity Seeker。
- A股适用性：券商柜台 PB/PTrade、QMT、Ptrade 通常提供 TWAP/VWAP/POV 三件套。**注意 A股 9:30-9:35 与 14:55-15:00 流动性结构特殊**，需要专门校准 VWAP 曲线。

## 四、关键基础术语

> 凡是因子有效性、策略评价，都绕不开这几个数。

### 4.1 IC (Information Coefficient)
**定义**：调仓期初**因子值**与下期**收益率**的横截面相关系数。
- 通常用 **Spearman 秩相关**（Rank IC），对极端值不敏感，比 Pearson 常用。
- **|IC| > 0.03** 业内已视为有效；**|IC| > 0.05** 算好因子；**> 0.1** 罕见且常预示拥挤或过拟合。

### 4.2 ICIR (IC 的信息比率)
**定义**：`ICIR = mean(IC) / std(IC)`，衡量因子**有效性的稳定性**。
- ICIR > 0.5 较好；> 1.0 优秀。**IC 高但 ICIR 低 = 偶尔很神但不稳定**，难以用。

### 4.3 Sharpe Ratio (夏普比率)
**定义**：`(策略年化收益 − 无风险利率) / 年化波动率`。
- A股实务中常**忽略无风险利率**直接用 `年化收益/年化波动`。
- 主观股票多头基金 Sharpe 0.5-1.5；优秀指增 Sharpe 2-4；CTA 趋势 0.5-1.5；高频/中性策略 3-5+。

### 4.4 Maximum Drawdown (最大回撤)
**定义**：净值从历史最高点到后续最低点的最大跌幅。
- 比 Sharpe 更接近**投资者真实体感**——回撤大小直接决定客户能否拿得住。
- 衍生：**Calmar = 年化收益 / 最大回撤**，CTA 圈常用。

### 4.5 Turnover (换手率)
**定义**：单位时间内组合**买卖金额 / 平均持仓市值**，常按月或年度统计。
- 单边 vs 双边口径要区分。
- A股一个 100% 换手意味着一次性税费拖累约 0.5‰；高频策略年化换手 50× 以上时税费动辄吃掉 5‒10% 收益。

### 4.6 Capacity (策略容量)
**定义**：策略管理规模超过某阈值后，alpha 显著衰减或冲击成本吞噬收益的临界规模。
- 与换手率、标的流动性强相关。**高频 + 小市值** = 容量小；**低频 + 大盘 + 多因子** = 容量大。
- 国内头部量化"封盘"通常就是触及容量上限。

### 4.7 Alpha vs Beta
- **Beta (β)**：来自市场整体的收益，CAPM 中是单只股票对市场的回归系数。买宽基指数获取 Beta = "贝塔暴露"。
- **Alpha (α)**：扣除所有风险因子暴露后的**超额收益**，是**真正反映管理人能力的部分**。
- 实务："**指数增强 = Beta（基准指数） + Alpha（选股超额）**"；"**市场中性 = 纯 Alpha**"（多头组合 − 股指期货空头）。

### 4.8 因子衰减 (Factor Decay)
**定义**：因子被市场发现并被大量资金套利后，IC 和 ICIR 随时间下降甚至失效。
- A股表现尤为明显：经典价值、低估值、小市值溢价等因子在 2017 年后大幅衰减；2021 年以来量价高频因子也在加速拥挤。
- 应对：持续挖新因子、用 ML 自动生成、关注**正交化后的纯 alpha 部分**而非毛 IC。

## 五、给老王的几条"快速建立直觉"提示

1. **A股量化 ≠ 美股量化的翻译**：T+1、印花税、融券受限、散户主导，意味着**高频做市死路一条，量价 ML 选股黄金时代**。
2. **业绩好坏第一看 Sharpe + 最大回撤**，第二看**净值曲线的"陡峭与平滑"** —— 远比看年化收益率有意义。
3. **多因子框架是地基**，深度学习/Transformer 是上层装修，**没有数据治理 + 风险模型，模型再花哨也是沙上塔**。
4. **回测 Sharpe 5+ 大概率是过拟合**。可信指标：滚动窗口外样本 IC 稳定、turnover 与税费考虑后仍正、不同时段表现不爆炸。
5. **监管在变**：2024 程序化交易报告制度、限制融券、DMA 收紧——量化在中国是政策敏感行业。

## 不确定 / 待进一步核实
- "Sharpe 经验值"区间各家口径略有差异，上文取业内常见说法。
- 印花税以 2023-08-28 减半 0.5‰ 为准，后续若有调整应核对。
- Alpha158 因子总数 158 来自 Qlib 文档；不同版本/扩展可能略不同。
- 部分细节（如 Almgren-Chriss 在 A 股的具体实证表现）需要再翻券商研报或论文确认。
