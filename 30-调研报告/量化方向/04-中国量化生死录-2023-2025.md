## 一、2024.2 量化雪崩 — 中国版 Quant Quake

### 起火链路
```
雪球结构敲入 
  → 券商场外对冲卖出 IC/IM 股指期货
  → 基差暴走30%
  → 中证500/1000 暴拉
  → 微盘股开盘无量跌停(流动性枯竭)
  → 量化指增/中性/DMA 多空双杀
```

### 重灾名单
| 产品/私募 | 跌幅 |
|---|---|
| 幻方千象500指增 | -23.30% |
| 明汯500指增 | -29.70% |

| 公募大成动态量化A | -41.48% |
| **DMA(4倍杠杆中性)整体** | **-20% ~ -50%** |

**2024.2.19** 灵均投资 1分钟内卖出25亿,**被沪深所限制交易3天** — A股首次对量化"开第一枪"。

## 三、散户博主神话破灭识别(避雷指南)

四个红旗,**有一个就跑**:

1. **零回撤+年年20%+** = 100% 假
2. **只晒收益不晒规模** = 容量虚假,小资金跑得动,放大就崩
3. **推付费课/分仓软件** = 商业模式不在策略本身
4. **不公开持仓只说信号** = 旁氏味,信号无法验证

## 四、2024 还在赚钱的赛道

### 真实跑赢的策略
- **CTA趋势**(黑色系焦煤铁矿)— 商品周期红利
- **可转债低价策略**(集思录派)— 大V年化 +3-10%,**散户可复用**
- **红利ETF/银行/煤炭** — +20%级被动收益
- **低频多因子**(衍复/磐松活下来)— 容量小但稳

### 共性特征
- 容量小
- 低频(月度级以下不调仓)
- 规则透明
- 跟产业基本面挂钩(不是纯量价博弈)

## 六、2025 AI+量化结合点(真实进展)

### 已落地
- **LLM 抽财报/纪要文本因子** — 中金/华泰/国信都在内部做,outperform 传统NLP
- **另类数据**(招聘JD/卫星图/电商销量)— 拥挤前还有 6-12 个月窗口
- **强化学习做订单执行** — Qlib 的 RL 模块在学术圈热,实盘验证仍少

### 反向解读
**幻方现象 = 量化作为生意,头部自己都不信增长了**
- 头部主动转向通用AI(梁文锋 → DeepSeek)
- 私募规模整体收缩 23%
- 超额持续衰减,因子拥挤
- **2025 入场的散户,记住你是接盘侠的接盘侠**
