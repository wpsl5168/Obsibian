# A股量化交易：数据源与券商接入技术（个人投资者视角）

> 调研重点：散户/小私募可用方案为主；机构方案简要带过。截至 2025 年初；标注"需核实"的为不完全确认项。

## 一、行情/基本面数据源

### 1.1 机构付费三巨头（个人基本用不到，背景了解）

| 平台 | 费用 | 特点 |
|---|---|---|
| **Wind 万得** | 个人版 ~2-3 万/年，机构终端 6-10 万+/年 | A股最全（行情/财报/分析师一致预期/宏观/另类），Excel 插件+Python API（WindPy），是卖方/买方研究的事实标准 |

#### 关键差异说明

**Level-1 vs Level-2**
- 散户公开行情都是 Level-1（5档行情，3秒1快照）。
- Level-2（10档+逐笔委托+逐笔成交+委托队列）由上交所/深交所收费授权，机构通过券商/数据商授权；个人想用 Level-2 一般 200-500元/月，通过同花顺/通达信 L2 增值服务，或在支持的券商账户内调用。Tushare/AKShare/baostock **没有真正的 Level-2 委托队列**。

**复权处理**
- 标准做法：拿不复权 OHLC + 复权因子，回测时按需算前/后复权。Tushare/JQData/RQData 都给因子；AKShare 多数接口直接给"前复权/后复权/不复权"三选项。
- 坑：除权除息日的复权计算如果只调 close 不调 OHLC，会让低开高走类策略数据失真。

**停牌/退市/PIT 数据**
- Tushare/JQData/RQData：保留退市股代码与历史行情，回测可避免幸存者偏差。
- AKShare/baostock：退市数据**不完整**，做长周期回测有偏。
- 财报数据"PIT 修正"（用首次发布版本而非最新调整版）只有付费数据商（Wind/JQ/RQ/Tushare 高积分）做了。

**分析师一致预期**
- 散户能拿到的真正预期数据基本只有：Tushare（高积分 / 单独购买）、JQData、RQData 付费档。
- AKShare/baostock 没有，新浪/东财只有零散研报评级。

### 1.3 Tushare 积分制实操（最容易踩坑的点）
- 注册送 100 分；填资料 + 关注公众号到 ~120 分。
- 常用接口（日线、财报基础）120-200 分够用。
- **分钟线**需 5000 分（捐 200 元可拿一年；或邀请用户/写文章攒）。
- **资金流、Level-1 实时、tick** 需 2000-5000 分以上。
- 单接口购买：分钟 2000元、研报 500元、新闻 1000元、董秘问答 500元（皆为年费）。
- 实用结论：纯日频策略 100元/年级别能搞定；要 Level-1 实时+分钟+财报全套，年支出 500-2000 元。

### 1.4 散户推荐组合
- **入门/学习**：AKShare 主，baostock 备份；日线/财报/资金流够用，免费。
- **认真回测**：Tushare Pro（捐 200-500 元拿日线+基础财报+分钟权限）+ 本地通达信抽 tick。
- **要分析师预期/PIT**：JQData 个人年费版（~1500/年）性价比最高。
- **期货为主**：RQData 或 直接拿期货公司给的 CTP 历史 tick。

## 二、实盘接入协议

### 2.1 期货：CTP 系（成熟开放）

- **CTP**（上期技术综合交易平台）：国内期货事实标准，**所有期货公司**都支持。
- 个人开户：身份证+银行卡，无资金门槛（开通中金所/期权另需 50万+考试）。
- **SimNow** 仿真免费可注册，代码原样上实盘。**openctp / TTS** 是 vn.py 团队维护的备胎，支持股票仿真。
- 文档/示例齐全（vn.py、rqalpha-mod-ctp、ctpbee 等开源框架）。
- 高频用户可升级 **CTP Mini / 飞马CTP / 易盛 9.0**（同一家期货公司另外签）。
- **个人做期货量化，CTP 是几乎唯一的合规路径，且无门槛。**

### 2.2 股票：四大主流（按个人可达性排序）

#### A. QMT（迅投 PB / xtquant）— 个人最主流
- 厂商：迅投（恒生竞争对手），被 **国金、国信、中信建投、银河、华泰、招商、中金财富、东北、兴业** 等大量券商采用。
- 两个形态：
  - **完整 QMT**：客户端+策略+图表，支持 VBA/Python，本地运行，可读本地文件，**回测 tick/分钟/日线**。
  - **miniQMT (xtquant)**：极简模式，只提供 Python API（实盘下单+订阅行情），不带回测；体量小、适合自己用 PyCharm/VSCode 写代码 + 调券商实盘接口。当前散户做 Python 量化最流行的方式。
- **开户门槛**（2024-2025 实际情况）：
  - 官方明面：50 万金融资产（参考新规专业投资者门槛）。
  - 实际：很多券商客户经理可以**降到 10 万、甚至 2 万入金 1 个月即开**，是常见揽客手段。具体看券商，国金、国信、华鑫、东北证券、兴业等门槛公认较低。
  - 部分券商对 miniQMT 单独要求略高（要 20-50 万）。
- 支持品种：股票、两融、ETF、可转债、期权（部分券商）、期货（接对应席位）。
- **算法单**：QMT 支持 TWAP、VWAP、冰山、Pegging 等常见算法单（具体看券商接入的算法库）。

#### B. Ptrade（恒生）— 与 QMT 并列
- 厂商：恒生电子。券商：**华泰、海通、国泰君安、广发、平安、中信、方正** 等。
- 形态：策略**上传服务器运行**（关电脑不影响），支持 Python，自带回测。
- 门槛：跟 QMT 类似，官方 50 万，实际可谈到 10-20 万；某些券商对接 Ptrade 比 QMT 更易开。
- 不支持读本地文件（服务器端运行有沙盒限制），灵活性弱于 QMT。

#### C. XTP（中泰证券自研）— 偏机构/高频
- 中泰证券自研极速柜台，开源 Python/C++/Java API；同时也是 vn.py 教程的标准案例。
- **门槛较高**：
  - 散户用：需"专业投资者"认证——**金融资产 ≥ 300 万 + 一年投资经历**，或机构身份。
  - 流程：开户 → 联系客户经理签"三方采购"协议 → 程序需提交中泰合规检查 → 实盘必须部署在中泰内网托管服务器上，禁止外网传行情/交易数据。
- 适合：小私募、专业个人；速度强（XTP 是国内最快的几个证券柜台之一）。
- 类似的还有**华鑫奇点 Ostock**（华鑫 2017 自研）、**华锐 TORA**、**顶点 HTS**、**金证**等。这些"极速柜台"普遍都走"专业投资者+三方采购+内网托管"路线，散户基本不可达。

#### D. easytrader / 同花顺 hexin / VBA 脚本 — 模拟键鼠（灰色）
- 原理：用 pyautogui / Win32 API 操作"同花顺/银河/华泰/国金"的客户端 UI 完成下单。
- **不需要券商批准，无门槛**，技术上散户都能跑。
- **风险**：
  - 监管角度：2024.10 《证券市场程序化交易管理规定（试行）》要求"**先报告、后交易**"——个人投资者用程序化交易，理论上需要通过券商向交易所报备账户基本信息、资金、策略、软件等。easytrader 模式很难合规报告；2025.7 起的实施细则把报告/监控做实，使用者面临账户被限制交易的风险。
  - 技术角度：客户端升级即坏；并发慢（百毫秒-秒级），无法做日内高频；丢单/错单难处理。
  - 现状：仍有量化散户用来跑低频网格、定投、调仓，但**不推荐作为长期方案**；预算允许直接上 QMT/Ptrade。
- 项目本身在维护，但作者公开声明"教育用途"，券商一般不背书。

#### E. 券商 FIX / 第三方算法接入
- 大型机构走 **FIX 4.4 / FIX 5.0** 接券商算法交易（VWAP/TWAP/Implementation Shortfall），通常 1000 万元以上资金 + 合规审查才上。散户无关。

| 协议/平台 | 厂商 | 谁支持 | 个人门槛 | 算法单 | 推荐人群 |

## 三、监管现状（2024-2025）

### 3.1 核心文件
1. **《证券市场程序化交易管理规定（试行）》**（证监会 2024.5.15 发布，**2024.10.8 实施**）
   - 定义：通过计算机程序自动生成或下达交易指令。
   - **"先报告、后交易"**：所有程序化交易投资者（含个人）必须先向券商报告账户基本信息、资金、交易、软件等信息后方可交易。
   - 交易所对程序化交易**实时监控**，异常行为重点盯。
   - 高频差异化监管：单独报告、单独收费。
   - 北向资金（沪深股通）按"内外资一致"原则纳入报告。

2. **沪深北交易所《程序化交易管理实施细则》**（2025.4 发布，**2025.7.7 实施**）
   - **高频交易定义**："单账户每秒申报/撤单合计 ≥ 300 笔" 或 "单账户全日申报/撤单合计 ≥ 20,000 笔"，触发即认定为高频。
   - 高频额外义务：报告系统服务器所在地、系统测试报告、应急方案。
   - **四类异常交易**：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交——4 类指标自 2024.4 起已试运行。
   - 处罚：限制账户交易、暂停主机托管资源、报送基金业协会/证监会派出机构。

3. **《关于加强资本市场中小投资者保护的若干意见》**（证监会 2025.10）
   - 强化券商交易单元统一管理，**严禁为个别投资者提供特殊便利**——直接打击独立交易单元 / 专属机柜的"通道特权"。
   - 配套整改：2025 年底起暂停新增独立交易单元；要求"一个独立交易单元至少 10 个活跃账户"；多家券商已把机房从交易所搬离。
   - 游资打板、量化高频通过独占通道获取微秒级优势的玩法**逐步终结**。

### 3.2 散户实际影响
- **量化散户日均申报 << 20000 笔，几乎不会触发"高频"认定**；中小投资者基本不受新规惩戒。
- 但是：用 QMT/Ptrade 时，券商会代为做"程序化交易报告"，是合规前提；用 easytrader 这种规避券商通道的方式，**报告链条缺失**，理论上是违规的。
- 实操：监管目前主要盯量化私募与券商自营，散户事实上低风险，但**法律义务在那里**。

### 3.3 量化指增产品现状
- **2024 春节"小微盘股踩踏"** 是行业分水岭：DMA（4 倍杠杆中性）翻车，中证 1000/2000 指增大量产品当周回撤 -7%~-23%，多家百亿私募（衍复、稳博、因诺等）旗下产品净值断崖。
- 监管反应：
  - **DMA "三个不新增"**（窗口指导）：不新增合约、不新增投资人、不新增募集规模；存量逐步消化。截至 2024 年 Q2，DMA 业务日均成交占比从 ~5% 降至 ~3%。
  - 指增产品讨论"成分股 60%" 限制（参考公募 80% 的较松版本），新老划断。
  - 量化私募在频繁报送、策略报告、风控合规上压力陡增。
- **2024 全年业绩**：私募量化股票多头平均 +14.32%，跑赢主观多头 +11.33%；82% 量化指增正收益。Q4 行情好转后超额修复，但客户赎回明显（"水上即跑"）。
- **2025 趋势**：超额收益持续衰减、管理人之间相关性上升（500 指增超额相关性从 38% → 57%）、中证 A500 指增成新赛道、行业向头部 + 平台化集中、低延时硬件红利被监管抹平后竞争回归投研能力。

### 3.4 散户做量化的合规建议
1. 走 QMT/Ptrade 等**有牌照通道**，让券商替你做报告，最省心。
2. 不要尝试模拟一个"市场操纵"风险动作：频繁撤单、瞬时拉抬、跨账户对倒。
3. 资金量不到 50 万的，先用 CTP 期货仿真 + Tushare/AKShare 数据练手；要做股票实盘，找客户经理谈低门槛 QMT/miniQMT。
4. easytrader 仅用于学习；不要拿大资金跑。
