# Khan Academy 组织与财务

## 组织速览

| 项 | 信息 |
|---|---|
| 法律形式 | 美国 **501(c)(3) 非盈利组织** |
| 注册年 | 2008 |
| 总部 | Mountain View, California |
| 使命 | "free, world-class education for anyone, anywhere" |
| 员工数 | 全职约 200 人（含合同/志愿者 RocketReach 报 963，口径不同） |
| 覆盖国家 | 190+ |
| 支持语言 | 55+（14 种完整 + 28+ 部分） |

## 主要资助方（按时间）

| 年份 | 捐赠方 | 金额 | 用途 |
|---|---|---|---|
| 2010 | Google (Project 10^100) | \$2M | 新课程 + 翻译 |

| 2013 | Carlos Slim Foundation | 未公开 | 西班牙语翻译 |

| 2021.01 | **Elon Musk** (Musk Foundation) | \$5M | 通用 |
| 2024+ | **Microsoft** | 未公开 | Khanmigo for Teachers 免费授权（赞助 Azure OpenAI 算力） |
| 持续 | Reed Hastings (Netflix CEO) / Tiger Foundation / O'Sullivan Foundation | 未公开 | 通用 |

## 财务规模

| 财年 | 收入 | 支出 | 备注 |
|---|---|---|---|
| 2018 | \$31M | — | Wikipedia |
| 2019 | \$28M | — | Sal Khan 薪酬 \$839K |
| **2023** | **\$107.3M** | \$72.5M（**84% 用于项目**） | Electro IQ 引 IRS Form 990 |
| 2024 | 数据冲突 | — | Zippia \$44.8M vs 其他来源——**未找到权威 990 数据** |

**关键洞察**：
- 84% 收入直接用于项目（行业内极高比例，标杆非营利运营效率）
- 收入波动大，**严重依赖巨额单笔捐赠**——Musk 一笔 \$500 万就能波动一个百分点
- **没有商业化收入压力**——这是 Khanmigo 能坚持苏格拉底法（短期反人性）的根本原因

## Sal Khan 个人薪酬

- 2019 年公开 \$839,000/年——**引发非营利高管薪酬争议**
- 比同等规模 501(c)(3) CEO 偏高，但比硅谷同等资历低 5-10 倍
- Sal 公开回应：远低于他做对冲基金能拿的，且自己也是组织最大捐赠者之一

## 与 Microsoft / OpenAI 的合作机制

- **OpenAI 提供模型**：GPT-4 → GPT-4o，Khanmigo 是 OpenAI 官方旗舰案例
- **Microsoft 提供算力**：Khanmigo for Teachers 教师免费这件事是 Azure OpenAI 服务赞助跑出来的
- **数据隐私保护**：Khan Academy 与 OpenAI 签了协议，**学生/教师数据不用于训练模型**（Common Sense Media 确认）
- **三方关系本质**：非营利做产品和品牌、OpenAI 做模型、微软做基础设施和分发，三家各取所需

## 主要争议

1. **Sal Khan 薪酬** \$839K（2019）vs 非营利伦理
2. **Gates Foundation 长期资助** → 部分批评者认为是"硅谷亿万富翁主导公共教育改革"叙事
3. **2024 后大量接受 Microsoft 赞助** → 担忧产品独立性

## 数据缺口

- 2024-2025 年度 IRS Form 990 完整审计数据未公开
- 微软合作的具体资金/算力规模未公开
- 各国分支机构（如 Khan Academy India / Brasil）独立财务未公开
