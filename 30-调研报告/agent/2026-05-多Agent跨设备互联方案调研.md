# 多 Agent 跨设备互联方案调研

老王场景:Hermes(Azure VM)+ Mac/Win + 手机 + 未来树莓派 IoT,如何打通?

## 一句话结论

**协议层 MCP+A2A、运行时 Letta+LangGraph、网络 Tailscale+Redis Streams、端侧 Ollama/Foundation Models**。
四个事实标准已收敛,2026 中起步无悬念。

---

## 1. 协议层(谁是事实标准?)

| 协议 | 用途 | 状态 |
|---|---|---|
| **MCP** (Anthropic) | Agent ↔ 工具 | ⭐⭐⭐⭐⭐ OpenAI/Google/MS 全押注,LF 治理,工具层事实标准 |
| **A2A** (Google) | Agent ↔ Agent | ⭐⭐⭐⭐ 150+ 组织,v1.0 GA,AgentCard+SSE+webhook 天然跨 NAT |
| IBM ACP | Agent ↔ Agent | 已被 A2A 收编,死路 |
| OpenAI Agents SDK | 框架 | 内部 handoff,对外仍走 MCP/A2A |
| LangGraph Platform | 框架+运行时 | 私有 REST,框架第一梯队 |

**选型**:MCP 装工具,A2A 连 Agent,其它都是实现细节。

## 2. 运行时编排框架

| 框架 | 范式 | 跨机 | 持久化 | 适合 |
|---|---|---|---|---|
| **LangGraph** | 状态机+图 | Platform 分布式 | ⭐⭐⭐⭐⭐ checkpointer | 复杂流程+HITL+回滚 |
| CrewAI | 角色团队 | 单机 | ⭐⭐⭐ | 角色 PoC |
| AutoGen v0.4 | actor 模型 | gRPC 真分布式 | ⭐⭐⭐ | 异构语言 |
| OpenAI Agents SDK | handoff | 无 | Session | 强绑 OpenAI |
| **Letta** (原 MemGPT) | Agent-as-Service | 天生 server/client | ⭐⭐⭐⭐⭐ Core/Archival/Recall | **跨设备共享记忆** |

**选型**:双层架构 — **Letta 管"我是谁"(记忆层) + LangGraph 管"我在做什么"(编排层)**。

## 3. 网络+总线+端侧(工程方案)

```
        ┌────────── Tailscale Mesh (WireGuard) ──────────┐
 [Azure VM]100.1   [Mac]100.2   [手机]100.3   [树莓派]100.4
   Hermes GW         本地 LLM      端侧 Agent    边缘传感
   Redis Streams                                  Mosquitto MQTT
        ↓
 微信/TG/飞书(走公网 webhook,不进 mesh)
```

| 层 | 选型 | 备注 |
|---|---|---|
| 跨 NAT | **Tailscale** | 每台 100.x IP,Hermes 当 LAN 调家里设备 |
| 控制总线 | **Redis Streams** | 已有 Redis 免费送;>10 设备迁 NATS JetStream |
| IoT 数据 | **MQTT (Mosquitto)** | 传感器→边缘 Agent |
| 手机端脑 | iPhone Foundation Models / Android Gemini Nano / 兜底 MLC LLM | 只做意图+脱敏 |
| 树莓派脑 | Pi 5 8GB + Ollama + qwen2.5:1.5b | 边缘推理+MQTT 网关 |

## 4. 隐私三级

| 级别 | 例子 | 去向 |
|---|---|---|
| **L0 必须本地** | 摄像头帧/麦克风流/位置/密码 | 永不出设备 |
| **L1 内网可流转** | 脱敏事件/文档摘要/代码片段 | Tailscale mesh 内 |
| **L2 可上云** | 回复文本/公开 query | 微信/TG/云端 LLM |

Gateway 内置脱敏中间件,L0 越界用 Redis 字段 `data_level` 审计。

## 5. 2 周最小落地

- **Week 1**:VM/Mac/手机装 Tailscale → VM Redis 开 Streams → Hermes 加 consumer group → Mac 当 worker(Ollama)→ 微信投递
- **Week 2**:Raspi 5 装 Ollama+Mosquitto → 接一个传感器 → 摘要写 Redis → 触发播报。脱敏 plugin 落地。

骨架不变:**Tailscale 做网,Redis Streams 做总线,Ollama 做端侧脑**。NATS/Gemini Nano/Letta 是渐进升级。
