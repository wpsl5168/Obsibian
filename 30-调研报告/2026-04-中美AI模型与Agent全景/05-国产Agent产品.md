## 深度点评

### 🏆 扣子 Coze — 国内 Agent 平台事实标准
- **核心打法**：低代码 Workflow + 抖音/飞书超级 App 分发
- **新动作**：2025 后增加"操作电脑/手机"能力（追赶 Manus/AutoGLM 路线）
- **竞争位**：国内开发者首选，海外 coze.com 在东南亚跑得最好
- 字节生态绑定既是优势也是限制（不绑字节场景的客户犹豫）

### 🏆 AutoGLM — 国家队的 Agent 旗手
- **架构亮点**：GLM-4.5（规划脑）+ GLM-4.5V（视觉脑）双模型协同
- **杀手锏**：云手机异步执行 + 40+ 国民 App 自动化覆盖
- **性价比**：单任务成本 ~$0.2，端到端 RL 训练加持
- **公司动态**：智谱已在港交所上市（2026-01），国家队背景 + 上市资本 + Agent 商业化三位一体

### 🏆 Manus — 估值最猛的"通用 Agent"，但被收购了
- **数字最炸**：270 天 ARR 破 $1 亿，订阅 $19–$199
- **2025-12-30 被 Meta 收购**（数十亿美元级），创始人加入 MSL
- **2026-01 中国商务部启动技术出口审查** — Manus 案件成"中国 AI 公司海外退出"路径事实终结的标志事件
- **历史意义**：证明"无原创模型也能拿到 $1 亿 ARR"，工程编排 + 场景落地的价值

### 文心 AgentBuilder — 搜索分发是差异化护城河
- 80 万+ Agent，超 20 万开发者，规模可观
- 但增速放缓，受扣子/智谱双向挤压
- 面向传统中小企业卖 token + 行业方案是稳健路径

## 国产 Agent 共性观察

### 形态共性
1. **通用 Agent 路线被普遍押注**（Manus、AutoGLM、扣子操作电脑）— 与美国"编码 Agent 一枝独秀"形成鲜明对比
2. **MaaS + 平台 + 应用三层并行**（智谱、字节、百度都做这套）
3. **搜索/超级 App 分发成关键资源**（百度搜索、抖音、飞书）

### 商业化共性
1. **C 端付费弱、B 端走政企/私有化 + 项目制**
2. **全球化是高 ARR 的唯一出路**（Manus 模式得到验证）
3. **但全球化路径已被地缘政治切断**（Manus 被收购 + 商务部审查）

### 与美国 Coding Agent 头部的差异
| 项 | 美国 Coding Agent | 中国通用 Agent |
|---|---|---|
| 用户群 | 开发者 | C 端白领 + B 端企业 |
| 客单价 | $20–$200/月 | $19–$199/月（Manus）/项目制（B 端） |
| 商业模式 | 订阅 + IDE 嵌入 | SaaS + 私有化 + 平台分成 |
| 护城河 | 模型 + IDE 体验 | 工程编排 + 场景渗透 |
| 出海能力 | 天然全球（Cursor 已破 $5B ARR） | 受限（Manus 后路径事实终结） |

## Manus 案件的行业意义

> Manus 是 2025-2026 年中国 AI 行业最重要的标志性事件之一：
> - **正面**：270 天 $1 亿 ARR 证明工程派也能拿大钱
> - **负面**：被 Meta 收购 + 商务部审查 → "中国孵化 + 海外退出"路径事实终结
> - **后续影响**：迫使国产 Agent 厂商重新思考"全球化 vs 国内深耕"，倒逼本土生态更紧密协同
