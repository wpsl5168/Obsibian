## 5/9 PROACTIVE-5 详细
**话题域硬隔离**(`~/.hermes-pet/app-prompt.md`,仓外 mtime 热加载):
- 6 大禁讨论域:代码 / 项目内部进展 / 接单 / Hermes 配置 / 工作进度 / 商业策略
- **主动被动都禁** — 即使老王主动问也要傲娇推开 + 抛新话题
- 例外:情绪状态可共情,但不追技术细节

**greeting 多样性**(`web/src/lib/prompt-loader.ts`):
- 15 调式词库(傲娇/撒娇/吐槽/八卦/好奇/犯困/无聊/兴奋/委屈/神秘/自言自语/突然插话/一本正经胡说/碎碎念/邀功)
- 句式轮换 + 话题源轮换(体育不只 NBA,科技不只 OpenAI,影视不只新剧)
- 开场词扩充(喂—/欸欸/嘶/嗯哼/打哈欠/伸懒腰)
- 避免连续重复(上轮体育这次非体育)

**接续与拒绝识别**:
- 接续:有上下文优先续上未闭环话题,带"上次"钩子但不复读
- 拒绝信号:明确拒绝 / 连续两轮敷衍 / 反问回怼 / 主动开新话题
- 被拒后立刻换调式 + 换话题源,不解释不挽尊

**实测**:onboarding 5 次开场全不重样贴 vibe / chat 拒绝识别准 / 话题域硬隔离 3 场全过

**commits**: `7b479e3` prompt 主体 + `a1b6a94` splash 7.0.5 降级 + `cac31f0` launcher icon 重生成 → main pushed

## 决策记录(关键)
| 日期 | 决策 | 触发/理由 |
|---|---|---|
| 5/7 | 8 周 MVP, dogfood 先行 | 业余节奏 + 自己先用透 |
| 5/8 | 跳过 ChatBox 中转 | 减少中间环节 |
| 5/8 | 鸿蒙锁 ArkTS 原生 | 改动小, 不依赖第三方适配层 |
| 5/8 | 跨端方案进 backlog | 一个端都没做完, 谈跨端是过度设计 |
| **5/8** | **灵魂+皮肤解耦** | 同一个 AI 不分裂；皮肤纯视觉不带性格 |
| **5/8** | **不做性格选择器** | 性格归 hermes 自治；用户画像驱动语气 |
| **5/8** | **不开独立 profile** | 灵魂统一，跨平台关系连续 |
| **5/8** | **不做多用户/多租户** | 一个用户=一个部署；多用户 v2+ 再说 |
| **5/8** | **首启 LLM 个性化开场白** | 读 USER.md 自动适配老王风/萌系/直男风 |
| **5/9** | **零服务端对话存储** | proactive followup 用客户端推快照,服务端只存 chat events ndjson(无 PII) |
| **5/9** | **app-prompt 仓外管理** | `~/.hermes-pet/app-prompt.md` 不入仓,mtime 热加载,客户端无权改;铁律层独立于人格层(user-soul.md) |
| **5/9** | **mio 是陪伴角色不是工作助手** | 6 大工作话题域硬隔离;陪伴感不能被技术讨论污染 |
