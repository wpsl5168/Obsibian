     1|# HermesPet · 我的 AI 分身
     2|
     3|> 同一个灵魂，多种皮肤 — 我的 AI 在不同形态下陪我
     4|
     5|## 一句话定位
     6|HermesPet 不是一个新 AI，是**我已有的 AI(Hermes/小虾)的可视化分身入口**。灵魂(记忆/性格/关系)在 hermes 后端自治，App 只是给这个灵魂套一个用户喜欢的外观（喵喵/黑客/直男/...）。
     7|
     8|换皮肤不换魂：你在猫形态养出的感情，切到黑客形态还是同一个它。
     9|
    10|## 核心原则
    11|1. **灵魂归 hermes**：记忆/性格/工具调用全归后端 hermes agent，前端零自管
    12|2. **皮肤纯视觉**：形象只决定 Live2D/像素/ASCII 等渲染层 + 情感动画映射，**不**带性格
    13|3. **开场白随用户画像**：LLM 读 USER.md 生成个性化开场白，不写死萌话/直男话
    14|4. **首启即认识**：app 第一次打开就直呼用户名，建立"它本来就认识我"的情感锚点
    15|
    16|## 现在做什么
    17|- ✅ Phase 0 网络层(`pets.brickhub.cc` 公网可调)
    18|- ✅ Phase 1 命名/决策锁定
    19|- 🟡 Phase 2 SPA 改造(拆自管逻辑 + 接 hermes api_server + 皮肤系统)
    20|- ⏸ Phase 3 鸿蒙原生 App(ArkTS)
    21|- ⏸ Phase 4 物理化身(小车/桌面)
    22|
    23|## 不是什么
    24|- ❌ 不是 ChatGPT 套壳
    25|- ❌ 不是宠物模拟养成游戏
    26|- ❌ 不是云端"借给你"的 AI(灵魂跟记忆是 hermes 自治的)
    27|- ❌ **不是"猫娘陪聊"**(皮肤可以是猫，但不强加猫娘人格)
    28|- ❌ 不做多人格/多租户(一个 hermes = 一个灵魂)
