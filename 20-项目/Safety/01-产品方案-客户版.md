# Safety AI · 工程安全检查系统

## 一句话定位

**让现场作业人员一拍照，AI 自动识别违规并形成整改闭环的智能安全管理平台。**

私有化部署，数据不出客户域；通用内核 + 行业模板，开箱即用。

---

## 一、为什么需要

| 传统安全检查的痛点 | Safety AI 的解决方式 |
|---|---|
| 安全员人少、巡检频次低、漏检多 | 一线工程师人人可拍，AI 自动识别违规 |
| 检查记录散落在纸质表格、微信群 | 全部数字化沉淀，一处可查 |
| 整改靠口头提醒，闭环难追溯 | 标准化流转：派单→整改→证据→复核→关闭 |
| 月报季报手工统计，效率低 | 一键生成 PDF/Excel 报表 |
| 高危违规事后才知道 | 实时推送到企微/短信/钉钉 |

---

## 二、产品全景

![架构图](assets/architecture.png)

系统由四部分组成：

1. **工程师端 APK**：手机端，现场拍照→AI检查→整改上报
2. **管理端 Web**：后台，看台账、派整改单、出报表、配规则
3. **AI 引擎**：视觉识别 + 行业规则库，输出违规清单与整改建议
4. **私有化部署包**：一键安装到客户内网或专属云服务器

---

## 三、工程师端（手机 APK）

> 安卓 APK，扫码下载即用；面向一线工程师、班组长、安全员

### 核心功能

| 模块 | 功能 |
|---|---|
| **登录** | 工号/手机号登录，长期免登录 |
| **首页** | 我的项目、待办整改红点、一键拍照 |
| **拍照检查** | 单拍/连拍/相册多选；可选检查类型（日常巡检/专项/复检） |
| **AI 分析** | 上传后自动识别违规，标注违规位置、严重度、整改建议 |
| **结果详情** | 违规框可点击查看：法规依据、整改方案、相似案例 |
| **整改任务** | 接收派单 → 现场整改 → 拍前后对比图 → 提交复核 |
| **历史记录** | 个人/班组检查记录，支持按时间/项目筛选 |
| **离线支持** | 无网络时本地缓存，联网自动补传，工地信号差也不丢数据 |

### 用户体验亮点

- ✅ 拍完照 **3-5 秒**出结果
- ✅ 违规位置直接在图上**框选高亮**
- ✅ 严重度**颜色分级**（红/黄/蓝）一眼可辨
- ✅ 整改建议带**法规条文出处**，有理有据

## 五、AI 能力

### 三段式智能识别

```
现场图片 ─► 视觉大模型 ─► 行业规则匹配 ─► 严重度评分 ─► 违规清单
            (识别画面元素)   (匹配违规规则)    (优先级排序)
```

- **视觉大模型**：业界领先的多模态大模型（Gemini / Qwen-VL / Claude）
- **规则引擎**：覆盖通用安全 + 行业专项规则
- **置信度评分**：AI 给出可信度，低置信由人工最终判定

### 行业模板（开箱即用）

| 行业 | 规则数 | 典型违规 |
|---|---|---|
| **电力作业** | 30+ | 高空未系安全带、带电作业违规、工器具不合规 |
| **建筑施工** | 50+ | 高空坠落、三宝四口、起重违规、临边防护缺失 |
| **化工生产** | 40+ | 动火作业、受限空间、防爆区违规、PPE 缺失 |
| **制造车间** | 30+ | 机械防护缺失、危化品违规、消防通道堵塞 |
| **仓储物流** | 20+ | 货架超载、叉车违规、通道堵塞 |

> 客户上线时按需勾选；可在项目级覆盖严重度阈值；支持自定义新增规则。

## 六、私有化交付

### 部署模式

> 一客户一套独立部署，**所有数据存储在客户指定的服务器上**，厂商不接触客户业务数据。

| 部署位置 | 适用场景 |
|---|---|
| **客户内网服务器** | 数据高敏感，要求完全隔离 |
| **客户专属云服务器** | 阿里云/腾讯云/华为云等客户自有云账号 |
| **厂商托管** | 客户无运维能力，由厂商代管（专属实例，仍单租户） |

### 系统要求

- **服务器**：4核 CPU / 8G 内存 / 100G 硬盘起（可承载 50 人团队、月 5000 次检查）
- **操作系统**：Linux（Ubuntu 22.04+ / CentOS 8+ / 国产麒麟均可）
- **网络**：需可访问 OpenRouter API（境外）；如客户内网受限，提供国产模型适配方案
- **域名/HTTPS**：客户提供；如无可使用厂商提供子域

### 安装与升级

- **一键安装**：一行命令完成部署，2 小时内上线
- **平滑升级**：定期发布新版本，一键升级，自动数据迁移
- **数据备份**：每日自动备份至客户指定位置

## 七、数据安全

| 维度 | 措施 |
|---|---|
| **数据归属** | 全部数据归客户所有，存于客户指定存储 |
| **传输加密** | 全链路 HTTPS / TLS 1.3 |
| **存储加密** | 数据库与对象存储加密落盘 |
| **访问控制** | RBAC 多级角色 + 操作审计日志 |
| **数据导出** | 支持随时全量导出（图片+台账） |
| **AI 调用** | 仅传图片至大模型推理，不留存于第三方 |
| **退出机制** | 终止合作时，提供完整数据导出与销毁证明 |

## 八、典型工作流

### 场景：电力作业现场巡检

```
1. 班组长打开 APK，进入"日常巡检"
2. 对作业现场连拍 5 张照片
3. AI 3 秒返回：发现 2 条违规
   - 🔴【严重】工人 A 高空作业未系安全带（GB 26859-2011）
   - 🟡【一般】工器具未做绝缘测试标识
4. 班组长确认违规，APK 自动派单给工人 A
5. 工人 A 收到通知，整改后拍"整改后"照片提交
6. 安全员收到复核任务，确认整改到位，关闭违规
7. 月底：管理端一键生成本月安全报告 PDF
```
