# Safety AI · 行业模板规划

## 设计原则

> **通用内核 + 可插拔行业模板包**

- 内核：规则引擎 DSL + 评分器 + Prompt 框架（一次开发）
- 模板包：每个行业一份 YAML 规则库（独立维护、独立更新、独立销售）
- 派生：客户可在项目级覆盖严重度/阈值，可新增自定义规则

---

## 模板包数据结构

```yaml
template_id: power_2026
industry: 电力作业
version: 1.2
last_updated: 2026-05-03
rules:
  - code: PWR-001
    title: 高处作业未系安全带
    category: 高空作业
    severity: critical          # critical / major / minor
    confidence_threshold: 0.7
    prompt_hint: |
      重点观察：图中是否有工人位于2米以上高度？
      是否正确佩戴五点式安全带？安全绳是否系挂在牢固构件？
    legal_ref: GB 26859-2011 第6.3条
    suggestion: |
      1. 立即停止作业
      2. 正确佩戴五点式安全带
      3. 安全绳高挂低用，挂于上方牢固构件
    examples:
      - positive: assets/pwr-001-pos.jpg   # 正例（违规）
      - negative: assets/pwr-001-neg.jpg   # 反例（合规）
```

## 电力作业模板（P1，参考现 demo）

详细规则待 P3 阶段产出，初版至少包含：

- 高空作业（安全带、安全绳、登高工具）
- 带电作业（验电、绝缘工具、双人监护）
- 工器具（绝缘鞋手套、合格期）
- 临时用电（接地、漏保、线缆）
- 倒闸操作（票面、监护、唱票复诵）

法规依据：
- GB 26859-2011《电力安全工作规程》
- DL 5009.3-2013《电力建设安全工作规程》

## 建筑施工模板（P1，市场最大）

- 三宝四口五临边（安全帽/安全网/安全带；楼梯口/电梯井口/预留洞口/通道口）
- 高处作业（脚手架、防护栏、安全网）
- 起重作业（吊装、信号工、吊钩防脱）
- 临时用电
- 模板支撑
- 基坑/沟槽支护
- 消防（动火、灭火器）

法规依据：
- GB 50870-2013《建筑施工安全技术统一规范》
- JGJ 80-2016《建筑施工高处作业安全技术规范》

## 模板维护流程

1. 行业专家访谈 → 提取核心规则（10-20条/次）
2. 撰写 prompt_hint + 严重度 + 法规依据
3. 收集正反例图片（10+/规则）
4. 在测试集上跑准召率 → 调整 prompt
5. 内部 review → 入库 → 打 tag 发布
6. 客户启用后收集反馈 → 迭代

---

## 风险与坑

- **法规依据可能涉及版权**：GB/AQ 标准条文摘录是否需授权？需法务咨询
- **行业差异大**：同样是"高空作业"，建筑和电力定义不同，必须在模板维度区分
- **VLM 对中国工地场景的理解**：实测 Gemini 对中文标识、国标 PPE 颜色、国内特有工种识别有偏差，需用 prompt_hint 校准
- **规则数量天花板**：超过 50 条规则时，单次 VLM 调用 prompt 会过长 → 需分组路由
