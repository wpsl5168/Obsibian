## D9: 端到端插件集成测试 (8 场景) — NEW

覆盖 Hermes 插件系统 → 海马体服务的完整链路。

| 编号 | 场景 | 验证点 |
|------|------|--------|
| T9.1 | 插件加载与Hook注册 | register(ctx) 正确注册3个hook |
| T9.2 | pre_llm_call 语义召回 | 用户消息触发海马体搜索，返回相关上下文 |
| T9.3 | 短消息/空消息跳过 | MIN_QUERY_LEN 过滤生效 |
| T9.4 | post_llm_call 规则提取 | 匹配模式的用户消息被提取存储 |
| T9.5 | post_tool_call 记忆镜像 | memory工具的add/remove操作同步到海马体 |
| T9.6 | 全链路往返 | 写入→归档→语义召回 完整闭环 |
| T9.7 | WAL离线容灾 | 服务宕机时写入WAL，恢复后自动重放 |
| T9.8 | 注入格式验证 | 返回 {"context": "🦛 ..."} 格式正确 |

### 关键发现

- **BUG-004 (P1, 已修复)**: 插件缺少 `register(ctx)` 函数，导致hook从未注册，所有对话都不会触发海马体搜索。2026-04-19修复。

### 测试方法

D9测试直接import插件模块调用hook函数，不依赖Hermes运行时。需要OpenHippo服务和Ollama在线。T9.7会临时停止服务，测试后自动恢复。

详细测试代码见技能: `openhippo-testing` D9章节。
