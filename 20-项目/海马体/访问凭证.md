## 架构链路

```
Browser → Cloudflare (Full Strict, proxied)
       → Caddy (Docker, Let's Encrypt + Cloudflare DNS-01)
       → host.docker.internal:8200
       → uvicorn openhippo.api.rest:app (systemd --user, 0.0.0.0:8200)
```

## Token 轮换

```bash
NEW=$(openssl rand -hex 24)
HASH=$(echo -n "$NEW" | sha256sum | awk '{print $1}')
# 1) 改 ~/.hippocampus/config.yaml 里 auth.bearer_sha256 = $HASH
# 2) echo "$NEW" > ~/.hippocampus/UI_TOKEN.txt && chmod 600 ~/.hippocampus/UI_TOKEN.txt
# 3) systemctl --user restart openhippo.service
# 4) 更新本文档
```
