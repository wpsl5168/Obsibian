# 海马体测试用例 D6-D8（容量/生命周期/异常恢复）

> 📚 上级页面：[[测试方案与用例]]

### D6: 容量管理（2个场景）⚠️

#### T6.1 热记忆容量监控

| 项目 | 内容 |
|------|------|
| **目的** | 检查当前hot memory的容量使用率 |
| **指标** | hot_memory_chars / 4400, hot_user_chars / 2750 |
| **已知缺陷** | **BUG-001**: HOT_MEMORY_LIMIT仅display用，无执行逻辑 |

#### T6.2 批量写入淘汰行为

| 项目 | 内容 |
|------|------|
| **目的** | 观察连续写入20条后是否有自动淘汰 |
| **预期（当前）** | 无淘汰，条目数=before+20 |
| **预期（修复后）** | 超过4400 chars时自动归档最旧条目 |

---

### D7: 生命周期完整性（1个场景）

#### T7.1 端到端全链路

```
创建 → 替换 → 归档 → Cold搜索 → 提升 → 删除 → 验证清除
```

7步操作验证记忆从诞生到销毁的完整生命周期，每一步都检查状态正确性。

---

### D8: 异常与恢复（3个场景）

#### T8.1 无效请求处理

| 输入 | 预期状态码 |
|------|-----------|
| 缺少content字段 | 422 |
| 空JSON body | 422 |
| 非法target值 | 400/422/500 |

#### T8.2 不存在条目操作

| 操作 | 预期 |
|------|------|
| Replace不存在的old_text | 404 |
| Remove不存在的old_text | 200 (含error字段) |
| Promote不存在的cold_id | 404 |

#### T8.3 服务重启持久化

| 项目 | 内容 |
|------|------|
| **方法** | 记录stats → systemctl restart → 对比stats |
| **验收** | cold_count和hot_memory_count完全一致 |
