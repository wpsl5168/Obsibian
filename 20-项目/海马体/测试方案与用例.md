# 🦛 OpenHippo 记忆系统测试方案与用例

> 本文档定义海马体记忆系统的完整测试体系，覆盖8大验证维度、27个测试场景，用于系统性评估功能正确性、性能、稳定性和生产就绪度。

## 1. 测试目标

作为 Agent 记忆系统，OpenHippo 需满足以下行业标准：

| 能力要求 | 说明 | 对应维度 |
|----------|------|----------|
| **记忆准确性** | 写入即可读，替换/删除立即生效 | D1 功能正确性 |
| **去重能力** | 精确去重 + 语义去重，防止记忆膨胀 | D2 去重机制 |
| **检索质量** | 关键词精确匹配 + 语义理解 + 混合排序 | D3 搜索质量 |
| **响应性能** | 写入 <1s，搜索 <0.5s，支持并发 | D4 性能基准 |
| **数据安全** | 特殊字符不破坏存储，SQL注入防护 | D5 数据完整性 |
| **容量治理** | 热记忆有上限管控，自动淘汰 | D6 容量管理 |
| **生命周期** | 创建→更新→归档→检索→提升→删除 全链路 | D7 生命周期 |
| **容错恢复** | 异常输入优雅处理，重启不丢数据 | D8 异常恢复 |

## 2. 系统架构概览

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   MCP Tool   │  │  REST API   │  │     CLI     │
└──────┬───────┘  └──────┬──────┘  └──────┬──────┘
       └────────────┬────┘────────────────┘
            ┌───────▼────────┐
            │   Core Engine   │
            │  ┌───────────┐  │
            │  │ Hot Memory │  │  ← 每轮注入，快速读写
            │  ├───────────┤  │
            │  │Cold Memory │  │  ← FTS5全文 + Vec向量搜索
            │  ├───────────┤  │
            │  │  Dedup 🔒  │  │  ← SHA256精确 + 余弦语义
            │  └───────────┘  │
            └───────┬────────┘
            ┌───────▼────────┐
            │ SQLite+FTS5+Vec │
            └────────────────┘
```

**关键参数：**
- Hot Memory 容量上限：memory=4400 chars, user=2750 chars
- 语义去重阈值：L2 distance < 0.4（≈ cosine > 0.92）
- Embedding 模型：nomic-embed-text (768维)
- 混合搜索算法：RRF (Reciprocal Rank Fusion, k=60)

## 6. 测试执行指南

### 前置检查清单

- [ ] OpenHippo 服务运行中 (`curl localhost:8200/health`)
- [ ] Ollama 可用 (`curl localhost:11434/api/embeddings -d '{"model":"nomic-embed-text","prompt":"test"}'`)
- [ ] 单元测试基线通过 (`cd ~/OpenHippo && .venv/bin/python -m pytest tests/ -v`)
- [ ] 记录测试前 stats 快照

### 测试数据规范

- 每轮测试使用**时间戳tag**: `[T{维度}.{场景}_{timestamp}]`
- 测试后**必须清理**测试数据，避免污染生产环境
- 清理标识前缀: `[T1.`, `[T2.`, ..., `[T8.`, `[perf_`

### Pitfalls

1. **Ollama冷启动**: 首次embedding请求可能>2s，测试前发预热请求
2. **测试数据污染**: 不清理会导致hot memory持续膨胀（已有BUG-001）
3. **FTS5语法**: 特殊字符(引号、括号)需转义，否则静默回退LIKE
4. **并发假象**: SQLite单写锁，uvicorn排队，非真并行
5. **语义去重依赖Ollama**: Ollama宕机时embedding返回None，语义去重静默跳过
