# 写作风格约定（中文优先）

- 默认用中文写。
- 专有名词/标准/产品名可保留英文（如 [[MCP]], HITL, tracing, evals, sandbox, workflow）。
- **不解释每个英文单词**：默认读者有基本英语。
- 仅对“关键但可能陌生”的术语，在**首次出现**时用括号补一句中文（可省略）。读者不懂再问。
- 少堆链接：每条信息必须回答“是什么 / 为什么重要 / 怎么用”。
- 控制信息密度：宁缺毋滥，每日 5–10 条以内。
