# Governance（治理与可恢复性）

目标：把“有意义的东西”落到 GitHub（wpsl5168/Obsidian），做到服务器故障也能找回。

## 原则
- GitHub 是 **所有输出物** 的落地处：日报、话题页、规则、模板、关键记忆副本。
- 本机只当缓存/工作区；任何重要结论必须 commit+push。
- 记忆分层：
  - **Daily memory（原始日志）**：按天追加
  - **Curated memory（提炼记忆）**：长期有效的偏好/背景/决策

## 目录
- `OpenClaw-Memory/`：记忆副本（从本机 workspace/memory 同步过来）
- `Rules/`：写作规范、工作流、审批点策略
- `Agents/`：大秘/二秘职责与边界（角色定义）
