## 今日判断

大厂官博空窗，今天真正有用的是 Agent 安全与记忆、长上下文推理栈两组工程信号。

ClawSentry 把技能首审、调用意图、执行结果、事后证据拆成四层检查，项目方实验把 Agent 攻击成功率从 39.55% 压到 2.61%，任务成功率只从 83.78% 降到 83.05%。这比“装 skill 前扫一下”完整得多：供应链安全必须延伸到 runtime，尤其要防同一 session 内绕过。

Weighted Memory Tree 和 Memory-Augmented CoT 指向同一个结论：Agent 记忆不该只是向量库加 top-k。前者动态决定保留、折叠和抑制，报告准确率 +9.97pp、prompt token -32.8%；后者把历史推理压成可复用 scaffold，以 prefill 换 decode，多个基准提升 6.61–29.5 points。数字仍需复现，但结构值得直接借鉴。

长上下文方面，E²-TTT 在训练长度 8 倍处仍报告 >90% passkey accuracy；BF1 对预训练模型做局部稀疏注意力 retrofit，32K 单层 prefill 10.91×，但整模 TTFT 只降 15.3%。后一个数字更诚实：kernel 加速不等于端到端同比加速。

### Simon Willison：昂贵模型迫使团队认真做 workload routing

Simon 转引 Drew Breunig 的判断：过去新模型往往同价或更便宜，并能掩盖 harness 和 context 的低效；昂贵的 Fable 使“什么任务交给什么模型”重新变成硬问题。

### 推理与 Serving

- [E²-TTT: Rethinking Expressivity and Efficiency in Test-Time Training](https://arxiv.org/abs/2608.21308) — cs.LG，submitted 2026-08-21。推导闭式状态转移，在 chunk-start 梯度近似下复现逐 token recurrence；训练到 1.3B，Needle-in-a-Haystack 在训练上下文 **8×** 长度仍报告 **>90%** 准确率。判断：兼顾长上下文外推与并行训练，值得核代码与近似边界。
- [BF1: A Causal Dyadic Sparse-Attention Retrofit](https://arxiv.org/abs/2608.20427) — cs.LG，submitted 2026-08-19。RTX PRO 6000 Blackwell 上 32K 单层 prefill **10.91×**；Qwen3-0.6B 只改 28 层中的 8 层，8K/16K/32K 整模 TTFT 降 **7.7%/11.3%/15.3%**。判断：局部 retrofit 可迁移；单作者结果和基线仍需复现。
- [TreeWY: Speculative Verification for Gated DeltaNet Hybrids](https://arxiv.org/abs/2608.20961) — cs.AI，submitted 2026-08-21。用 tree-structured WY transform 免去每个 draft position 的 recurrent-state snapshot，只在 commit 重建状态；测试 Qwen3.5 35B/397B。摘要未给吞吐数字，并承认显存不紧时有几个百分点开销。判断：问题选得准，结果还不够定量。
- [Memory Augmentation Unlocks Efficient Chain-of-Thought Reasoning](https://arxiv.org/abs/2608.21265) — cs.CL，submitted 2026-08-21。training-free，把历史 reasoning traces 压成可检索 scaffold；相对 Chain-of-Draft 在 GSM8K/MATH/BBH/MMLU-Sci 提升 **21.4/28.0/29.5/6.61 points**，相对标准 CoT latency **1.14–1.49×**。判断：以 prefill memory 换 decode token，适合低成本复现。

### Agent runtime、安全与记忆

- [ClawSentry](https://arxiv.org/abs/2608.21101) — cs.CR，cs.AI Cross，submitted 2026-08-21。四层覆盖技能首审、意图、执行效果和事后证据；SkillInject/Codex GPT-5.4 上 contextual ASR **39.55%→2.61%**，TSR **83.78%→83.05%**；五类 Work Agent 的 ASR 从 **33.5%–49.7%** 降至 **9.09%–15.03%**。判断：比静态 skill 扫描完整，最值得直接借鉴 session 级 anti-bypass。
- [Weighted Memory Tree](https://arxiv.org/abs/2608.20631) — cs.AI，submitted 2026-08-21。按 task/subtask/action 组织记忆，以事件和 selection-based decay 更新 retention；GAIA-Text 相对 linear memory 准确率 **+9.97pp**、prompt token **-32.8%**，并做 poisoning 实验。判断：记忆的核心是淘汰决策，不是无限追加。
- [CAS: Conformalized Agentic Search](https://arxiv.org/abs/2608.20771) — cs.AI，submitted 2026-08-21。检索侧用 APS 动态截断文档集，训练侧用 ACI 约束回答置信度并在 GRPO 中惩罚低置信轨迹。摘要只称提高准确率、减少工具调用，未给幅度。判断：组合有意思，但 coverage 在非交换、分布漂移 Agent 轨迹上是否成立要看证明与实验。
- [Tree-of-Concerns](https://arxiv.org/abs/2608.20777) — cs.CL，submitted 2026-08-21。五类 skeptic persona 并行 debate；ToC-Bench 含 **414 篇论文、1,905 条未声明局限**，相对最强 baseline precision **+79%**、coverage **+11%**。判断：可做 reviewer copilot；必须核相对提升口径与 reviewer 文本泄漏。

### 端侧、推荐与机器人

- [Bern2Edge](https://arxiv.org/abs/2608.20497) — cs.LG，submitted 2026-08-20。以 Bernstein polynomial activation 蒸馏 teacher；相对 W8A8 teacher，在 KV260 FPGA 上报告最高 **99.8% latency reduction、95.2% BRAM reduction**，准确率差 **0.5pp** 内。判断：训练到综合链路完整，但极大百分比必须核基线。
- [Dynamic Single-Level Large Semantic Codebook](https://arxiv.org/abs/2608.21012) — cs.IR，cs.LG Cross，submitted 2026-08-21。三种 serving 架构估算解码 FLOPs 降 **47.93%–48.70%**、单卡 QPS 升 **28.57%–47.0%**；5 天线上 A/B、2.5% 流量，主消费指标升 **0.792%**。判断：今天少数带线上证据的论文，优先看实验细节。
