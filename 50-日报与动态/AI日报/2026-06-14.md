# AI 日报 2026-06-14

## 🔴 TOP 1：美国商务部紧急下架 Anthropic Claude Fable 5 & Mythos 5

### 事件时间线
- **6月9日**：Anthropic 发布 Claude Fable 5（公众可用）+ Mythos 5（限 Project Glasswing 合作伙伴）
- **6月12日 17:21 ET**：美国商务部发出出口管制令，要求立即全球下架两模型
- **6月12-13日**：Anthropic 全球禁用两模型，所有用户（含付费 API）失去访问

### 技术背景
- **Mythos 5**：Anthropic 最强模型，擅长软件漏洞挖掘（披露称远超现有工具）
- **Fable 5**：Mythos 同架构 + 强制安全护栏（95%场景无触发，<5%回退 Opus 4.8）
- **定价**：$10/M input tokens, $50/M output（比 Mythos Preview 便宜 50%+）

### 触发原因（官方说法 vs 外界猜测）
#### Anthropic 声明
> "我们认为政府得知某种 jailbreak 方法可能绕过 Fable 5 安全护栏，但类似能力在多个公开模型中均存在。将此标准扩展到所有前沿模型，将彻底暂停商业前沿模型部署。"

#### 外界分析（TechCrunch / HN）
1. **自食其果论**：Anthropic 4月过度渲染 Mythos 危险性（Sam Altman 当时直斥 "fear-based marketing"），引起政府注意
2. **网络安全能力触线**：Mythos 在内部评估中展示 "读全量代码库 + 自主修复漏洞" 能力，可能跨越出口管制红线
3. **UK AISI 报告**：英国 AI 安全研究所在外部红队测试中确认一个潜在 jailbreak 路径（虽被限制，但足以触发行政动作）

### 影响范围
- ✅ **Claude Opus 4.8 / Sonnet 4.5 / Haiku 4**：全部正常服务
- ❌ **Fable 5 API (`claude-fable-5`)**：全球下线
- ❌ **Mythos 5**：原本仅限合作伙伴，现彻底停止
- ⏳ **Claude Corps 计划**（6月11日刚宣布的 $150M 公益计划，培训 1000 名 AI Fellows）：未受影响，继续招募

### 行业反响
| 阵营 | 观点 |
|------|------|
| **Anthropic** | "窄化 jailbreak 不应成为召回数亿人使用的商业模型的理由。我们与政府合作，尽快恢复访问。" |
| **OpenAI（隐喻）** | Sam Altman 4月已埋雷："这明显是营销手段——'我们造了颗炸弹，但我们不会公开，因为我们负责任'。" |
| **GitHub 社区** | HN 帖子 #48470581："前沿模型能力已公开，单独禁 Fable 是象征性政治动作，技术上无意义。" |
| **安全研究界** | "如果政府标准是'能挖洞就禁'，那 OpenAI o1 / Google Gemini 3.5 也该下架。真实红线在哪？" |

### 技术细节（Fable 5 架构）
```yaml
Safety System (三层):
  1. AI Safety Classifiers (独立检测模型)
    - 网络安全：漏洞利用 / offensive cyber / 横向移动侦察
    - 生化：基因编辑 / 病毒设计 / 合成生物学（承认过度宽泛）
    - Distillation：防止能力提取到未授权模型
    - 触发阈值：<5% sessions，回退 Opus 4.8
  2. Data Retention Policy
    - 30天留存（vs Opus 系列 zero-day）
  3. External Red Team
    - 1,000+ 小时外部赏金测试：零通用 jailbreak
    - UK AISI：发现 1 个潜在路径（已限制但未封死）
```

## 🌐 Google DeepMind：Gemini Omni Flash（多模态视频生成）

### 核心能力
- **任意输入 → 视频**：文本 / 图像 / 音频 / 视频混合输入，生成单一连贯视频
- **物理正确性**：内置重力 / 动能 / 流体力学理解，结合历史/科学知识生成场景
- **多轮对话编辑**：连续 prompt 叠加，保持角色一致性 + 场景连续性

### 可用性
| 渠道 | 状态 |
|------|------|
| Gemini app (AI Plus / Pro / Ultra) | ✅ 全球可用 |
| Google Flow | ✅ 全订阅层 |
| YouTube Shorts / YouTube Create | ✅ 本周推送，免费 |
| API (开发者 / 企业) | ⏳ 数周内 |

### 技术亮点
- **SynthID 水印**：所有 Omni 视频嵌入不可见水印（可通过 Gemini / Chrome / Search 验证）
- **Avatar 功能**：用自己声音生成视频（语音合成仍在测试，未全面开放）

### Demo 案例
- "Claymation explainer of protein folding, stop motion, accurate"
- "Dynamic sci-fi film style based on image_0.png, light sync to beat of audio_0.wav"
