### 2. Anthropic 发布 Claude Opus 4.8

**发布日期**：2026-05-28

**性能提升**：
- **诚实度与可靠性**：代码审查场景下允许缺陷通过的概率降低 4 倍（相比 Opus 4.7）
- **Agentic 判断**：在长期任务中主动提问、自我纠错、推后不稳健的计划
- **对齐水平**：亲社会特质达到新高，错位行为率大幅下降（接近 Claude Mythos Preview）

**性能基准**（早期测试数据）：
- **Super-Agent Benchmark**：唯一端到端完成所有案例的模型，成本持平时击败 GPT-5.5
- **CursorBench**：各难度级别全面超越此前 Opus 模型，工具调用效率提升（更少步骤达到同等智能）
- **Legal Agent Benchmark**：史上最高分，首个突破 10% 全通标准的模型
- **Online-Mind2Web**（计算机使用/浏览器代理）：84% 得分，显著高于 Opus 4.7 和 GPT-5.5

**新功能（同日上线）**：
1. **Dynamic Workflows（研究预览版）**：
   - 适用于 Claude Code 的 Enterprise / Team / Max 计划
   - 支持在单次会话中规划工作、运行数百个并行子代理，验证输出后再向用户报告
   - 案例：跨数十万行代码的代码库级迁移（从启动到合并）
   - Opus 4.8 延长了 agent 运行时限

2. **Effort Control（努力控制）**：
   - 出现在 claude.ai 和 Cowork 的模型选择器旁
   - **High effort（默认）**：更频繁、更深的思考，响应质量更高
   - **Lower effort**：更快响应，消耗更少 rate limit
   - 所有计划可用，默认高努力使用的 token 量与 Opus 4.7 默认相当，但性能更好

3. **Messages API 增强**：
   - 现在接受 messages 数组内的 system 条目
   - 允许在任务中更新 Claude 的指令而不破坏 prompt cache
   - 用例：在 agent 运行时更新权限、token 预算或环境上下文

**定价（保持不变）**：
- 常规模式：输入 $5 / 百万 token，输出 $25 / 百万 token
- Fast 模式：输入 $10 / 百万，输出 $50 / 百万（速度提升 2.5 倍，现比旧模型便宜 3 倍）

**API 调用**：`claude-opus-4-8`

**来源**：https://www.anthropic.com/news/claude-opus-4-8

### 3. Google I/O 2026：搜索全面升级为 AI 代理平台

**发布日期**：2026-05-19（Google I/O 大会）

**核心指标**：
- **AI Mode 月活**：突破 **10 亿用户**（上线仅一年）
- **查询增长**：自推出以来每季度翻倍
- **查询量**：上季度达历史新高

**主要更新**：

1. **Gemini 3.5 Flash 成为 AI Mode 全球默认模型**：
   - 定位：为代理和编码提供持续前沿性能
   - 全球所有用户即日起生效

2. **Intelligent Search Box（25 年来最大升级）**：
   - 动态扩展，给详细问题更多空间
   - AI 驱动的建议（超越传统自动完成）
   - **多模态输入**：文本、图像、文件、视频、Chrome 标签页
   - 保留传统搜索结果范围
   - 全球所有 AI Mode 国家/语言即日可用

3. **增强对话体验**：
   - 从 AI Overview 直接提出后续问题
   - AI Mode 内无缝对话流
   - 整个探索过程中保持上下文
   - 随探索深入逐步提升相关性
   - 今日全球桌面和移动端上线

**搜索代理（Search Agents）**：

**A. Information Agents（信息代理，24/7 后台监控）**：
- **能力**：智能推理网络信息（博客、新闻、社交帖子）+ 实时数据（金融、购物、体育）
- **用例**：
  - 租房搜索：持续扫描，满足条件时通知
  - 球鞋发售：喜爱的运动员宣布联名时即时提醒
  - 任何问题的自定义监控
- **上线时间**：2026 年夏季（Google AI Pro & Ultra 订阅者优先）

**B. Agentic Booking Capabilities（代理预订能力，扩展版）**：
- **新类别**：本地体验和服务
- **功能**：
  - 分享具体标准（如"周五晚上 6 人私人卡拉 OK 房间，提供深夜食物"）
  - 整合最新定价和可用性
  - 提供直接预订链接（通过用户选择的提供商）
  - **电话呼叫**：针对家庭维修、美容和宠物护理类别，Google 可代用户致电商家
- **上线地区**：美国，2026 年夏季

**C. Agentic Coding in Search（搜索中的代理编码）**：
- 基于 **Google Antigravity** + **Gemini 3.5 Flash**
- **Generative UI 能力**：
  - 为每个问题构建理想格式的响应
  - 实时创建自定义布局
  - 实时组装组件（交互式视觉、表格、图表、模拟、可视化工具）
- **示例**：
  - 天体物理学可视化
  - 交互式设备机械演示（如"你的手表如何工作"）
- **可用性**：2026 年夏季，对所有人免费

**D. Custom Dashboards & Task Trackers（自定义仪表板和任务跟踪器，"迷你应用"）**：
- **用途**：持续、重复性任务（婚礼策划、搬家、等）
- **示例：自定义健身跟踪器**：
  - 由 Search 为用户的特定健康例程构建
  - 访问新鲜、实时来源（评论、实时地图、本地天气数据）
  - 持久跟踪器用于持续进度
- **上线时间**：未来几个月，首先面向美国的 Google AI Pro 和 Ultra 订阅者

**扩展的个人智能（Personal Intelligence）**：
- **地理覆盖**：近 200 个国家和地区
- **语言支持**：98 种语言
- **费用**：无需订阅
- **可连接应用**：Gmail、Google Photos、Google Calendar（即将推出）
- **隐私与控制**：用户始终控制，明确选择加入应用连接

**核心理念**：
> "搜索的目标一直很简单：帮助你询问脑海中的任何问题 —— 从快速事实到深刻、复杂或高度具体的问题，这些问题可能难以表达。这代表了 Google 搜索的下一章：为你工作的智能 AI，利用世界信息。"

**来源**：https://blog.google/products-and-platforms/products/search/search-io-2026

### 4. Microsoft Build 2026：推出首批自研 AI 模型，减少对 OpenAI 依赖

**发布日期**：2026-06-02（Microsoft Build 开发者大会，旧金山）

**核心发布**：

**A. MAI-Code-1-Flash（微软首个 AI 编码模型）**：
- 将书面描述转换为应用和网站源代码
- 描述为"推理超高效"
- 通过以下渠道可用：
  - GitHub Copilot AI 编码服务
  - Visual Studio Code 文本编辑器
- 支持"vibe coding"（通过文本提示让开发者和非技术用户编写复杂软件）

**B. MAI-Thinking-1（推理模型）**：
- 定位："高效率和性能，但关键是低 token 成本"（Kyle Daigle，微软开发者营销主管）
- **Token 效率**：Token 是决定开发者成本的数据构建块
- **自定义能力**：结合客户特定数据时准确性提升
- **可用性**：通过 Microsoft Foundry 私有预览；客户可在 microsoft.ai 表达兴趣

**C. 更新的云端模型**：
- 语音识别
- 合成语音生成
- 图像生成

**D. 小型 Aion 模型**：
- 针对 Windows PC 优化运行

**战略转变**：
- 从"基础设施提供商"转向"AI 模型竞争者"
- 超越传统角色（Azure 云基础设施、第三方服务提供商 OpenAI/Anthropic API、股权投资者 $130 亿 OpenAI + $50 亿 Anthropic）
- **经济激励**：在 Azure 上运行自有模型消除向 OpenAI 等第三方支付，随着 AI 模型定价上涨降低开发者成本

**性能证据**：
- **关键基准**：为咨询公司麦肯锡定制后，微软模型超越 OpenAI GPT 5-5，**成本效率提升 10 倍**（CEO Mustafa Suleyman）

**CEO 战略声明**：
> "你刚才看到的是一个相当重大的转变。我们认为时代已到：每家公司都应从仅仅消费前沿模型转向完全参与前沿生态系统。"
> —— Satya Nadella，Microsoft CEO

**竞争格局**：
- **Google**：2026 年 5 月发布 Gemini 3.5 Flash（可在 Google 自有数据中心运行的编码模型）
- **Anthropic**：2026-06-01 机密提交 IPO 文件
- **OpenAI**：正在寻求 IPO，可能于 2026 年

**来源**：https://www.cnbc.com/2026/06/02/microsoft-unveils-new-ai-models-lessen-reliance-on-openai-lower-costs.html
