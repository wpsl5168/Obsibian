## 今日判断

OpenAI 今天最实质的动态不是模型，而是广告业务：上线不足 200 天，年化收入运行率已到 10 亿美元，覆盖 40 多国。ChatGPT 已经从订阅/API 产品变成广告平台；真正该盯的是“当前对话上下文”和可选的跨会话上下文如何参与定向，而不是公关稿里的“广告不影响答案”。

工程上更值得抄的是两条“少机制、多数据”：Memoryfield 用 Markdown 正文加可删除的 SQLite 向量索引表达 Agent 记忆；论文中的 agentic data cracking 只在首次读文档时顺手抽取后续可能复用的结构，而非预处理全库。两者都在反对把记忆/RAG 做成难审计的流水线。方向对，但记忆污染、版本和删除策略仍要单独设计。

系统论文里，跨模型 KV 翻译层最有想象力：若作者结果能复现，多模型级联不必反复 prefill 同一长上下文。不过跨 tokenizer、跨家族的误差与训练成本还没被生产负载验证，先看代码和复现，别按摘要改 serving 架构。

### Microsoft Research：把病理基础模型计算量压到 1/50

GigaPath-Flash 使用 22M 参数 ViT-S tile encoder 与 21M 参数 LongNet slide encoder。微软称其在 PANDA 与 EBRAINS slide-level benchmark 上，以约 **1/50 计算量**保留原 GigaPath **97%** 的预测性能。GigaTIME-Flash 约 **快 6×、少用 8× 内存**；按每张切片约 10,000 tiles 估算，单张 A100 处理 100 万张切片约需 70 GPU 天，原版约 300 GPU 天。两者均以 Apache 2.0 发布开放权重。

判断：这是今天最硬的模型工程更新。蒸馏小 backbone 加 LoRA 没有花活，直接解决病理全切片的成本墙；但官方明确未验证临床诊断、预后或治疗决策，不能把研究模型包装成医疗产品。

来源：[GigaPath-Flash and GigaTIME-Flash](https://www.microsoft.com/en-us/research/blog/gigapath-flash-and-gigatime-flash-toward-population-scale-discovery-with-efficient-pathology-foundation-models)（Published 2026-08-31）。

## arXiv

分类 `/new` 页面与 Export API 在采集时存在公告批次时差；以下只收 2026-08-31 实际提交、已由 API/abs 元数据发现的论文，不把它们冒充为 9 月 1 日 new 榜单。均为预印本，尚未同行评审；数字来自作者摘要，未独立复现。

### Agentic data cracking：只在需要时增量结构化文档

[Token-Efficient Data Reasoning Agents via Adaptive Structuring of Unstructured Data](https://arxiv.org/abs/2608.31082)（cs.AI/cs.CL/cs.DB，submitted 2026-08-31）。Agent 首次打开文档时派生低边际成本子 Agent，抽取可能服务后续查询的结构化知识，而非预先处理全部语料。作者称 FanOutQA 上理想结构化存储比重复读文档便宜 28×；每个测试问题只增加一个相关后续问题时，方法在保持准确率的同时降低 53% 成本。

判断：适合长期运行的企业文档 Agent，尤其是查询分布逐步显现的场景。风险是首次抽取错误会被长期复用，必须保留原文引用、版本和失效机制。

### 跨模型 KV 共享：给不同模型翻译上下文状态

[A Universal Context-Reuse Layer for Cross-Model KV Sharing](https://arxiv.org/abs/2608.30963)（cs.LG/cs.AI，submitted 2026-08-31）。方法把一个模型的 KV 状态翻译给不同规模、架构、tokenizer 甚至不同家族的模型。作者报告：Qwen2.5-7B→1.5B 时 LongBench2 从 27.59% 升至 34.48%；Qwen2.5-1.5B→Gemma-2-2B 在 4K context 下减少 67.05% target prefill；Llama-3.1-70B→Qwen2.5-7B 准确率 44.0%（原生 45.7%），延迟 899ms 降至 138ms。

判断：如果复现成立，能直接降低多模型 Agent 和级联推理重复 prefill 的浪费。论文摘要没有替生产回答翻译层训练成本、长上下文稳定性和并发服务复杂度。

### OPD 可能主要靠抑制尾部 token，而非教师知识

[Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement](https://arxiv.org/abs/2608.31046)（cs.LG/cs.CL，submitted 2026-08-31）。作者认为 on-policy distillation 的 teacher signal 含大量噪声，提出无需 teacher 的 OPSA，按熵分配负 advantage、抑制尾部 token。Qwen3-1.7B 在 AIME24 Avg@32 提升 35.41 分，相对提升 263%；比 OPD 高 16.77 分。

判断：若复现，会影响蒸馏/RLVR 的成本结构。现在只是单篇预印本和作者 benchmark，不能据此删掉 teacher pipeline。

### PaperGym：用 rubric 降低研究计划数据泄漏

[PaperGym: Rubric-Centered Evolution for Research-Plan Generation](https://arxiv.org/abs/2608.31119)（cs.CL，submitted 2026-08-31）。从论文研究目标生成问题、从方法和实验生成 rubric，以避免同一段文字同时生成问题和评分标准。作者称 criterion leakage 为 3.7%，对比既有数据集 11.90%–34.10%；Qwen3-1.7B/4B/8B 在五项 benchmark 平均提升 5.6/5.0/4.8 分。

判断：rubric 与问题分源生成值得借鉴；模型参与生成与评分仍可能共享偏差，关键要看人工抽检和跨模型 judge。

## 工程清单

- ChatGPT Ads 进入企业风险评估：确认对话上下文是否参与广告个性化、关闭入口、地区差异、数据保留和审计证据。
- Agent 记忆优先采用可读原文、稳定引用和可重建索引；向量库只是 cache，不应成为唯一事实存储。
- 文档 Agent 做增量结构化时，必须记录 source span、版本和 TTL；错误派生数据要能追溯与批量失效。
- 跨模型 KV 共享先做固定模型对的离线 PoC，测准确率、prefill、训练成本、长上下文漂移，再考虑接入 serving。
