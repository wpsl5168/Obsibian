### 2. Anthropic Claude Sonnet 5 发布 + Fable 5/Mythos 5 解除出口管制
**发生了什么**:
- 6月30日发布 Claude Sonnet 5，性能接近 Opus 4.8，但价格更低
- 6月30日美国商务部解除 Claude Fable 5 / Mythos 5 出口管制，7月1日全球恢复访问
- 6月30日发布 Claude Science（科学家定制化 AI 工作台）
- 6月23日发布 Claude Tag（团队协作新方式）

**技术细节**:
- **Claude Sonnet 5**:
  - 上下文窗口：1M tokens
  - 最大输出：128K tokens
  - **Breaking Changes**: 不再支持 `temperature` / `top_p` / `top_k` 采样参数
  - 新 tokenizer 导致 token 数量增加 ~30%，实际成本变化：
    - 英文文本：~1.4倍
    - 西班牙语：~1.33倍
    - Python 代码：~1.27倍
    - 中文：~1.01倍（几乎无变化）
  - 默认启用 Adaptive Thinking（可关闭）

- **Claude Science**:
  - 集成科研常用工具和包
  - 生成可审计的 artifacts
  - 灵活访问计算资源

**政策与伙伴**:
- **Jailbreak 框架**: Anthropic 与 Amazon, Microsoft, Google, Glasswing 提出行业通用的 jailbreak 严重度评分框架
- **AI 指数级增长政策**: 6月10日发布政策提案，核心观点"AI 以指数级速度发展，而政策制定流程为慢速世界设计"
- 战略伙伴：TCS（监管行业）、DXC（银行/航空系统集成）、首尔办公室开设+韩国生态合作

**已知问题**:
- **工具调用退化**: 社区反馈 Opus 4.8 / Sonnet 5 生成畸形工具调用的概率高于旧模型
- 理论：Claude Code 训练数据中的专有编辑工具导致模型在其他环境（如 Pi）中误用类似工具

**影响与关注点**:
- Simon Willison 用 Claude Fable 完成 sqlite-utils 4.0rc2，成本 ~$149.25
- 成本优化技巧：让 Fable 自主决策，将具体编码任务委托给低功耗模型（sonnet/haiku）
- Fable 会保存决策记录到 memory 文件，供未来会话参考

**来源**:
- https://www.anthropic.com/news
- https://simonwillison.net

## 工具与项目

### Simon Willison 最新开源
1. **llm-coding-agent 0.1a0**:
   - Claude Code 风格的 Python 编码 agent 库
   - 基于 LLM 框架
   - 提供 6 个核心工具：edit_file, execute_command, list_files, read_file, search_files, write_file
   - 命令行用法: `uvx --prerelease=allow --with llm-coding-agent llm code`
   - Python API: `CodingAgent(model="gpt-5.5", root="/path", approve=True).run("Fix the failing test")`

2. **sqlite-utils 4.0rc2**:
   - 主要由 Claude Fable 编写，成本 $149.25
   - 保持 SemVer 兼容性达到稳定 4.0
   - GitHub: https://github.com/simonw/sqlite-utils/releases/tag/4.0rc2

3. **DSPy for Datasette Agent 评估**:
   - 使用 Stanford DSPy 框架评估 Datasette Agent 的 SQL 系统提示词
   - 发现问题：schema 列表仅显示表名，导致模型猜测列名并陷入错误循环
   - 建议：在 schema 列表中包含列名，或软化"避免 describe_table"的建议

### 有趣技术
**500 字节 ASCII 世界地图** (Iwo Kadziela):
- 使用 445 字节 deflate 压缩数据
- 利用 `fetch()` + `data:` URI + `DecompressionStream` API 在浏览器中解压
```javascript
fetch('data:;base64,1ZpLsgIxCEXnrM...==')
  .then(r => r.body.pipeThrough(new DecompressionStream('deflate-raw')))
  .then(s => new Response(s).text())
  .then(t => b.innerHTML = '<pre>' + t)
```
