## 顶级博主

### Simon Willison：Qwen 3.8 27B 能干活，但默认推理档位选错了

Simon 在 128GB M5 Max MacBook Pro 和 NVIDIA DGX Spark 上测试 Apache 2.0 的 Qwen 3.8 27B，使用 17GB Q4_K_M 量化版。

- 默认 `xhigh` 推理生成一个 SVG：21 分钟，22,276 reasoning tokens，最终输出 3,223 tokens。
- 关闭推理后，同一提示耗时 137 秒，输出 3,715 tokens，但图像质量下降。
- LM Studio 默认 8,192 context 不够它“想”；改为完整 262,144 context 后才避免耗尽。
- Simon 的本地速度约 15–30 token/s；在 llama.cpp 开启 MTP 后，基准速度比 LM Studio 默认 GGUF 高约 72%。
- 模型还能用 Pi 分析代码库，并生成、测试 JSONL 转 Markdown 工具。

判断：27B 本地模型的能力已跨过“玩具线”，但 `xhigh` 不该做默认值。生产路由应按任务难度设置 reasoning effort，并设 token/time ceiling；否则 20 分钟推理只是浪费，不是更聪明。

原文：[Qwen 3.8 27B is excellent, but it defaults to wildly overthinking things](https://simonwillison.net/2026/Aug/16/qwen-38-27b/)（正文 2026-08-16；Atom 折算北京时间 8 月 17 日 06:00）

### Simon Willison：浏览器内把动画 SVG 转 MP4

`markdown-svg-renderer` 可把 Markdown 内的 SVG 渲染并导出 PNG、JPEG；新增 MP4 标签会加载 30MB 以上 `ffmpeg.wasm`，在浏览器逐帧编译动画 SVG。对分享模型生成的 SVG 和推理记录有用，但 AI 信息密度一般。

## arXiv：8 月 17 日 new listings

以下均为预印本，主要收录有具体数字、可迁移方法或直接反驳工程直觉的论文。

### 1. Twin：测试时先造一个可执行数字孪生

[Twin: Playing an Unknown Game with a Test-Time Digital Twin](https://arxiv.org/abs/2608.14490v1)（cs.AI，v1 提交 2026-08-14）

- 完成 179/183 个关卡（97.8%），158/179（88.3%）比人类更高效。
- 相同基础模型直接运行得分 7.8%，通用 harness 61.1%，Twin 93.3%。

判断：测试时让 coding agent 编写、回放、修复可执行环境模型，比单纯延长 CoT 更像可靠的长程规划。对游戏 Agent、机器人仿真和故障回滚都有迁移价值。

### 2. LSP 不一定替 coding agent 省 token

[Does a Language Server Save Tokens for Coding Agents?](https://arxiv.org/abs/2608.13568v1)（cs.CL/cs.AI；进入 8 月 17 日 new list，官方 abs 显示更早提交）

- 符号定位任务中，LSP 反而多耗 6%–118% tokens。
- 模型自由选择时，定位任务仅 0%–6% 使用语义工具。
- grep 完成全部多文件重命名；只返回位置的 LSP 漏掉调用点，失败 3/4。

判断：别把“语义工具更高级”当成默认路由。定义/引用查找用 LSP；注释、字符串、模糊定位和全局替换继续保留 grep。样本仍小，不能把结论外推到所有语言和仓库。

### 3. Intern-S2-Mobius：拆开知识与推理

[Intern-S2-Mobius: Foundation Model with Decoupled Knowledge and Reasoning](https://arxiv.org/abs/2608.14290v1)（cs.AI，v1 提交 2026-08-14）

7B 从零训练模型用 Transformer 基线 62.6% 的训练数据取得相近下游结果；基于 Qwen3.5-35B 继续预训练的版本，在相近分数下接近 4× 端到端推理加速。摘要未给完整逐项基准和吞吐口径，先看复现，别急着押架构。

### 4. ScienceFlow：长程研究 Agent 要可恢复状态

[ScienceFlow](https://arxiv.org/abs/2608.14354v1)（cs.AI，v1 提交 2026-08-14）

完整 MLE-bench、24 小时预算下 Any-Medal 70.22%，比此前报告高 4.92 个百分点。工程价值在可恢复执行状态、失败分支回滚、按证据分配计算资源；需要继续核对模型与算力成本是否公平。

### 5. 路由要算重试后的真实 token 成本

[Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems](https://arxiv.org/abs/2608.13571v1)（cs.CL/cs.AI；进入 8 月 17 日 new list，官方 API 显示更早提交）

- 7B 模型多跳问答工作流 token 膨胀最高 4.25×；CBE 预测高膨胀的 AUROC 为 0.887。
- GSM8K 固定预算下准确率 94.7%，FrugalGPT 为 91.0%，同时少用 31% tokens。
- 把失败 CoT 交给 GPT-4o，准确率最多下降 34.8 个百分点。

判断：模型路由应优化任务完成总成本，而非单次调用价格；失败后重新生成，别把污染推理链继续传下去。

### 6. 推理与训练基础设施速览

- [Batch-wise Adaptive Pruning](https://arxiv.org/abs/2608.14003v1) — DeepSeek-R1-Distill-Qwen-7B、batch 4、50% 稀疏度下，比此前自适应剪枝平均准确率高 39.7 个百分点；相对稠密推理 1.40×。
- [SimpleOPD](https://arxiv.org/abs/2608.14277v1) — tokenizer-agnostic on-policy distillation；Intern-S2-Preview 在 ProofBench 提高 21.2 分至 55.2。跨模型族有效，但仍待独立复现。
- [KV Cache Compression Through the Lens of Transform Coding](https://arxiv.org/abs/2608.14191v1) — 在 Llama-3.1-8B、Qwen2.5-7B 及多组长上下文/推理基准上，约 5.8× KV cache 压缩且近乎无损；真实 kernel 吞吐与元数据成本尚未给出。
- [QUASAR](https://arxiv.org/abs/2608.13966v1) — Qwen3、Llama-3.1 的 3/4-bit QAT held-out KL 至少下降 10%，2-bit 下降 29%；2-bit 八项任务平均准确率高 3.5–4.3 个百分点。
- [Rollplex](https://arxiv.org/abs/2608.14498v1) — 32 张 H800 上，VLM post-training 相对 colocated runtime 加速 1.23×–1.30×，相对 disaggregated runtime 1.57×–2.24×。
