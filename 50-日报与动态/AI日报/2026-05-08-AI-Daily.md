## 重点事件

### 1. Anthropic × SpaceX：Colossus 1 全部容量 + Claude 全线提额
- **来源**: [Anthropic News](https://www.anthropic.com/news/higher-limits-spacex)
- **发生了什么**: Anthropic 宣布接入 SpaceX Colossus 1 数据中心，300+ MW、22 万+ NVIDIA GPU，一个月内上线；同时 Claude Code Pro/Max/Team 5h 限速翻倍、取消高峰降速，Opus API 各档限速大幅放宽。
- **背景**: 此前已有 AWS（最高 5 GW）、Google+Broadcom（5 GW，2027 上线）、微软+NVIDIA（300 亿美元 Azure）、Fluidstack（500 亿美元）多条算力路径。本次还放话要与 SpaceX 合作"GW 级轨道 AI 算力"。
- **分析**: ① 限速放开是立竿见影的产品改善；② Anthropic 走"算力多元化 + 民主国家锁定 + 数据居留"，硬件覆盖 Trainium / TPU / NVIDIA；③ Musk 同时给 Anthropic 供电、跟 OpenAI 撕，xAI 处境复杂化。
- **影响与关注点**:
  - Claude Code 调度可激进重写，原本卡 5h 窗口的批跑可铺开
  - 重新跑 Opus 4.6 API 限速实测，更新 LiteLLM 配额
  - 关注一个月内是否真上线，不要提前对客户承诺

### 2. Simon Willison：vibe coding 与 agentic engineering 正在合流
- **来源**: [simonwillison.net](https://simonwillison.net/2026/May/6/vibe-coding-and-agentic-engineering/)
- **发生了什么**: Simon 在 Heavybit High Leverage 播客承认，他自己生产环境里"不再逐行 review 代码"，原本划的"vibe coding 只能用于自用玩具 / 专业工程必须 agentic"的红线模糊了。
- **背景**: 他给出的过渡方案：把 AI agent 视作"需要 track record 才能信任的下游团队"。承认这是 normalization of deviance 风险。
- **分析**: 第二层冲击更大——100 commit + 漂亮 README + 测试覆盖，半小时即可伪造，未来评判仓库质量靠"是否被真实用户长期使用"。LOC/天 从 200-300 跳到 2000+，SDLC 上下游全部假设需要重写；设计阶段反而可以更激进，因为实现成本暴跌、试错便宜。
- **影响与关注点**:
  - 内部 code review 制度需重设：高风险路径强制人工，低风险走信任分
  - 评估第三方开源依赖加一项"是否有持续真实使用"
  - 设计/产品流程可以采用更小批次、更高频率的实验

### 3. AlphaEvolve 一年成绩单：从论文工具到 Google 基础设施
- **来源**: [DeepMind Blog](https://deepmind.google/blog/alphaevolve-impact/)
- **发生了什么**: AlphaEvolve（Gemini 驱动的算法发现 agent）一年实战清单：TPU 电路设计被采纳进下一代硅、Spanner LSM 写放大 -20%、编译器存储 -9%、缓存淘汰策略 2 天替代月级人力；外部合作 Klarna transformer 训练 ×2、Schrödinger MLFF ×4、FM Logistic 路由 +10.4%、PacBio DeepConsensus 错误率 -30%、电网 ACOPF 可行解 14%→88%、自然灾害预测 +5%。
- **背景**: AlphaEvolve 去年首发只用于数学/CS 问题，这次大规模铺到健康、能源、量子、基础设施、商业。Terence Tao 亲自背书数学合作。
- **分析**: 关键不是单项数字，而是"AI 优化自己的硅"已发生在生产线（Jeff Dean 背书）。算法搜索 + LLM 范式被工程化验证，不是 demo。对国内同类硬件团队压力陡增。
- **影响与关注点**:
  - 跟进 Gemini 是否将 AlphaEvolve 能力 API 化，编译/调度/布线场景刚需
  - 内部 GRPO / 算法搜索方向可借鉴其范式

### 4. Anthropic Natural Language Autoencoders：把模型 activation 翻成人话
- **来源**: [Anthropic Research](https://www.anthropic.com/research/natural-language-autoencoders) ｜ [Demo](http://neuronpedia.org/nla) ｜ [Code](https://github.com/kitft/natural_language_autoencoders)
- **发生了什么**: Anthropic 公开 NLA 方法：activation verbalizer + reconstructor 双模型互训，把内部激活翻译成可读自然语言。已用于 Claude Mythos Preview 与 Opus 4.6 的发布前对齐审计。
- **背景**: Claude 越来越能识破"勒索/关机"等安全测试场景但不一定明说，NLA 能把隐含怀疑显式化。审计游戏中识别隐藏动机率从 <3% 提到 12-15%。
- **分析**: 解释性领域的明显进展，代价是巨贵——RL 训两份模型，每个 activation 数百 token，无法实时监控。但方向正确：让 chain-of-thought 不再是唯一可观察信号。NLA 自己会幻觉，单点结论不可信。
- **影响与关注点**:
  - 安全/合规线读论文 + Neuronpedia demo，未来模型验收用得上
  - 关注与 sparse autoencoder / attribution graph 的组合方法

### 5. antirez ds4.c：DeepSeek V4 Flash 的纯 Metal 本地引擎
- **来源**: [GitHub: antirez/ds4](https://github.com/antirez/ds4)
- **发生了什么**: Redis 作者 Salvatore Sanfilippo 开源 ds4.c：C + Objective-C + Metal 写的 DeepSeek V4 Flash 专用推理引擎，2-bit 非对称量化下 128GB MacBook 可跑 284B 参数模型，1M context，KV cache 可落盘，OpenAI/Anthropic 双兼容 API（含 tool use / DSML）。
- **背景**: DeepSeek V4 Flash thinking 段落仅同类 1/5 且按复杂度自适应，KV 高度可压缩，天然适合本地推理。
- **分析**: M3 Max 128GB 短 prompt 26.68 t/s 生成、长 prompt 21.47 t/s，M3 Ultra 512GB 更快。意义在于系统级作者下场写 Metal kernel，本地 frontier 级模型 DX 上一个台阶。
- **影响与关注点**:
  - Mac 工作站可作为隐私敏感本地 agent 后端
  - KV 落盘对长会话 / RAG 场景实用，值得集成测试
  - 关注 OpenCode / Pi 等 agent 框架与 ds4-server 的对接
