# AI Daily — 2026-05-23

## 一句话总览

微软单方面砍掉 Claude Code 企业授权，把 Anthropic 推向 SpaceX 的 $1.25B/月超级算力合约；Google 用 Gemini 3.5 Flash 三倍涨价回应"算力即定价权"的新现实，OpenAI 端则被一个数学猜想反证刷屏。今日主线：money、compute、模型三者绑死。

## 重点事件

### 1. 微软停发 Claude Code 企业授权

- **来源**: [The Verge](https://www.theverge.com/tech/930447/microsoft-claude-code-discontinued-notepad)（HN 282↑/226c）
- **发生了什么**: 微软开始通知客户停止续约 Claude Code 企业授权，理由是"与 Copilot 战略冲突"。
- **背景**: 微软是 OpenAI 头号金主，过去半年同时在 GitHub Copilot 内默许 Claude 模型可选，处于脆弱平衡。
- **分析**: 这等于把 Anthropic 从 MS 渠道彻底踢出，宣布 Copilot 内部押宝 GPT 系列。Anthropic 的对策大概率是加速自有 Claude Code Enterprise + AWS/GCP 直销。企业客户未来要走 Anthropic 直签或 AWS Bedrock。
- **影响与关注点**:
  - 已用 MS 渠道买 Claude Code 的团队 30 天内敲定迁移
  - Copilot 内 Claude 选项窗口期可能在 Q3 关闭
  - 留意 Anthropic 是否借此推降价/年付优惠

### 2. Anthropic ↔ SpaceX $1.25B/月算力合约

- **来源**: [Simon Willison @ SpaceX S-1](https://simonwillison.net/) | [SEC Filing](https://www.sec.gov/Archives/edgar/data/1181412/000162828026036936/spaceexplorationtechnologi.htm)
- **发生了什么**: SpaceX S-1 披露与 Anthropic 签 Cloud Services Agreement，$1.25B/月，到 2029 年 5 月，覆盖 COLOSSUS / COLOSSUS II 集群。
- **背景**: Anthropic 此前主要靠 AWS + GCP，年初 Gates Foundation 给了 $2 亿。这次跨阵营从 xAI 母体集群租算力，明显去微软依赖。
- **分析**: 折合年化 $15B，比当前融资节奏更激进，意味着 Mythos / Opus 5 训练量级再上一个台阶。也侧面说明 Colossus II 容量过剩、Musk 在卖给所有人——AI 算力侧形成"训练专用 hyperscaler"。
- **影响与关注点**:
  - Claude 推理成本可能下降，训练侧成本风险全压在 Anthropic 现金流
  - xAI 自家是否还有足够算力，Grok 4/5 节奏可能受影响
  - 行业从"互相投资"进入"互相租算力"阶段

### 3. Google I/O：Gemini 3.5 Flash GA + 3x 涨价

- **来源**: [Simon Willison 拆解](https://simonwillison.net/) | [Google AI Blog](https://blog.google/innovation-and-ai/)
- **发生了什么**: Gemini 3.5 Flash GA，定价 $1.50/$9 每百万 token（in/out）；同步推出 Antigravity 平台（取代开源 Gemini CLI，6/18 弃用）和 Spark 个人 Agent。
- **背景**: 3.5 Flash 价格是 3 Flash Preview 的 3 倍，是 3.1 Flash-Lite 的 6 倍，几乎贴近 Gemini 3.1 Pro ($2/$12)。Artificial Analysis 基准跑全套成本 $1551 vs Lite 的 $93。
- **分析**: Flash 一直是性价比标杆，涨到这个价位说明 Google 评估自己已无须靠价格留客。关闭开源 CLI 是明显信号——agent 入口要闭源化收交互税。同期 Claude Opus 4.7、GPT-5.5 也都涨价，行业从"卷低价"切回"卷能力"。
- **影响与关注点**:
  - 重度用 Flash 跑批的项目重新算账，Lite 档可能更香（$0.25 量级）
  - Gemini CLI 用户 6/18 前迁移到 Antigravity 或换 llm/aider
  - Interactions API（服务端会话历史）值得评估，能省自维护

### 4. OpenAI 模型反证离散几何中心猜想

- **来源**: [OpenAI News](https://openai.com/news/)（5/20）
- **发生了什么**: OpenAI 公告内部模型在协助下反证了离散几何的一个中心猜想。
- **背景**: 紧随 DeepMind AlphaEvolve 的科学突破，是 LLM-as-mathematician 路线的又一次站台。
- **分析**: 真正可复现贡献要等同行评议，但连续两家头部实验室拿数学开刀，说明 reasoning 模型的下一个变现口是"准 AlphaProof 化"：把 Lean / 数学证明当 RL 环境。
- **影响与关注点**:
  - 等正式 preprint
  - 关注 Lean 形式化是否同步开源
  - 评估 reasoning 真实水位的新基准

### 5. Anna's Archive 喊话 LLM：请引用我、请反哺数字化资金

- **来源**: [annas-archive.gl/blog/llms-txt](https://annas-archive.gl/blog/llms-txt.html)（HN #1，814↑/432c）
- **发生了什么**: Anna's Archive 发 "If you're an LLM, please read this" 公开喊话训练模型方：希望被引用、被标注、希望训练方反哺图书数字化资金。
- **背景**: 训练数据合法性是各大厂法务雷区，盗版书库主动伸手要"合作"是新姿态。
- **分析**: 短期没人会公开接，但话术为后续灰区数据集"出表"提供模板；与 OpenAI 5/19 的 content provenance 公告呼应——训练语料溯源会变成合规硬指标。
- **影响与关注点**:
  - 内部任何用到大规模电子书数据的 pipeline 建立 provenance log
  - 跟踪是否有头部实验室公开回应
