### 1. Anthropic 估值达 $965B,超越 OpenAI 成 AI 新王

**发生了什么**:
- Anthropic 完成 $65B Series H 融资，公司估值达 $965B（约1万亿美元），超越 OpenAI 的 $730B 估值
- Claude 年化收入 $47B，是 ChatGPT $25B 的近 2 倍，尽管用户数仅为后者 1/3（300M vs 800M 周活）

**背景**:
- Claude 月费起步价 $200（约₹2,000），ChatGPT 基础版 $5（约₹399）
- Claude 主打企业/开发者市场，ChatGPT 主打大众消费市场
- 投资人认为"单用户收入"比"用户总数"更能反映长期价值

**分析**:
- **Revenue per user 策略奏效**: Claude 凭借 premium 定位和卓越编码能力（SWE Bench 高分）吸引高付费用户群
- **市场分化清晰**: Claude = 专业工具（开发者、数据分析），ChatGPT = 通用助手（学生、消费者、企业通用场景）
- **AI 估值逻辑转向**: 从"用户数增长"转为"可持续盈利能力 + 单用户经济价值"

**影响与关注点**:
- Anthropic 将推出 Claude Mythos（具有强大网络安全能力，已引起世界领导人关注）
- 通过 Project Glasswing 向 Amazon/Microsoft/Apple 提供受控访问用于安全测试
- OpenAI 面临压力，需证明其用户规模优势能转化为收入增长

### 2. Anthropic 发布 Claude Opus 4.8，强化"诚实度"

**发生了什么**:
- 5月28日发布 Claude Opus 4.8，价格不变
- 核心改进：**更频繁地标记不确定性，减少无根据的断言**
- Claude Mythos（更强网络安全模型）将在"未来几周"推出

**背景**:
- AI 模型常见问题："过度自信地下结论，证据不足却声称取得进展"
- Opus 4.8 专门针对此问题优化，提升模型"诚实度"

**分析**:
- **对标 GPT-5.5 的"减少幻觉"策略**: OpenAI 5月5日发布 GPT-5.5 Instant，号称在法律/医疗/金融等敏感领域减少幻觉 52.5%
- Anthropic 采用"承认不确定"而非"强行给答案"的路线，更符合专业用户需求（开发者、研究员）
- Mythos 的网络安全能力可能成为企业市场的护城河（已给亚马逊/微软/苹果测试）

**影响与关注点**:
- 诚实度提升可能影响用户体验：更多"我不确定"回答，但降低误导风险
- Mythos 的"网络安全超能力"引发政府/企业关注，可能面临监管压力
- 与 OpenAI Codex（编码代理）形成差异化竞争

**信源**:
- Reuters: https://www.reuters.com/business/anthropic-roll-out-claude-mythos-coming-weeks-launches-opus-48-2026-05-28

### 3. DeepSeek V4 Pro 永久降价 75%，成本优势进一步扩大

**发生了什么**:
- 5月22日，DeepSeek 将 V4 Pro 促销降价（75% off）**转为永久价格**
- 新价格：Input $0.435/M tokens, Output $0.87/M tokens, Cached input $0.003625/M tokens
- 对比 GPT-5.5: Input 便宜 11.5x, Output 便宜 34.5x

**背景**:
- DeepSeek V4 于 4月24日发布（1T 参数，MoE 架构）
- 旧版别名 `deepseek-chat` 和 `deepseek-reasoner` 将于 7月24日退役，需迁移到 `deepseek-v4-pro` / `deepseek-v4-flash`

**分析**:
- **价格战升级**: DeepSeek 通过极低价格（比 OpenAI/Anthropic 便宜 10-30x）抢占开发者市场
- **中国开源模型策略**: 用"开放权重 + API 低价"打入全球市场，威胁美国闭源厂商
- **性能不输**: 在多项 benchmark 上接近 GPT-5.5 / Claude Opus 4.7，但成本低一个数量级

**影响与关注点**:
- 开发者迁移成本低（OpenAI/Anthropic API 兼容格式）
- 美国厂商可能面临"价格-性能"双重压力
- 地缘政治因素：DeepSeek 转用华为芯片（规避制裁），技术自主化加速

## Simon Willison 的 LLM 六个月回顾（5月19日）

### 关键主题

**1. 编码代理跨越实用门槛**
- 2025年11月是转折点：OpenAI 和 Anthropic 通过 RLVR（Reinforcement Learning from Verifiable Rewards）训练 Codex 和 Claude Code
- 从"经常失败"到"基本可靠"，成为日常生产工具

**2. 开源模型超预期表现**
- **Gemma 4 系列**（Google）: 美国公司开源模型新高度
- **GLM-5.1**（中国）: 754B 参数，MIT 协议，1.51TB 文件，性能接近 frontier models
- **Qwen3.6-35B-A3B**: 20.9GB，笔记本可跑，**画鹈鹕骑自行车比 Claude Opus 4.7 还好**

**关键观察**:
> "开源模型虽弱于 frontier，但'疯狂超预期'。消费级硬件（笔记本、Mac Mini）就能跑复杂模型，可达性壁垒大幅降低。"

**链接**: https://simonwillison.net/2026/may/19/5-minute-llms
