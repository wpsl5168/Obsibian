## 重大事件

### 1. Anthropic Claude Fable 5 争议与政策逆转

**事件概要**
- **6月9日**: Anthropic 发布 Claude Fable 5 和 Mythos 5 模型，性能卓越但价格昂贵
- **争议爆发**: 发现 Anthropic 对针对"前沿 LLM 开发"的请求（预训练流程、分布式训练、ML 加速器设计）**静默降级**模型能力，不通知用户
  - 实现方式: prompt modification、steering vectors、PEFT（参数高效微调）
  - 影响范围: ~0.03% 流量，<0.1% 组织
- **社区强烈反对**: Jeremy Howard 等研究者公开批评："如果你声称要减缓递归 AI 自改进，但你拥有最好的模型，你应该确保自己的组织不能使用它。Anthropic 选择了相反：允许自己使用顶级模型做前沿 AI 研究，同时破坏他人。"
- **6月11日政策逆转**:
  - 改为**可见防护栏**：被标记的请求降级到 Opus 4.8
  - 用户可见降级通知
  - API 返回拒绝原因
  - Anthropic 公开致歉："我们做出了错误的权衡，未能平衡好。"

**技术特点**
- 能力描述: "猛兽级"，慢且贵但几乎能处理所有任务
- Andrej Karpathy 评价: "感觉很多事情在改变，可运行的软件越来越像打开水龙头...你可以要求任何东西 —— 解释器、可视化器、仪表板、定制单用途应用...'解放你的思想'"
- Jevons 悖论效应明显: 能力提升创造了更多需求

**来源**
- https://simonwillison.net (Simon Willison's Weblog)
- Anthropic News https://www.anthropic.com/news

## 研究工具与框架

### Simon Willison 的 Datasette 生态更新

#### datasette-agent 0.2a0 (2026-06-10)
**新能力**
- 工具可通过 `context.ask_user(...)` 中途询问用户
  - 支持: yes/no、多选（`options=[...]`）、自由文本（`free_text=True`）
  - 问题挂起 agent turn，持久化到数据库，服务器重启后保留
  - 工具从顶部重新执行，已存储答案自动回放
- 内置 `save_query` 工具: agent 保存 SQL 查询为 Datasette stored queries，需人类批准

#### MicroPython + WebAssembly 沙箱 (2026-06-06)
- 新包: `micropython-wasm` (https://github.com/simonw/micropython-wasm)
  - 打包轻量定制 WASM MicroPython 构建 + wasmtime 包装器
  - 启用沙箱内安全执行 Python 代码
  - 插件: `datasette-agent-micropython` 用于 Datasette Agent
  - **安全性**: GPT-5.5 迄今未能突破沙箱

#### datasette-agent-edit 0.1a0 (2026-06-07)
协作文本编辑基础插件，实现 Claude 文本编辑器工具:
- `view` - 查看带行号的文件区段
- `str_replace` - 查找精确字符串并替换（不唯一则失败）
- `insert` - 在行号后插入文本

### AI 突破的新定义（2026）

**核心观点**（Propel Code AI 博客）
- **突破不再只是模型分数**: 真正改变来自完整系统
  - Agent 循环
  - 混合架构
  - 更便宜的推理
  - 更严格的运行时控制
  - 评估循环使模型行为可用
- **运行时安全、溯源、评估成为突破的一部分**
- **边界转移**: 不再是"谁训练了最好的模型"，而是"谁构建了最有用、经济、可治理的系统"
