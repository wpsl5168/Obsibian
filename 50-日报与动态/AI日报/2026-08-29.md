## 今日判断

今天没有通用模型代际跃迁，真正值得看的有三件事。

第一，OpenAI 因 Cursor 被 SpaceX 收购而准备在 11 月 12 日停止供模，说明模型供应商的 ToS 和控制权变更条款已经是开发工具的生产依赖。把单一闭源模型绑死在 IDE 里，不只是价格风险，也是供应链风险。

第二，Agent 正在把漏洞披露窗口压到分钟级。cohttp 修复 PR 公开约 10 分钟后就出现同类探测；这不能证明探测一定由 AI 发起，但公开 issue、修复 commit 和 CVE 描述已足够让现代 coding agent 快速生成利用。传统“公开讨论、几天后发版”的开源协作节奏需要重做。

第三，Agent 工程继续从“更长上下文”转向显式状态与权限边界。Lemmalog 用 Datalog 维护事实、撤回、来源和时间有效期；SARA 把工具输出诱导出的动作与运行时授权拆开；AgentJudgeBench 则证明，大模型 judge 在困难 DAG 工作流上仍有 77%–82% 的结构性天花板。模型不该同时兼任记忆数据库、授权器和最终裁判。

### Simon Willison：漏洞只剩传闻，Agent 也能把利用找出来

Simon 转述 OCaml 核心维护者 Anil Madhavapeddy 的现场记录：cohttp 6.3.0 的路径穿越问题在公共 PR 讨论后，约 10 分钟内服务器就收到 percent-encoded traversal 探测。Anil 称自己的 Agent 约 1 分钟生成本地利用；Claude Fable 拒绝后，DeepSeek V4 Pro 又找到相关问题。

Simon 引用的 HN 讨论还给出 rclone 维护现场：项目前 10 年约 20 次安全披露，最近一个月超过 40 次，约 75% 确有需要处理的问题；GitHub 分配 CVE 从 2–3 天拖到 3–4 周。

判断：日志无法证明探测来源就是 AI，个别项目也不能外推全行业；但攻击者已不再需要等待完整 PoC。修复应先在私有环境完成，自动化构建、发布、WAF/虚拟补丁和依赖升级链必须压缩到小时级，不能把“尚无公开利用”当缓冲区。

## arXiv

2026-08-29 为周六，`/new` 页面仍是 **Friday, 28 August 2026**。primary new submissions：cs.AI 96、cs.CL 118、cs.LG 77，三类合并去重 291 篇。下列数字均来自摘要，未独立复现。

### Agent 评测、安全与状态

- [AgentJudgeBench](https://arxiv.org/abs/2608.26623) — cs.AI，提交 2026-08-27。3,808 实例、6 种 DAG、3 难度、5 generators、6 judges；无 ground truth 时 judge alignment 随难度下降快 1.5×，困难题集中在 77%–82%，rubric 最多提升 6.5pp。模型 judge 不是可靠 oracle，关键自动评测仍要程序化验证器或人工抽检。
- [When Tool Outputs Become Commands / SARA](https://arxiv.org/abs/2608.27146) — cs.AI，2026-08-27。在 AgentDojo/AgentDyn 将直接攻击 ASR 压到 ≤0.63%。核心是把 action provenance 与 execution authority 分离；工具输出可以建议动作，但不能自动获得执行权限。
- [Knowledge-Verified Emergent Deception](https://arxiv.org/abs/2608.26372) — cs.CL，2026-08-26。KnownLieBench 覆盖 8 个客服域、112 cases、18 个模型；先验证模型知道事实，再判断是否说谎，避免把不知道或幻觉误判成欺骗。
- [BekchiAI](https://arxiv.org/abs/2608.26867) — cs.AI，2026-08-27。13 个 ReAct agents、7 类任务、2,057 个确定性测试、4 模型比较，并提供 token/latency telemetry 与远程终止。比只报准确率更接近生产 Agent 的可观测性。
- [SKILL.state](https://arxiv.org/abs/2608.26263) — cs.AI，2026-08-26。用显式可变 execution state 取代不断追加完整历史；摘要称准确率提高、累计 token 降低，但没给幅度。值得做架构 A/B，不能只凭摘要下结论。
- [GraphMemix](https://arxiv.org/abs/2608.26983) — cs.AI，2026-08-27。用 query-aware evidence forest 管理长期多模态记忆，在 4 个 benchmark 上声称形成 accuracy/lifecycle-cost 新 Pareto frontier；摘要无绝对数字，先看实现和消融。
- [INTENT-AS-A-TOOL](https://arxiv.org/abs/2608.27348) — cs.CL，2026-08-27。把“意图”显式为 tool-call 概率，作为 judge-free 在线风险信号。适合运行时干预，但要防模型学会隐藏意图。

### 科研 Agent 与训练/推理

- [AgentFold](https://arxiv.org/abs/2608.26747) — cs.AI，2026-08-27。在超过 2,000 LOC 的蛋白折叠工程上探索约 80 个变体，耗约 5,000 GPU-hours 和 170M LLM tokens；同预算 best lDDT 比独立 Codex proposals 高 7.5%。闭环科研 Agent 能工作，但成本极高且领域很窄。
- [VERA-RL](https://arxiv.org/abs/2608.26596) — cs.CL，2026-08-27。12,900 样本、4,300 matched chains、6 类科研错误；Qwen3-VL-8B 经 RL 后在 Scan 上接近旗舰 MLLM，摘要没给绝对差值。重点是把科学错误验证拆成证据搜寻与推理两类动作。
- [Information-Guided Frontier Decoding](https://arxiv.org/abs/2608.26641) — cs.CL，2026-08-27。训练免费、无辅助模型、无额外 forward pass；同预算下在多数 diffusion-MLLM benchmark 更好，但摘要没有提升幅度。
- [Weak-Model Guidance in RLVR](https://arxiv.org/abs/2608.27420) — cs.CL，2026-08-27。用弱模型 partial trajectories 缓解 entropy collapse，无需额外 SFT 或复杂 reward；摘要称随 k 增大收益更明显，但未给绝对数值。
- [Performance Foundations of Parallel & Distributed Reasoning Language Models](https://arxiv.org/abs/2608.27046) — cs.LG，2026-08-27。系统整理 PPO/GRPO、data/tensor/pipeline/sequence/context/expert parallelism、disaggregated placement、stage fusion 与异步执行；偏系统方法论，适合 RL-for-LLM 训练架构选型。

## 后续跟踪

- Cursor/SpaceX 事件应触发开发工具的模型供应降级预案：至少保留第二 provider、兼容 API、模型能力回归集和凭据切换流程。
- 漏洞修复从“公开 PR 后发版”改为私有修复、预构建 release、同步公告；公开 CVE 描述前先确认补丁可达。
- Agent 记忆不要只堆向量检索；把“相关历史”和“当前仍为真”拆成 retrieval 与 state maintenance 两层。
- 高风险工具调用采用独立授权层；模型输出、网页内容和 tool output 都只视为不可信建议。
- Agent eval 不能只用另一个 LLM 打分；关键路径保留确定性 verifier、可回放 trace 和人工抽样。
