# AI圈简报 | 2026-07-09

## 🔥 厂商动态

### OpenAI
- **GPT-Live**(7.8) — 实时流式对话模式,带 System Card。没说性能提升,纯产品包装。
- **GPT-5.6 Sol**(6.26) — 下一代模型预览。名字终于不叫 turbo 了,但 preview 阶段能力未知。
- **Coding eval 噪声分离**(7.8) — 研究博客,讲 HumanEval/MBPP 等 benchmark 的信号 vs 噪声问题。老生常谈,benchmarketing 依旧。

### Anthropic
- **Claude Sonnet 5**(6.30) — Sonnet 线性能"接近 Opus 4.8",但价格持平 Sonnet 4.6。**问题:新 tokenizer 导致同样输入 token 数 +30%,实际等于涨价 30%**。英文 1.42x,西班牙文 1.33x,Python 代码 1.28x,简体中文几乎不变(1.01x)。Adaptive thinking 默认开启。上下文 100 万 token,输出 12.8 万。**Fable 5 被美国政府禁了,7.1 恢复,加了 cyber safeguards。**
- **Claude Code 幕后故事**(7.6) — from internal CLI to coding agent,产品化过程。
- **Claude Science**(6.30) — AI workbench for scientists,定制化工具集、可审计产物、灵活算力。跟 OpenAI 的 scientific research 方向正面竞争。

### Google DeepMind
- **Gemini Omni**(最新) — 新多模态旗舰,细节缺失。
- **Gemini 3.5 Flash computer use** — 加入电脑操作能力,跟 Anthropic 和 Adept 方向一致。
- **Nano Banana 2 Lite** — 端侧小模型,开始开发者接入。

### Meta
- **Muse Image + Muse Video**(7.7) — 高保真图生成+视频生成(原生音频)。Muse Image 能精确编辑、多参考图、读 Instagram 语境。**Instagram 成了训练数据来源,社交数据 + 生成模型闭环。**
- **Brain2Qwerty**(6.29) — 脑波转文字,非侵入式脑机接口。跟 Neuralink 走不同路线。

### Microsoft Research
- **SkillOpt**(6.30) — 把 agent skills 当可训练参数,不改模型权重。解决手工编辑 skills 无保证的问题。
- **Memora**(6.29) — agent 记忆系统,分离存储/检索,解决长上下文效率问题。

## 📌 趋势判断
1. **Context 窗口军备竞赛降温,转向 adaptive thinking/agent 能力** — Sonnet 5 的 100 万 context 没人提了,adaptive thinking 默认开。
2. **Tokenizer 隐形涨价成新手段** — Anthropic 这次示范了「技术升级+实际涨价」组合拳,30% token 膨胀 = 30% 成本增加,但名义价格未变。
3. **科研工具成兵家必争** — Claude Science、openscience、Google Gemini for Science 同时上线,AI4Science 从学术概念进入产品化阶段。
4. **开源模型从中国大厂涌出** — Tencent Hy3、DeepSeek、01.AI,Apache 2.0/MIT 授权,直接对标 Llama/Mixtral。美国出口管制下的另一条供应链。
5. **Red teaming 从 bug bounty 升级到系统工程** — Anthropic 被政府禁 Fable 5,机构部署规则论文同步出现,合规成本上升。
