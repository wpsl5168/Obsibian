## 今日判断

今天最硬的信号不是新模型，而是三个工程边界被同时戳破：价格会突然变，Agent benchmark 很容易被“过测试但没做迁移”骗过，多 Agent 互相读完整答案反而会迅速同质化。

OpenAI 把 GPT-5.6 Sol 标准短上下文价调到输入/输出 **$4/$20 每百万 token**，并注明促销价至少持续到 11 月 21 日；Kiro 的官方实验称 Terra 在 Terminal-Bench 2.1 成功任务成本约降 **82%**。结论很直接：模型路由和成本验收不能写死在季度预算里，至少要把 provider/model/price snapshot 一起落账。

SWE Refactor Bench 的 520 次全仓迁移运行里，只有 **28 次（5.4%）**通过“迁移审计 + 固定行为测试 + 6 个 Agent 生成的针对性测试”；13/20 任务没有任何可接受解。仅看测试绿灯会放过“复制旧实现”这种假迁移。长任务验收必须同时查过程目标和最终行为。

多 Agent 也不是越聊越聪明。Interaction Tax 在 11 个 verifier-scored 优化任务上发现，完整方案互看会在一轮内抹平不同模型的解法差异；更好的默认是独立出方案，再选择或只交换局部 critique。这个结论正适合拿来约束多 Agent 编排。

## 官方博客与公告

### OpenAI：GPT-5.6 进入 Kiro，价格同步下调

OpenAI 与 AWS 把 GPT-5.6 Sol、Terra、Luna 接入 Kiro 的 spec-driven 开发流程，覆盖需求、设计、实现、review 和 property-based testing。官方称 Terra 在 Terminal-Bench 2.1 的成功任务成本约降低 82%，但未在文章中给出完整基线、样本和置信区间，因此只能当厂商实验。

官方价格页当前标准短上下文价格：Sol **$4 输入 / $0.40 cached input / $5 cache write / $20 输出**；长上下文为 **$8/$0.80/$10/$30**。Batch/Flex 短上下文为 **$2/$0.20/$2.50/$10**。页面注明 Sol 促销价至少持续到 2026-11-21。

判断：Kiro 集成是渠道扩张，82% 是缺基线的营销数字；价格下调才是今天会直接改生产账单的事实。成本监控应保存生效日期，不能只保存 model ID。

来源：[Kiro 公告](https://openai.com/index/gpt-5-6-in-kiro)｜[官方价格页](https://developers.openai.com/api/docs/pricing)，正文日期 2026-08-24，本期相对昨日报告为新增发现。

### OpenAI：封禁俄罗斯隐蔽影响行动账户

OpenAI 称封禁了一组很可能来自俄罗斯、通过 VPN 使用 ChatGPT 的账户。操作者用俄语提示生成英/德语社媒内容，推广伪装成以色列智库的 International Burke Institute；网站包含复制、错误署名的学术文章和偏向俄罗斯的“主权指数”。OpenAI 明确称活动触达受众较小。

判断：这不是“AI 让宣传突然有效”，而是 AI 降低了多语种内容生产和身份伪装成本。真正有效的检测线索仍来自账户、VPN、发布网络和跨平台协同，而不是只判文本像不像 AI。

来源：[OpenAI 原文](https://openai.com/index/disrupting-malicious-uses-of-ai-influence-campaign-russia)，RSS 发布 2026-08-25 00:00 GMT。

### Agent 与软件工程

- [SWE Refactor Bench](https://arxiv.org/abs/2608.23564) — 20 个全仓迁移任务、8 个前沿模型、520 runs。只有 **28/520（5.4%）**过三阶段；13/20 任务零通过；最佳 Claude Opus 5 得 **47/100**。340 次通过迁移审计的运行中，58% 达到 99% 固定检查，但仅 26% 达 100%。判断：最有价值的是把“迁移真的发生”从行为测试里拆出来，直接可迁移到 Agent 验收。
- [Prime Agent](https://arxiv.org/abs/2608.23552) — 8 月 5 日首发、8 月 24 日更新。持久 IPython REPL + 跨轨迹 history/memory/skill + recursive subagents；作者报告 ARC-AGI-3 RHAE Best@1 从 30% 到 95.5%。判断：架构与 Hermes 高度相似，数字可能混入 harness 优势，重点应核资源核算和 ablation，而非追榜。
- [The Interaction Tax](https://arxiv.org/abs/2608.23541) — 11 个 verifier-scored 优化任务、matched budget。完整方案交换会让不同模型一轮内收敛到首个方案；独立生成再选择更能保留多样性。判断：多 Agent 默认应隔离提案，最后由 verifier/裁判合并；不要全程共享 scratchpad。

### 训练、长上下文与生成

- [How to Train a Critic Stably and Efficiently](https://arxiv.org/abs/2608.23566) — BPCO 组合 DPPO、有界 value、Monte Carlo target、未归一化 advantage 和长度自适应 GAE；1.5B 到 30B-A3B 模型上，用每 prompt **1 个 response**匹配或超过 group-based baseline。判断：若复现成立，能直接砍 GRPO 多样本成本；摘要未给完整提升幅度，先看代码。
- [ProxyFormer](https://arxiv.org/abs/2608.23463) — proxy token 双流压缩；作者称 16GB GPU、batch 1 下训练长度从约 20K 拉到约 **0.7M**，64K 训练窗在 1,048,576-token multi-needle 上保留 **92%–95%**。单作者、synthetic retrieval，先别把它当通用长文推理突破。
- [ChebBooster](https://arxiv.org/abs/2608.23429) — DiT training-free Chebyshev 外推缓存，覆盖 DiT-XL/2、PixArt-Σ、FLUX.1-dev；作者报告最高 **3.68× latency**、**5.12× FLOPs**。工程上可试，但图像质量与硬件基线需复核。
- [ReWorld](https://arxiv.org/abs/2608.23565) — 局部/全局混合 attention heads + pose-indexed landmark bank，固定 12-chunk cache 在 64 秒 out-and-back rollout 中仍重建起点；704×1280、4-step 实时生成。判断：把“控制短窗”和“空间长期记忆”拆开，结构比单纯拉长 KV cache 更合理。

### 安全与测量

- [Mitigating Reasoning-Induced Misalignment via Safety-Direction Penalty](https://arxiv.org/abs/2608.23497) — 在 Qwen2.5-3B/7B 上定位 reasoning/safety activation direction 耦合，并在 reasoning fine-tuning 中惩罚安全方向位移；作者称恢复安全且不损 reasoning benchmark。判断：样本只覆盖两个同族小模型，跨架构前不应外推。
- [STONIC](https://arxiv.org/abs/2608.23411) — 5,144 situations、35 固定模型配置；17 个有可用行为数据的配置都偏好自己先前答案，median effect 0.790，但位置偏置在全部配置中都改变选择率。判断：问卷 rating、pairwise choice、自由生成不能粗暴合成一个“模型价值观分数”。
