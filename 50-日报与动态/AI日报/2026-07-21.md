## 顶级博主

### Lilian Weng: Harness Engineering for Self-Improvement
- 7月4日发布,OpenAI 安全团队负责人 Lilian Weng 新长文
- 核心观点:**harness**(模型周边部署系统)跟模型本身权重一样重要
- 定义 harness = 编排执行+工具调用+上下文管理+状态存储+评估的系统
- 近期 RSI(递归自我改进)路径更可能从 harness 工程开始,而非模型直接改写自己权重
- 详细拆解了 coding agent harness 设计模式(workflow/file system/subagent)
- 引用了大量最新研究(ACE、MCE、prompt evolution、auto-research)
- 来源: https://lilianweng.github.io/posts/2026-07-04-harness

## 分析

本周最重要的是 **Lilian Weng 关于 harness engineering 的长文**,这是 OpenAI 安全团队对当前 AI agent 生态的系统性总结。核心信息:

1. **部署系统跟模型权重一样关键** — Claude Code、Codex 成功不只是因为模型强,更因为 harness 设计好
2. **RSI 近期路径是改 harness 不是改权重** — 模型直接 rewrite weights 还不现实,但模型改进训练/部署系统已经在发生
3. **Coding agent harness 已收敛到标准模式** — file system 做持久化、subagent 做并行、workflow 做编排

OpenAI/Anthropic 同期发布的 GPT-5.6 和 Sonnet 5 都是"更 agentic"方向,验证了这个趋势。

Qwen 3.8 Max 开放权重是政策信号,但无 benchmark/license,暂时只是 PR。值得跟踪实际 release。

GitHub trending 里 free-claude-code 和 webnovel-writer 火,说明开发者在找绕过付费墙的路子,也在探索长文本写作(harness 应用场景之一)。
