### 1. 白宫对 Anthropic 实施紧急出口管制

**时间线**：
- 6月9日：Anthropic 发布 Claude Fable 5 和 Mythos 5
- 6月12日：Amazon CEO Andy Jassy 向白宫报告模型安全漏洞
- 6月13日（星期五）：白宫高层与 Dario Amodei 进行三轮电话谈判后，特朗普政府对 Anthropic 模型实施出口管制

**核心问题**：
Amazon 发现 Fable 5 存在"越狱"方法，可绕过模型的网络安全防护栏。

**Anthropic 辩护**：
- 声称测试者尚未找到"通用越狱"（能广泛绕过防护栏的方法）
- 认为完全避免越狱"目前对任何公司都不可能"
- 其防护系统"强到许多用户抱怨过于严格"

**政府立场**：
- 财政部长 Scott Bessent 直接告诉 Amodei 他做出了"糟糕的决定"
- 白宫网络安全主管 Sean Cairncross 强烈主张移除模型
- NSA 审查后认定 Amazon 的发现具有可信性

**结果**：
- Anthropic 被迫立即禁用所有客户对 Fable 5 和 Mythos 5 的访问
- 标志着美国政府首次对 AI 模型部署采取紧急干预措施
- Anthropic 目前正与特朗普政府谈判解除管制

**影响**：
- 前白宫 AI 沙皇 David Sacks（反监管立场）都支持政府决定
- 美国网络安全领导者呼吁白宫解除禁令
- 引发关于 AI 安全治理框架的激烈讨论

**原始信源**：
- Politico：https://www.politico.com/news/2026/06/13/inside-the-whirlwind-24-hours-that-led-the-white-house-to-slap-export-controls-on-anthropic-00961519
- Fortune：https://fortune.com/2026/06/16/trump-administration-licensing-regime-for-frontier-ai-models-ad-hoc-and-opaque-eye-on-ai

## 🔬 技术深度解析

### Claude Fable 5 性能评测（Simon Willison）

**规格**：
- 上下文窗口：100万 tokens
- 最大输出：128,000 tokens
- 知识截止：2026年1月
- 定价：$10/百万输入 tokens，$50/百万输出 tokens（是 Claude Opus 4.5-4.8 的2倍）

**模型规模推测**：
Simon Willison 通过知识测试推测 Fable 5 可能是"迄今为止任何供应商发布的最大模型"。测试中，Fable 5 列出了15+个 Simon 的开源项目（包括发布日期），而 Opus 4.8 仅谨慎列出约4个知名项目。

**实战项目1：CPython WASM 沙箱**
- 任务：将 micropython-wasm 升级为运行完整 Python
- 成果：成功实现集成，生成13.9MB wheel 文件
- 质量：多轮迭代优化，展现复杂系统工程理解

**实战项目2：Datasette Agent & LLM 库**
- 初始目标：为 Datasette Agent 添加工具调用暂停/审批功能
- 实际成就：
  - 解决主问题（GitHub PR #20）
  - 识别底层 LLM 库中的4个相关问题
  - 实现所有功能（非 hack 方式）
  - **发布 LLM 0.32a3，几乎完全由 Fable 编写**

**关键功能**：
- `llm_tool_call` 参数（工具访问 `tool_call_id`）
- 每次工具调用的唯一 `tool_call_id`（如未提供则合成 ULID）
- `llm.PauseChain` 异常（无需虚拟结果的干净暂停/恢复）
- 并发工具执行失败语义
- 从历史记录恢复链（含未解析工具调用）
- 修复异步执行器静默丢失缺失工具的 bug

**成本分析（单日）**：
- 总花费：$110.42
- 主力项目（datasette_agent）：$99.26（78.2M tokens，89.9%）

**质量评价**：
> "I'm really impressed with the quality of API design, tests, code and documentation that Fable put together for this. I spent several hours on it today, but it feels like several days' worth of work."

**原始信源**：
- Simon Willison：https://simonwillison.net/2026/Jun/9/claude-fable-5/
