### 2. OpenAI ChatGPT Dreaming V3 记忆架构大改（June 4发布）

**发生了什么**:
- OpenAI于6月4日开始向Plus/Pro用户推出Dreaming V3，几周内扩展到Free/Go用户
- 新架构**完全移除手动保存的记忆列表**，改为后台自动从历史对话中合成用户画像
- 计算成本下降约5倍，使得免费用户首次获得真正的记忆能力

**背景**:
- 旧架构（至6月4日）依赖两层：显式保存列表 + Dreaming V0后台参考
- Dreaming V0在2025年4月引入，但不能独立作为记忆系统
- 新架构将后台合成作为唯一基础，saved list完全消失

**分析**:
- 这是从"用户主动告知"转向"系统被动学习"的根本性转变
- 记忆层独立于对话，在推理时注入system prompt
- 系统会自动更新记忆：比如你说"7月去新加坡"，回来后会自动修正为"8月去过新加坡"
- 2026年2月arXiv论文显示：96%的ChatGPT记忆条目是系统单方面创建的（非用户确认）

**影响与关注点**:
- 用户对"AI在背后记住什么"的控制感下降
- EU AI Act透明度规则将于8月2日生效，要求对记忆系统有明确审计机制
- 免费用户首次获得记忆能力 = 10亿级用户的个性化数据积累
- OpenAI未提供单一开关来关闭所有记忆功能（只有删除/编辑单条）

### 3. Claude Sonnet 4 / Opus 4 今日退役（June 15）

**发生了什么**:
- Anthropic于6月15日正式下线 `claude-sonnet-4-20250514` 和 `claude-opus-4-20250514`
- 推荐迁移目标：
  - Sonnet 4.6 ($3/$15 per M tokens, 1M context)
  - Opus 4.8 (5月28日发布, 1M context, Dynamic Workflows)

**背景**:
- 4月14日Anthropic通知开发者将退役这两个模型
- 提前2个月通知，但仍是Anthropic部署量第二高的API模型
- 新版本取消了`temperature`/`top_p`/`top_k`参数（Opus 4.7+），设置非默认值会返回400错误

**分析**:
- Anthropic模型生命周期加速：从发布到退役不到1年
- 迁移常见坑：
  1. 环境配置硬编码model ID
  2. 未处理deprecated参数导致400
  3. 1M context需要的beta header在4.6+不再需要
  4. `thinking` budget从显式token数改为 `"adaptive"`

**影响与关注点**:
- 生产环境今日会出现大量API失败（未及时迁移的团队）
- Sonnet 4.8预计本周(6月16-18)发布，距离Opus 4.8发布约3周（符合Anthropic cascade模式）
- Sonnet是生产agent实际使用的模型，Opus太贵；4.8发布将是2026最受关注的mid-tier模型

### 安全与沙箱

**OpenAI Lockdown Mode (June 5)**:
- 目标：防止prompt injection攻击的最后一环（数据外泄）
- 机制：限制outbound网络请求，切断exfiltration通道
- 重要：**不能防止prompt injection本身**，只能阻止数据传出
- 应对"致命三角"：私有数据访问 + 不可信内容暴露 + 外泄能力

**Anthropic沙箱架构**:
- Claude.ai: gVisor
- Claude Code (本地): Seatbelt (macOS) / Bubblewrap (Linux)
- Claude Cowork: 完整VM (Apple Virtualization framework / HCS on Windows)
- 核心原则：凭证永不进入沙箱 = 无法被窃取，无论是用户失误、模型"创造性"路径还是攻击者

**Meta AI账号劫持 (June 1)**:
