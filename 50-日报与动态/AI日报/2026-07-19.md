### Anthropic Claude Fable 5 订阅政策逆转
- **时间**: 2026-07-18
- **原文**: https://simonwillison.net/2026/Jul/18/claude-make-fable-5-permanent
- **事件**: Anthropic 宣布 7 月 20 日起 Fable 5 永久纳入 Max/Team Premium 订阅,额度限制为原来的 50%。Pro/Team Standard 用户继续通过 usage credits 访问,并获得一次性 $100 额度。
- **背景**: 原计划将 Fable 5 从订阅中移除,仅通过 API 付费提供。但 GPT-5.6 Sol 和 Kimi K3 的竞争使该策略无法维持——谁会为一个不含最强模型的订阅付每月 $100-200?
- **评论**: 这是竞争压力的直接结果。Anthropic 原计划由算力瓶颈驱动(要腾出 GPU 做训练),现在被迫用订阅 GPU 资源换用户留存。可能需要缩减训练规模来支撑推理负载。

### Kimi K3 vs Fable 5 vs GPT-5.6 Sol 性能比较
- **时间**: 2026-07-18~19
- **来源**: Reddit/X 社区测试、HN 讨论
- **核心数据**:
  - Kimi K3 在 Frontend Code Arena 胜率 76%,顶住了 Fable 5/GPT-5.6 压制
  - SpreadsheetBench 2: K3 排名第一
  - 游戏开发实测(X @cyrilXBT): K3 9.5/10($0.030)、Fable 5 7.5/10($0.38)、GPT-5.6 Sol 7/10($0.11)
  - 综合能力:Fable 5 仍是全场最强,但 K3 在编码/表格/前端等垂直场景逼近甚至超越,且成本仅为 Fable 5 的 8%
- **评论**: K3 是第一个"Fable 级开源权重"模型,但只在特定任务上接近 Fable。通用推理、长文本理解、复杂指令跟随上仍有差距。真正的意义是开源阵营终于有了能在部分任务上挑战闭源顶配的选项,开发者可以本地跑了。

### GPT-5.6 应用于数学证明

- **事件**: GPT-5.6 Sol 用一个 prompt 解决了一个 30 年悬而未决的凸优化缺口问题(继之前的 CDC 证明公告后)
- **评论**: 如果属实,这是继 AlphaGeometry/AlphaProof 后 LLM 在形式推理上的又一次突破。但 Reddit 源没给出论文/验证链接,需等同行评审。当前 LLM 在"正式数学证明"上仍处于辅助角色,自主发现新定理的能力有限,更多是压缩搜索空间。

### Bun 用 Rust 重写并已部署
- **来源**: https://simonwillison.net/2026/Jul/19/claude-code-in-bun-in-rust
- **原文**: https://bun.com/blog/bun-in-rust (Jarred Sumner 博客)
- **事件**: Bun v1.4.0(未公开发布)已用 Rust 完全重写,并在 Claude Code v2.1.181+(2026-06-17)中上线。Simon Willison 通过 `strings ~/.local/bin/claude | grep -Eo 'src/[[:alnum:]_./-]+\.rs'` 确认了 Claude Code 二进制中嵌入了 563 个 Rust 源文件路径。
- **技术细节**: 
  - Linux 启动速度提升 10%
  - 解决了 Zig 版本中 GC 与手动内存管理混合的稳定性问题
  - 已在数百万设备上静默部署,无明显用户反馈
- **评论**: Jarred 说"Boring is good"——生产级语言迁移的最高标准就是没人注意到。这证明 Rust 在系统级工具链改写上已经成熟到可以无缝替换现有 C++/Zig 栈。Claude Code 作为大规模分发应用的试金石,比任何 benchmark 都更能说明 Rust 生态的成熟度。

### AI 狂热正在摧毁企业决策
- **来源**: https://ludic.mataroa.blog/blog/ai-mania-is-eviscerating-global-decision-making/ (Nik Suresh)
- **转载**: https://simonwillison.net/2026/Jul/19/ai-mania
- **核心观点**:
  1. **高管制定 AI 战略时从未用过 AI 工具** — 一个咨询案例:某 $2B 收入公司的高管承认从未用过 ChatGPT,但刚刚签发了全公司 AI 转型战略
  2. **Token 积分制导致荒谬行为** — 工程师为了保住工作,让 AI 把整个 Go 仓库重写成 Zig,然后挂在后台刷 token,自己去干正事
  3. **客户-供应商的"皇帝新衣"链条** — 客户高管对外宣称"AI 带来 100x 生产力提升",供应商高管明知荒谬但不敢反驳,因为戳破客户幻想等于丢合同被炒,于是整条链上所有人都在说谎
- **评论**: 2026 年的 AI 炒作已经进入"组织性自欺欺人"阶段。不是技术不行,是决策层完全脱离实践,把 AI 当 PPT 符号用。这种狂热最终会带来一轮大规模的幻灭和裁员。

## 研究动态

### Anthropic: 模块化预训练 + GRAM (Gradient-Routed Auxiliary Modules)
- **来源**: https://alignment.anthropic.com/2026/modular-pretraining
- **问题**: 训练数据中包含危险知识(生化武器、黑客攻击),完全过滤会损失能力,不过滤会带来风险
- **方案**: 用 GRAM 把危险知识隔离到独立模块,可根据用户信任度动态开关
- **实验**: 单次训练可近似 5 个不同数据过滤版本的模型,参数规模 50M~5B 均有效
- **评论**: 这是"可控发布"的技术基础 — 同一模型底座,对不同用户暴露不同能力表面。未来模型会是分层访问的:内部红队全开,API 客户部分开,消费订阅最保守。

### Anthropic: 语言模型中的"全局工作空间"(J-space)
- **来源**: https://www.anthropic.com/research/global-workspace
- **发现**: Claude 内部存在一个类似"意识工作区"的表示空间(J-space),模型在其中进行推理、可报告的思考,其余处理在"无意识"层运行
- **实验验证**:
  1. 问 Claude"你在想什么",它报告的内容与 J-space 的激活高度一致
  2. J-space 在不同层之间演化,可以追踪"沉默词汇"(模型内部推理但不输出的 token)
  3. 可以通过 prompt 调制 J-space(类似人类的"心理聚焦")
- **评论**: 这是 Anthropic 可解释性研究的新突破,但也带来哲学争议 — 如果 J-space 真的类似人类意识,那模型是否有"体验"?伦理边界在哪?当前结论是 J-space 支持意识的*功能*特征(报告、推理、调制),但不代表存在主观体验。
