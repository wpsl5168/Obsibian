### AI 对开发者教育的影响
- **Josh W. Comeau** (课程创作者) 报告:
  - 销售额比去年大幅下降,收入下降 **50%+**
  - 用户参与度降低
- 原因:
  1. 许多人担心开发者工作在几个月内是否还会存在,因此不愿花时间/金钱学习新开发技能
  2. 即使想学习新开发技能,LLM 也能提供个性化辅导,购买付费课程的动力减弱
- 行业趋势: 多个课程创作者都经历类似 50%+ 收入下降
- 核心问题: LLM 在未经同意或补偿的情况下消费创作者内容

### Claude Code 使用技巧: 有效委派工作
- **最佳实践**: 让模型使用自己的判断而不是微观管理
- 测试方法: 告诉 Fable "只对较大功能使用自动化测试" 而不是指定确切流程
- 成本优化: 通过子代理将较小任务委派给低功耗模型
- 示例提示: `For all coding tasks use your judgement to decide an appropriate lower power model and run that in a subagent`
- **Claude 的记忆格式** (自动保存):
```
--- name: delegate-coding-to-subagents
description: Simon wants coding tasks delegated to subagents running an appropriately lower-power model
metadata:
  node_type: memory
  type: feedback
---
```
- 结果: 在保持输出质量的同时显著提高 token 效率

### LLM Coding Agent 0.1a0
- 基于 Simon 的 LLM 框架构建的 Claude Code 风格编码代理的新 Python 库
- 安装:
```bash
uvx --prerelease=allow --with llm-coding-agent llm code
```
- 功能:
  - 使用 TDD 方法构建,包含红/绿提交
  - CLI recipes: `llm code --yolo`, `llm code --allow "pytest*"`
  - Python API: `CodingAgent(model="gpt-5.5", root="/path", approve=True).run("...")`
- 实现的工具:
  - `edit_file(path, old_string, new_string)`: 替换精确字符串并验证差异
  - `execute_command(command, timeout=120)`: 运行 shell 命令,最大 600 秒超时
  - `list_files(pattern, path)`: 基于 glob 的文件列表 (最多 200 个路径,忽略隐藏/node_modules/.gitignore)
  - `read_file(path, offset, limit)`: 读取编号行并分页 (offset 从 0 开始,limit 最大行数)
  - `search_files(pattern, path, glob)`: 正则搜索,最多 100 个结果
  - `write_file(path, content)`: 创建/覆盖文件并创建父目录
- 演示结果: 构建了 SwiftUI ASCII 时间显示应用
- 仓库: https://github.com/simonw/llm-coding-agent
