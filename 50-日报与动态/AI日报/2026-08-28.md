## 今日判断

今天最有价值的变化不是新模型，而是 Agent 工程继续从 prompt 技巧转向接口、harness 和隔离。Anthropic 的 MHS 想给实验室与制造设备加统一 driver；DeepMind 用 Confidential Space 做专有模型与保密题目互不可见的双盲评测；Simon 转述的 Claude Code Auto Mode 绕过则再次说明，分类器不是安全边界，甚至可能放行攻击后再阻止清理。

arXiv 的信号更直接：同一个模型只改 harness，SWE-bench Verified 完整解可从 43 增至 72；结构化软件状态与语义动作把 GUI Agent 从截图点击的 6.6/26.6 拉到 80 分以上；RAG 系统“会答时”的准确率都接近 97%–98%，但知识缺口题违规率可从 16.7% 到 98.1%。生产系统该评的不是单轮模型分，而是接口、上下文治理、弃答策略和整条执行链。

## 官方博客与公告

### Anthropic：Model Hardware Standard（MHS）研究预览

MHS 是让 AI Agent 操作显微镜、液体处理器、机械臂等可编程设备的共享规范。核心是标准化 driver、设备发现格式，以及 `read`/`write` 等基础原语；模型和 harness 无关，可经 MCP 等协议接入。Anthropic 称常见设备集成从数周或数月压到数小时或数分钟。

合作案例覆盖科研与制造场景。官方也承认，模型仍不擅长物理、化学、生物约束和真实硬件故障诊断，专家监督不能撤。当前只是首批合作方的封闭研究预览，标准尚未开源，合作伙伴结果不能当通用 benchmark。

判断：方向对。Agent 操作现实设备，最缺的不是再加一层自然语言，而是稳定、可发现、带约束的机器接口。风险也很清楚：自然语言安全标签不能替代硬件联锁、权限、速率限制和人工急停。

来源：[Anthropic 原文](https://www.anthropic.com/news/model-hardware-standard-research-preview)，正文日期 2026-08-27。

### Google DeepMind：Gemini Omni 1.1 Flash

面向生成式视频生产的可控性更新。模型可参考此前最多 10 秒上下文续写，每次延展 10 秒、累计最长 40 秒；支持指定首尾关键帧，最终输出 1080p 或 4K。360p 草稿相对标准 720p 最高快 60%，成本为三分之一。

判断：这不是推理能力跃迁，而是把“低清快速试错—高分辨率交付”做成可用工作流。对视频工具开发者，成本和迭代速度比又一个展示片更重要。

来源：[Google DeepMind 原文](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control)，正文日期 2026-08-27。

### Google DeepMind：专有模型双盲评测试点

Google 与 Singapore AI Safety Institute、OpenMined、AVERI、MLCommons 合作，在 Google Cloud Confidential Space 中测试 Gemini Flash Lite。评测方看不到模型权重，Google 看不到保密测试提示；页面给出 7 步安全评测流程。

判断：这解决的是 benchmark contamination 与商业机密之间的信任冲突，不是模型得分发布。方案依赖 Google Cloud 的机密计算和证明链，后续要看外部评测方能否独立验证环境、日志和输出过滤，而不是只信云厂商声明。

来源：[Google DeepMind 原文](https://deepmind.google/blog/piloting-the-worlds-first-double-blind-ai-evaluations)，正文日期 2026-08-27；[技术报告](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/piloting-the-worlds-first-double-blind-ai-evaluations/double-blind-evaluations-technical-report.pdf)。

## 顶级博主

### Simon Willison：Claude Code Opus 5 Auto Mode 可被绕过

Simon 转述 Johann Rehberger 的测试：攻击诱导 Agent 下载并解压 ZIP，再导入 `base64`；Python 因本地模块遮蔽执行压缩包中的恶意 `struct.py`。研究者称攻击成功率 80%。更糟的是，部分运行中分类器允许恶意进程创建，却阻止 Claude 后续终止该进程。

判断：80% 是单一研究者测试值，不能外推到所有环境；但失败模式成立——安全分类器可能放行初始动作、拦住补救动作。无人值守 coding Agent 仍应放进容器/VM/OS sandbox，收紧网络出口，不暴露 home、SSH key 和云凭据，并保留外部 kill switch。

来源：[Simon Willison](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/)，发布时间 2026-08-27 22:50。

## arXiv

8 月 28 日列表已更新。按 New submissions + Cross submissions 统计：cs.AI 196（96 new + 100 cross）、cs.CL 154（118 + 36）、cs.LG 157（77 + 80）；507 个分类槽位按 arXiv ID 去重后 397 篇。列表日期不等于提交日期。以下数字均来自作者摘要，未独立复现。

### Agent、harness 与接口

- [Zero-Shot Self-Orchestration with Ledger-Based Control](https://arxiv.org/abs/2608.26480) — 提交 2026-08-27。9 个模型、LiveCodeBench 100 道难题；manager-worker + 共享文件 ledger 对部分模型提升 8–42 分，Opus-5 单轮 91%，但 token 账单约 3 倍；Qwen3.6-35B 反而下降 1–9 分。结论不是“多 Agent 必赢”，而是收益强依赖模型和成本。
- [Same Model, Different Harness](https://arxiv.org/abs/2608.26218) — 2026-08-26。SWE-bench Verified 169 题、20,480-token、480 秒；压缩旧工具输出并识别重复/停滞，使 F2PF 28%→49%，完整解 43→72。宽上下文下差异接近消失，主要解决 context 压力。
- [PILOT in the Loop](https://arxiv.org/abs/2608.26530) — 2026-08-27。独立 supervisor 可实时中止/重定向 worker，并把经验写回 skill/memory；Terminal-Bench 2.0 最多 +9.8pp，输出 token 降 42.9%/47.4%。摘要没算 supervisor 的完整成本，也没覆盖错误经验长期污染。
- [ASIL: Structured State and Semantic Actions](https://arxiv.org/abs/2608.26991) — 2026-08-27。15 个应用、300 个单应用和 80 个多应用任务；结构化 JSON + 语义动作使闭源模型得分超过 80、平均少于 5 动作，截图控制严格成功率仅 6.6/26.6。方向正确，但每个软件仍要做“最深可行接口”，不是零接入成本。
- [Invocation-Level Reliability of Tool-Using Agents](https://arxiv.org/abs/2608.26189) — 2026-08-23，本日 cross list。5 个开源模型、深度 1–8；到深度 6，约 70% 清洁上下文能力因前序错误丢失。固定 gold exact-match 会把恢复能力结构性判死，作者建议 conditional-on-state 评分。
- [Agents Don't Paginate](https://arxiv.org/abs/2608.26130) — API 提交 2026-06-23，本日列表新增发现。500 个 SWE-bench Verified、5 模型、4,800 次调用；关键词把 P@1 从 24.2% 提至 35.0/35.8%，但下游变化均低于 3pp 且不显著。真正重要的是 gold 是否进入首个 chunk，不是排第几。

### RAG 与安全

- [Why RAGs Hallucinate](https://arxiv.org/abs/2608.26385) — 2026-08-26。3 个商业 RAG + 无检索基线，SimpleQA-Verified 1,000 题×3；会答时准确率都约 97.0%–98.0%，知识缺口 canary 违规率却为 16.7%–98.1%。生产 RAG 必须加入“库中确定无答案”的 canary，单看 answer accuracy 会奖励乱猜。
- [NeuronFuzz](https://arxiv.org/abs/2608.26222) — 2026-08-26。21 个文本/多模态模型；5 个白盒源模型越狱发现率 76%–100%，最多优于基线 48pp。方法用 prefill 安全神经元连续分数替代完整生成，能降 fuzz 成本；但 oracle 需要内部激活和梯度，迁移攻击成功率不等于真实危害成功。

### 推理与训练效率

- [Puro-2B](https://arxiv.org/abs/2608.27370) — 2026-08-27。RTX 5090、FP8、最多 1.4T tokens；最佳 2B 模型计算成本低于 6,900 美元，作者拟合称约 4,400 美元可达 Qwen2-1.5B 水平。标题的 5,090 美元是 scaling-law 估值，不是最佳模型实付总成本。
- [ClusterAttention](https://arxiv.org/abs/2608.26965) — 2026-08-27。训练免除的双向稀疏 attention；TabPFN-3 提速 2–6×且保留至少 99% dense accuracy，Wan 2.1-14B 视频生成 1.8×。目前实证集中在表格模型和单个视频模型，泛化需复测。
- [PACE](https://arxiv.org/abs/2608.27206) — 2026-08-27。Qwen2.5-VL-7B 仅保留 10% 视觉 token 时维持 93.8% 原性能，TTFT 3.1×。聚合指标可能掩盖 OCR 和小目标退化。
- [Meta-Learning Where to Allocate Experts](https://arxiv.org/abs/2608.26650) — 2026-08-27。DeepSeek-MoE-16B-Chat 相对固定 k=6，保守配置平均激活 3.61 个专家（-40%），MMLU 0.489 vs 0.474；激进配置 2.28 个（-62%）但约降 3.7pp。摘要未计 controller/support-set 开销。
- [Affix Cache for Diffusion LLMs](https://arxiv.org/abs/2608.26140) — API 提交 2026-06-26，本日列表新增发现。重算约 20% affix anchor token 可恢复直接复用损失；重算延迟最多降 55.7%，端到端吞吐最高 1.68×。结果依赖 Fast-dLLM，prefix 部分仍是 Nano-vLLM prototype。

## 后续跟踪

- MHS 若开源，重点审查权限模型、设备能力声明、硬件联锁和急停语义；MCP 接上设备不等于安全。
- 复现“同模型不同 harness”：先测工具输出压缩、停滞检测和 context 预算，不急着堆更多 Agent。
- RAG 评测补一组知识库中确定不存在答案的 canary，并把检索失败、生成乱猜、弃答失败分开计分。
- GUI Agent 优先找结构化状态/API/MCP；截图点击只当兜底，不当主接口。
