## 📰 头条动态

### 1. Anthropic 推出 Claude Tag (6月23日)
**链接**: https://www.anthropic.com/news/introducing-claude-tag

**核心功能**:
- Claude 作为团队成员加入 Slack，可被 @提及执行任务
- 从频道对话中构建上下文记忆，支持访问工具、数据和代码库
- 支持任务规划和自动执行，团队成员可在其工作时处理其他事务

**影响力数据**:
- Anthropic 内部已有 65% 的产品团队代码由内部版 Claude Tag 生成
- 使用场景已扩展到工程之外：产品指标追踪、客户支持工单处理、bug根因分析

**可用性**:
- 当前为 Beta 版本，面向 Claude Enterprise 和 Team 客户开放
- 未来计划扩展到更多协作平台

**技术定位**:
- 定位为 Claude Code 的演进版本，更主动化、更适合团队协作
- 沿用 Claude Code/Cowork 的交互模式：简单指令 → 任务拆解 → 分阶段执行 → 结果反馈

## 🔧 技术实践

### Simon Willison: 在浏览器中移植 Moebius 0.2B 图像修复模型 (6月22日)
**链接**: https://simonwillison.net/2026/Jun/22/porting-moebius/

**项目**:
- 将需要 PyTorch + NVIDIA CUDA 的 Moebius 0.2B 图像修复(inpainting)模型移植到 WebGPU
- 在线演示: https://simonw.github.io/moebius-web/

**技术亮点**:
- 模型大小仅 0.2B 参数，但达到 10B 级别性能
- 支持浏览器内运行，用户可上传图像、标记要移除的区域、模型实时重建填充内容
- 非方形图像自动添加 letterbox

**工具链**:
- 使用 Claude Code 辅助开发
- 配合 Datasette 项目的表创建和修改 UI 功能开发(当前 PR 中)
