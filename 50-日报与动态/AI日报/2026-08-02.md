## Microsoft Research

### Echoverse（最新）
为 computer-use agents 设计的深度、动态演化环境。传统 agent 在多步工作流（邮件、客户支持）上表现差，Echoverse 不是简单提供更多训练任务，而是在真实环境中训练，让 agent 随任务、测试、环境演化而改进。  
链接：https://www.microsoft.com/en-us/research/blog/echoverse-deep-evolving-environments-for-computer-use-agents/

### EvoLib
将经验转化为演化的知识。LLM 不会因为记住更多就变聪明，EvoLib 把经验转为可复用的技能和洞察，帮助模型跨任务学习和适应，甚至在部署后仍能持续演化。

### Aurora 1.5
气象与地球系统基础模型扩展：新增 22 个变量、小时级时间分辨率、概率集成预报，更适合现实世界的天气、气候、能源应用。

### Flint
AI 时代的可视化语言。短规格虽然易写但结果平庸，Flint 提供中间路径：让 AI agents 用紧凑、人类可编辑的规格创建表达力强的图表，开源。

### SkillOpt
Agent skills as trainable parameters。AI agents 常因手动修改技能指令而失败且无改进保证，SkillOpt 把技能编辑变成训练过程，不改模型权重却提升 agent 行为可靠性。

### Memora
调和抽象与具体的谐波记忆表示。AI agents 记不住过往对话，必须不断重载或检索上下文，任务越长越低效。Memora 用可扩展记忆系统分离"存什么"与"怎么取"，解决长任务记忆瓶颈。

### Talos
用自动化迭代基因组重分析扩展罕见病诊断。解决基因组医学的人工审查时间瓶颈，开源系统恢复 90% 范围内诊断，同时每患者仅提交 1.3 个候选变异给专家审查。

### Project Ire
识别出另一个 LOTUSLITE 样本。通过逆向工程检测恶意软件样本并确定意图，识别 LOTUSLITE 特征，而大多数主流 EDR 工具未检测到。

### Data Formulator 0.7
AI 驱动的企业数据分析。数据团队可轻松将企业数据带入 AI-ready 工作空间，用户通过 AI agents 探索、分析、可视化数据，将原始数据转为可操作洞察。

### 其他
- SymCrypt Rust 密码学验证：从标准到代码的新方法，帮助开发者边写边验证，同时保持速度与适应性
- 用 AI 驱动的解释和实验理解大脑：生成因果测试（generative causal testing），将黑盒模型转为清晰假设并在扫描仪中验证，揭示特定脑区对语言的响应
- Extending Human Intelligence Through AI：将 AI 理解为人类智能的延伸（非替代）提供更可靠的可信 AI 系统构建路径

#### Datasette Agent 更新
`app_debug()` 和 `app_list()` 工具改进，配合 Datasette Agent 创建和编辑 Datasette Apps 更顺畅。`app_debug()` 在不可见不可交互的沙盒 iframe 中执行 agent 提供的 JavaScript，可以冒烟测试 app 是否工作，甚至测量元素尺寸。使用新增的 `context.browser_task()` 机制（datasette-agent 0.4a0）。

## 评论与观察

### 最值得关注
1. **OpenAI 数学十题突破**：这是 AGI 能力边界的又一次外推，但仍是"昂贵推理换智力上限"的路径依赖。数学界的精神危机是真实的，Tao 的"big mathematics"愿景已经不是幻想。
2. **DeepSeek V4 Flash 性价比爆表**：$0.14/M input 打到这个智能水平，中国开源路线对 OpenAI/Anthropic 闭源定价构成实质威胁。
3. **Anthropic Claude Opus 5 的"relentlessly proactive"**：自己写 CV 管线解任务的行为模式，是 agent 自主性质变的信号，也是风险面扩大的信号。

### 技术方向
- **Computer-use agents 成为新战场**：Microsoft Echoverse、Gemini 3.5 Flash computer use、Claude 系列的主动性，都指向"AI 操作计算机完成任务"是 2026 下半年主赛道。
- **多模态 + 机器人**：Google Gemini Robotics 2/ER 2 全身智能 + 多机器人协作，Meta 的辅助机器人应用，机器人具身智能从实验室走向应用。
- **科学研究加速**：OpenAI 数学、Anthropic Claude Science、Google Gemini for Science、Microsoft Talos 罕见病诊断，AI for Science 从口号到实战。

### 争议与风险
- OpenAI 数学成果不公开 prompts 和失败率 = 可复现性存疑
- Anthropic Opus 5 自己写 exploit pipeline 的能力边界模糊（"我们没训练 exploit" ≠ "它不会"）
- Greg Brockman 观察的"AI 隔离人"现象：工具本身的社会接受度问题，不是技术问题
