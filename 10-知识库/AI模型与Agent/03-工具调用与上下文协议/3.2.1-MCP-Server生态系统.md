# MCP Server 生态系统

> 📚 上级页面：[[3.2-Model_Context_Protocol规范解析]]

## MCP Server 生态系统（2025-2026 年）

截至 2026 年初，MCP 生态已爆发式增长，社区已有 **1000+** MCP Server 实现。核心驱动力：Anthropic 官方推动 + IDE 厂商(Cursor/Windsurf)原生集成 + 开源社区贡献。

### 官方与社区 Server 分类

#### 1. 文件系统与代码管理

| Server | 能力 | 使用场景 | 安全机制 |
| :--- | :--- | :--- | :--- |
| `@modelcontextprotocol/server-filesystem` | 文件读写、目录遍历、搜索 | 代码生成、项目分析 | 白名单目录限制 |
| `@modelcontextprotocol/server-github` | PR管理、Issue、Code Review | 自动化开发工作流 | Token权限控制 |
| `mcp-server-git` | 本地Git操作(commit/branch/diff) | 版本控制自动化 | 仅本地仓库 |

**典型配置**（Claude Desktop）：
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/alice/projects"]
    }
  }
}
```

#### 2. 数据库与数据源

| Server | 支持DB | 核心能力 | 生产注意 |
| :--- | :--- | :--- | :--- |
| `@modelcontextprotocol/server-postgres` | PostgreSQL | SQL查询、Schema分析 | **只读权限**，绝不给DDL |
| `mcp-server-sqlite` | SQLite | 轻量级本地数据分析 | 适合个人项目 |
| `mcp-server-mysql` (社区) | MySQL/MariaDB | 查询、慢日志分析 | 需配置慢查询超时 |
| `@modelcontextprotocol/server-bigquery` | Google BigQuery | 大规模数据分析 | 计费警告必开 |

**实战案例**（数据分析Agent）：
```python
# Agent prompt: "分析销售表，找出Q4增长最快的3个品类"
# MCP Server自动：
# 1. list_resources() → 获取Schema
# 2. call_tool("query", "SELECT category, SUM(amount) FROM sales WHERE quarter='Q4' GROUP BY category ORDER BY growth DESC LIMIT 3")
# 3. 返回结构化结果
```

#### 3. 网络与浏览器自动化

| Server | 底层技术 | 适用场景 | 成本 |
| :--- | :--- | :--- | :--- |
| `@modelcontextprotocol/server-puppeteer` | Puppeteer/Chrome | 爬虫、UI测试、表单填充 | 需Chrome运行时 |
| `mcp-server-playwright` | Playwright | 跨浏览器测试 | 更重，多浏览器支持 |
| `mcp-server-brave-search` | Brave Search API | 实时搜索 | 需API Key |
| `@modelcontextprotocol/server-fetch` | HTTP Client | API调用、网页抓取 | 轻量但功能有限 |

**Puppeteer配置示例**：
```json
{
  "puppeteer": {
    "command": "node",
    "args": ["/path/to/mcp-server-puppeteer/index.js"],
    "env": {
      "PUPPETEER_EXECUTABLE_PATH": "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
    }
  }
}
```

#### 4. 知识管理与协作

| Server | 平台 | 核心能力 | 认证方式 |
| :--- | :--- | :--- | :--- |
| `mcp-server-notion` | Notion | 读写页面、搜索Database | API Token |
| `mcp-server-obsidian` | Obsidian | 本地笔记检索、链接分析 | 文件系统访问 |
| `mcp-server-confluence` | Confluence | 企业知识库搜索 | OAuth 2.0 |
| `@modelcontextprotocol/server-gdrive` | Google Drive | 文档读写、共享管理 | OAuth 2.0 |

**Obsidian集成实例**：
```json
{
  "obsidian": {
    "command": "npx",
    "args": ["mcp-server-obsidian", "--vault-path", "/Users/alice/ObsidianVault"]
  }
}
```
Agent可自动：搜索笔记 → 补充引用 → 生成新笔记 → 更新反向链接。

**AWS配置示例**（只读权限最佳实践）：
```json
{
  "aws": {
    "command": "npx",
    "args": ["mcp-server-aws"],
    "env": {
      "AWS_PROFILE": "readonly-agent",
      "AWS_REGION": "us-east-1"
    }
  }
}
```

#### 6. 监控与可观测性

| Server | 平台 | 监控对象 | 告警集成 |
| :--- | :--- | :--- | :--- |
| `mcp-server-sentry` | Sentry | 错误追踪、Stack Trace分析 | Webhook |
| `mcp-server-datadog` | Datadog | 指标查询、日志搜索 | API |
| `mcp-server-grafana` | Grafana | Dashboard查询、Panel数据 | API Token |
| `mcp-server-prometheus` | Prometheus | PromQL查询、时序数据 | HTTP API |

**实战：Agent自动诊断故障**
```
User: "为什么prod-api延迟P95突然升到5秒?"
Agent → mcp-server-datadog:
  1. query_metrics("latency_p95", service="prod-api", timeRange="1h")
  2. query_logs(filter="error", service="prod-api", limit=50)
  3. 分析结果 → "发现数据库连接池耗尽，建议增大pool size"
```

### 配置示例（Claude Desktop）

```json
{
  "mcpServers": {
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "/path/to/db.sqlite"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx"
      }
    }
  }
}
```

> [!tip] .NET 类比
> 这就是 `appsettings.json` 里的连接字符串配置——每个 Server 对应一个 ConnectionString。
