# AI Daily — 2026-05-24

## 一句话总览
SpaceX 与 Anthropic 签下 $1.25B/月 计算合同把"算力即资本"推到新高度；同一周 Microsoft 自爆 AI agent 比雇人还贵、社区上线 isaiprofitable.com 公开盯账，AI 经济性正式被摆上台面拷问。

## 重点事件

### 1. SpaceX↔Anthropic：$1.25B / 月计算合同曝光
- **来源**: [Simon Willison 摘 SpaceX S-1](https://simonwillison.net/) · [Anthropic May 6 公告](https://www.anthropic.com/news)
- **发生了什么**: SpaceX S-1 招股书披露，与 Anthropic 签的云服务协议覆盖 COLOSSUS / COLOSSUS II 集群，Anthropic 自 2026-05 起按月支付 $1.25B（合同执行到 2029-05），任一方 90 天可终止，5-6 月按减免费率爬坡。
- **背景**: Anthropic 此前主要算力来自 AWS（Trainium）和 GCP（TPU），同时已和 SpaceX 在 5/6 公告里联手扩 usage limits。这是 xAI Colossus 之外，Musk 系算力首次被前沿模型公司"包月"。
- **分析**: 三年 ~$45B 的承诺，比 OpenAI ↔ Oracle 的 Stargate 单笔合同还硬。说明 (a) 算力供给已严重错配，Anthropic 宁愿挂在政治不稳定的 Musk 资产上也要锁单；(b) 前沿模型公司账面"营收"在被算力成本反向定义——这跟 Microsoft 抱怨"AI 比人贵"是同一个故事的两面；(c) 90 天退出条款是 Anthropic 给自己留的保命阀，暗示双方都不完全相信价格能撑三年。
- **影响与关注点**:
  - 留意 Anthropic 下一轮估值/融资额是否被这笔月供反推（年化~$15B 算力支出，对照其 ARR）
  - 国产同行 (DeepSeek/Qwen) 算力策略短期内只会更激进
  - 我们做 agent 平台/智能体业务时，inference 单位成本曲线要重新评估，别按 2024 年的 $/M token 拍

### 2. AI 经济性被公开拷问：MSFT 自爆"agent 比人贵" + isaiprofitable.com 上线
- **来源**: [Fortune: MSFT AI cost problem](https://fortune.com/2026/05/22/microsoft-ai-cost-problem-tokens-agents/) · [isaiprofitable.com](https://isaiprofitable.com/) (HN 251 分)
- **发生了什么**: Microsoft 内部数据显示 token 消耗型 agent 在多数后台流程上比同等人力还贵；社区上线公开站点逐厂统计 AI 业务"是否盈利"，今日窜上 HN 头版。
- **背景**: 过去 12 个月 reasoning model + 长上下文让单次任务 token 消耗 5-20x，叠加 GPU 折旧，单位经济性问题彻底盖不住。
- **分析**: 这不是某家公司的会计问题，是 reasoning 时代的结构性问题——更长 CoT、更多工具调用、更大 KV cache 都在线性放大成本。"AI 替代人力"的卖点正在掉头：真正能赚钱的不是"省人"，而是"做人做不了的"（自动化高并发 + 长尾任务）。等到下一代专用推理芯片或更激进的稀疏化（MoE/Linear Attention，参考今天 arXiv 上的 Gated DeltaNet-2）才能扳回来。
- **影响与关注点**:
  - 自家 agent 流水线优先核算"per task $"，不要光看 latency / 准确率
  - 关注 Linear Attention / state-space 在生产端落地节奏（KV cache 是大头）
  - 对客户报价时，把"token 通胀"风险写进合同 escalation 条款

### 3. OpenAI 内部模型证伪一项离散几何猜想
- **来源**: [OpenAI News 5/20](https://openai.com/news/)
- **发生了什么**: OpenAI 一个模型给出反例，推翻了一个流传已久的离散几何中心猜想（OpenAI 官方 5/20 发文）。
- **背景**: 紧随 DeepMind AlphaEvolve（Gemini-powered coding agent）在数学/科学领域刷成绩之后，前沿模型在"形式化推理 + 搜索"上的输出密度明显上升。
- **分析**: 反例搜索属于"非创造性但需要广搜+严格验证"的甜区，模型在这里赢不奇怪；真正信号是 OpenAI 愿意拿数学发现做公关，说明 GPT-5.5 系列内部已经把"可验证 reward"的强化训练跑通——这跟 RLVR / process reward 流派一脉相承。
- **影响与关注点**:
  - 我们做 evaluation 时可加"形式化可验证子集"（Lean/Coq 证明、组合搜索）作为新维度
  - 持续盯 GPT-5.5 是否会开放"reasoning trace" 给 API 用户

### 4. DeepMind Gemini Robotics-ER 1.6：具身推理升级
- **来源**: [DeepMind Blog](https://deepmind.google/blog/gemini-robotics-er-1-6/)
- **发生了什么**: DeepMind 发布 Gemini Robotics-ER 1.6，强化"embodied reasoning"，在真实机器人任务上提升空间/时序推理。
- **背景**: Figure、1X、Physical Intelligence 这条线 VLA (vision-language-action) 已是显学，Google 这版主打"通用大模型直接驱动机械臂"。
- **分析**: 真实世界数据 + 仿真协同还在解决长尾失败模式，1.6 这个小版号说明还在打磨，不是大跃迁；但具身 RL 数据飞轮一旦转起来，门槛上会迅速拉开。
- **影响与关注点**:
  - 留意是否开放 ER 系列 API 或权重（目前都是 demo）
  - 国内对标：宇树/银河通用本周如有新数据，对比看是否被卡身位

### 5. FTC 重击"active listening" AI 广告诈骗
- **来源**: [Simon Willison 5/22](https://simonwillison.net/2026/May/22/active-listening/)
- **发生了什么**: Cox Media Group 等三家公司支付约 $1M 与 FTC 和解：宣称用智能设备麦克风做实时语音广告定向，实际只是把数据经纪商的邮件列表加价转售。
- **背景**: Simon 2024 年就指出这是营销话术。FTC 关键定性：点击 ToS 并不构成此类入侵的"opt-in consent"。
- **分析**: 罚款金额不大，但裁定语义很重——把"埋在 ToS 里的同意"判为无效，对所有靠 vague consent 收集训练数据的玩家都是先例。
- **影响与关注点**:
  - 我们做端侧/语音类产品，consent 流必须显式分层（训练 vs 推理 vs 个性化）
  - 关注美国后续是否扩展到 LLM 训练语料合规
