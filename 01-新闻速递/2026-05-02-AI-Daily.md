# AI Daily — 2026-05-02

## 一句话总览
Grok 4.3 与 DeepSeek V4 两端发力压价（百万 context + 长尾推理成本下行），Uber 四个月烧光全年 AI 预算成为 Claude Code 经济性"反例"，OpenAI Cyber 闭门发布完成对 Anthropic Mythos 的真香打脸——今天的主线是"前沿能力 vs. 成本/治理"的二维拉扯。

## 重点事件

### 1. xAI 发布 Grok 4.3：1M 上下文，定价直插 GPT-5.4 / Claude Sonnet 中段
- **来源**: [xAI 官方文档](https://docs.x.ai/developers/models/grok-4.3)
- **发生了什么**: Grok 4.3 上线，1M context、function calling、structured outputs、reasoning 全配齐；定价 $1.25/$2.50（input/output，per 1M tokens），cached input $0.20。RPM 1800、TPM 10M。
- **背景**: GPT-5.4 是 $2.50/$15，Claude Sonnet 4.6 是 $3/$15，Gemini 3.1 Pro 是 $2/$12。xAI 把"中端旗舰"价格直接拉到原 mini 档。
- **分析**: 三件事值得注意——(1) 1M context 已经从"卖点"变成"准入门槛"；(2) cached input $0.20 表明 xAI 在拼 agent 长上下文复用场景；(3) 定价对 Claude Sonnet/GPT-5.4 是真威胁，但工具链生态（IDE/agent 框架）还差一截。
- **影响与关注点**:
  - 对成本敏感的 agent workload 值得跑一轮 A/B（注意 200K 以上 context 有阶梯定价）
  - 关注 OpenRouter / LiteLLM 何时把 grok-4.3 上架做对比

### 2. DeepSeek V4 预览：1.6T MoE Pro + 284B Flash，开源权重
- **来源**: [Simon Willison 评测](https://simonwillison.net/2026/Apr/24/deepseek-v4/) · [HuggingFace V4-Pro](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro)
- **发生了什么**: DeepSeek 放出 V4 Pro（1.6T 总参 / 49B 激活 / 865GB）和 V4 Flash（284B / 13B / 160GB），均 1M context、MIT 协议；定价 Flash $0.14/$0.28，Pro $1.74/$3.48。
- **背景**: V4 Pro 超越 Kimi K2.6 (1.1T) 与 GLM-5.1 (754B)，成为最大开源权重模型；V4 Flash 是当前最便宜的小模型（比 GPT-5.4 Nano 还低）。
- **分析**: (1) MoE 路线确认是开源前沿主流；(2) Flash 价格已经低到可以把内部规则系统全替换成 LLM 调用；(3) Pro 模型 865GB 不可能单机本地跑，必须依赖 vLLM 集群或托管 API；(4) MIT 协议商业用 OK，但内部部署需关注 49B 激活的内存/带宽实际开销。
- **影响与关注点**:
  - 优先在 OpenRouter 拉 deepseek-v4-flash 做现有任务回归
  - 评估自托管 V4 Pro 的 TCO vs. DeepSeek 官方 API
  - 关注是否冲击我们对 Sonnet/Haiku 的依赖

### 3. Uber 四个月烧光 2026 全年 AI 预算
- **来源**: [Briefs 报道](https://www.briefs.co/news/uber-torches-entire-2026-ai-budget-on-claude-code-in-four-months/)
- **发生了什么**: Uber 2025-12 推 Claude Code 给工程团队，到 2026-04 已烧光全年 AI 预算；95% 工程师月活、70% commit 来自 AI、人均月 API 成本 $500-2000。
- **背景**: Claude Code 用量 2 月已翻倍，Cursor 趋稳；CTO 表态"回到画板"重做预算。
- **分析**: 这是 agentic coding 经济模型的第一份硬数据点——70% commit AI 化的代价是工程师人均 ~$1k/月可变成本。算账上看，按硅谷工程师月成本 $30k 计，1k API 撬动 30%+ 产能仍然划算；但财务侧的"突发 OpEx"模型完全错位（原来按 SaaS seat 习惯）。Anthropic 的 capacity 也是隐性瓶颈。
- **影响与关注点**:
  - 我们自己用 Claude Code/Codex 的成本必须做月度预算告警（已有 cron 监控就再加一档阈值）
  - 关注 Anthropic 是否会加 enterprise quota 限流
  - 评估 DeepSeek V4 + 自建 agent 框架的替代成本

### 4. OpenAI 限流 GPT-5.5 Cyber，完成对 Anthropic Mythos 的"真香"打脸
- **来源**: [TechCrunch](https://techcrunch.com/2026/04/30/after-dissing-anthropic-for-limiting-mythos-openai-restricts-access-to-cyber-too/)
- **发生了什么**: OpenAI 发布 GPT-5.5 Cyber（渗透测试/漏洞挖掘/恶意代码逆向），仅限"关键网络防御者"申请访问；4-21 Altman 还公开嘲讽 Anthropic 限流 Mythos 是"恐惧营销"。
- **背景**: Mythos 早前已被未授权组织突破——本身就反证"限流不一定有用"。
- **分析**: 当前沿模型可信地承担 offensive security 任务后，所有 frontier lab 都会被迫走 gated release；Altman 的 180° 反转说明这不是公关问题而是责任/合规问题。趋势：未来高风险能力将形成"申请-认证-审计"标准范式。
- **影响与关注点**:
  - 涉及安全研究的项目需要预留申请周期
  - 留意中国/欧盟监管口径是否跟进 gated 发布要求

### 5. Apple 误把 Claude.md 文件随 Apple Support 应用一起发布
- **来源**: [HN 372pts/355c](https://news.ycombinator.com/) · [原推](https://x.com/aaronp613/status/2049986504617820551)
- **发生了什么**: 有人在 Apple Support 应用包内发现 `Claude.md` 文件——即 Claude Code/agent 的项目指令文件，等于 Apple 内部用 Claude Code 写代码的"提示词遗物"。
- **分析**: 一是验证 Claude Code 在大厂工程链路里的渗透深度（连 Apple 都在用）；二是发布流水线里的 artifact 清理是新型工程纪律盲点；三是这种 leak 会逐渐成为竞争情报金矿。
- **影响与关注点**:
  - 我们的发布脚本 .gitignore / .deployignore 加上 `Claude.md` `AGENTS.md` `.cursorrules` `.codex/` 等 agent 元数据
  - 反向：扫开源/移动端 app 包寻找类似遗物，可作为竞品技术栈侦察手段
