# AI Daily — 2026-04-26

## 一句话总览
本周前端模型集体迭代——OpenAI GPT-5.5（Apr 23）与 Anthropic Claude Opus 4.7（Apr 16）相继 GA，主线全面押注「可托付的长程 agentic 编码」；同时 ChatGPT Images 2.0、Qwen3.6-27B 把多模态/开源端的水位也往上抬了一截，AI 解数学猜想的「vibe-math」案例继续证明 LLM 已是研究级生产力工具。

## 重点事件

### 1. OpenAI 发布 GPT-5.5
- **来源**: [openai.com/index/introducing-gpt-5-5](https://openai.com/index/introducing-gpt-5-5/)
- **发生了什么**: 4/23 OpenAI 推出 GPT-5.5 与 GPT-5.5 Pro，先在 ChatGPT 与 Codex 上线，4/24 起开放 API。官方定位是「a new class of intelligence for real work」，强调一次性接收"messy, multi-part task"并自主完成（写/调代码、联网调研、操作软件、跨工具串联）。
- **背景**: 距 GPT-5 主线发布约半年，5.5 是中间档迭代，明显是对标 Claude 4.x 系列在 agentic coding 上的攻势；Codex 通道继续被当成新模型的"半官方后门"先行发布。
- **分析**: 1) 这次卖点几乎全在「自主性 + 长程任务可靠性」，不再卷 IQ 曲线，路线和 Anthropic 完全收敛。2) 推理效率单独成章，意味着推理成本是实际能不能 24×7 跑 agent 的瓶颈，不是 benchmark。3) API 延迟一天放出 + 同步 system card 更新，说明 agentic 模型上线流程已被 cyber/bio 安全护栏强约束，未来新模型这种"先 Codex 后 API"的节奏会变成常态。
- **影响与关注点**:
  - 立刻在 Codex/ChatGPT 里跑一轮我们自己的 agent eval，重点比 5 → 5.5 在「多文件改动 + 自验证」上的回归率。
  - 关注 API 定价与上下文长度——如果定价结构延续 5 系，可以直接接入 Hermes 现有 copilot 走的通道做 A/B。
  - 留意 Pro 档对 reasoning budget / tool-use 步数限制的差异。

### 2. Anthropic Claude Opus 4.7 GA + Mythos Preview 暗示
- **来源**: [anthropic.com/news/claude-opus-4-7](https://www.anthropic.com/news/claude-opus-4-7)
- **发生了什么**: 4/16 Opus 4.7 正式 GA，主打「最难的那部分编码现在可以 hand off」，强调长程任务里的"自我验证"，视觉分辨率明显提升。同时官方明确提到内部还有更强的 Claude Mythos Preview，但因配合 Project Glasswing 的网安护栏要先在 4.7 这种较弱模型上灰度。
- **背景**: 这是 4.6 之后又一个小版本快速迭代，时间线上正好压在 GPT-5.5 之前一周——典型的"先抢窗口期"打法。
- **分析**: 1) Anthropic 持续把 Opus 卡位在"高难度软件工程"细分，避开和 GPT-5.5 在通用 agent 上正面硬刚。2) "self-verification before reporting back" 是这次官方话术里最值得抓的能力——直接对应我们在 subagent-driven-development 里手工拼的验证回路，未来可以省一层 wrapper。3) Mythos Preview 没放出来等于明确告诉市场「我们手里还有牌，但 cyber 安全没过审先不发」，节奏感极好。
- **影响与关注点**:
  - 把 Hermes copilot provider 默认 Opus 升到 4.7，对照 4.6 跑回归。
  - 评估是否可在 architecture-review / requesting-code-review 这类 skill 中削减外层验证步骤，让模型自验。
  - Project Glasswing 的安全联盟（含 AWS/Apple/Google/MS/NVIDIA/JPM 等）值得归档跟踪，是产业级 AI 安全标准雏形。

### 3. ChatGPT Images 2.0 & Qwen3.6-27B（Simon Willison 周报）
- **来源**: [simonw.substack.com 本周刊](https://simonw.substack.com/p/gpt-55-chatgpt-images-20-qwen36-27b)
- **发生了什么**: Simon 同期还点了两件事：ChatGPT Images 2.0 上线（指令遵循 / 复杂场景能力跃升，他用"raccoon with ham radio in crowd"做基准），以及 Qwen3.6-27B 在开源端发布——27B 量级、性能逼近闭源中端。
- **背景**: 阿里 Qwen 系列一直是中国开源最强势的一支，27B 这个尺寸刚好能在单张 80G 卡或双 4090 上服务，是社区微调主力档。
- **分析**: 1) 闭源在卷 agent，开源还在补齐多模态 + 中等尺寸的通用底模，分工越来越清晰。2) 27B 档对自部署最友好，未来 fine-tune / RAG 的默认底模会从 Llama 系明显倾斜到 Qwen 系。3) Simon 也吐槽 Claude Code 定价混乱（疑似 $100/月），说明 agentic 工具的商业化定价还没找到稳态。
- **影响与关注点**:
  - 把 Qwen3.6-27B 拉一份到本地评测，跑我们标准的 code + reasoning suite。
  - 关注 Claude Code 实际定价落地，影响我们对外推荐和内部默认配置。

### 4. 业余数学家用 ChatGPT 攻克 60 年悬案（HN 409 分）
- **来源**: [Scientific American 报道](https://www.scientificamerican.com/article/amateur-armed-with-chatgpt-vibe-maths-a-60-year-old-problem/)
- **发生了什么**: 一位非职业数学爱好者用 ChatGPT 协作，证明了一个 60 年未解的（Erdős 系）猜想，且给出的方法路线"是人类此前没想到的"。HN 顶到 409 分。
- **背景**: 类似剧情已在 2024-2025 年的 Polymath / IMO 题目上演过，但这次是真·研究级开放猜想被攻克。
- **分析**: 1) 这不是 LLM "回忆已知证明"，而是 LLM 与人类共构出新路径，定性上比之前的进展更硬。2) 配合 GPT-5.5 强调的 reasoning，主线模型在数学/科研辅助上的 ROI 已经到了"个人研究者也吃得到"的级别。3) 对学术圈的信号：拒绝把 LLM 写进方法学声明的期刊政策需要重新讨论了。
- **影响与关注点**:
  - 收藏到 llm-wiki，归在「AI 协助科研」的成功案例集。
  - 我们 dspy / 推理类 skill 里可加一个"vibe-math style"的协作模板。

### 5. OpenAI Privacy Filter（HN 220 分）
- **来源**: [openai.com Privacy Filter](https://openai.com/index/introducing-openai-privacy-filter/)
- **发生了什么**: OpenAI 推出 Privacy Filter，作为模型推理前的隐私脱敏层，社区讨论度高。
- **背景**: 企业版 ChatGPT / API 一直有数据留存与合规争议，这一层是平台级解法。
- **分析**: 信号是 OpenAI 在把"安全/合规"做成可被企业直接采购的中间件，而不是埋在条款里。对自部署 agent 系统是个值得抄的设计模式——把 PII 检测/脱敏和模型调用解耦。
- **影响与关注点**: 评估是否值得在 hermes-gateway 入口处加一层可插拔的 PII filter（与 native-mcp 解耦）。
