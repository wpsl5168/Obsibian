# AI Daily — 2026-04-23

## 一句话总览
OpenAI 今日正式发布 GPT‑5.5（主打"真实工作流"长任务执行），叠加昨日 ChatGPT Workspace Agents 落地与 GitHub Copilot 个人版收紧 / Claude Code 定价乌龙，"Agent 经济学"正在从概念走向账单——平台开始为长会话付出的算力买单。

## 重点事件

### 1. OpenAI 发布 GPT-5.5
- **来源**: [Introducing GPT-5.5 (OpenAI)](https://openai.com/index/introducing-gpt-5-5/) ｜ 配套 [Bio Bug Bounty](https://openai.com/index/gpt-5-5-bio-bug-bounty/)
- **发生了什么**: OpenAI 4 月 23 日发布 GPT‑5.5，定位"a new class of intelligence for real work"，强调编码/调试、联网研究、数据分析、文档与表格生成、跨工具长任务一镜到底；同步开放针对生物风险的"通用越狱" Bug Bounty（首单 $25,000，仅限 Codex Desktop 内的 GPT‑5.5）。
- **背景**: GPT-5 系发布后，市场重心明显从"benchmark 分数"转向"能不能把多步任务做完"。同一天 Anthropic 因 Claude Code 定价乌龙被 Simon Willison 抓包（一度只对 Max $100/$200 开放，几小时后回滚），GitHub 也在前一天收紧 Copilot 个人版。
- **分析**: 5.5 不是路线图上的"超大跳跃"，而是把 Agent loop 的可靠性、推理效率（OpenAI 单独立了一节"Next-generation inference efficiency"）做到能商用买单的水位。Bio Bug Bounty 与"在 Codex Desktop 内分发"两件事一起看，OpenAI 正在把"高能力模型 + 高约束容器"作为默认交付方式——这是对监管和误用的提前对冲。
- **影响与关注点**:
  - 评估你现有 Agent pipeline 在 GPT‑5.5 下的"任务完成率/成本"曲线，而不是单点 benchmark；
  - 留意 Codex Desktop 是否正在变成 OpenAI 的"主交付通道"（类似 Anthropic 之于 Claude Code）；
  - 对外输出的 Agent 产品要把"长时会话单价"写进商业模型。

### 2. ChatGPT Workspace Agents 上线 + GitHub Copilot 个人版收紧
- **来源**: [Workspace Agents in ChatGPT](https://openai.com/index/introducing-workspace-agents-in-chatgpt/) ｜ [GitHub Copilot Individual 调整](https://github.blog/news-insights/company-news/changes-to-github-copilot-individual-plans/)
- **发生了什么**: OpenAI 4/22 推出可在企业 Workspace 内构建/分享/治理的 Agent；同日 GitHub 暂停 Copilot Individual 注册、收紧用量、把 Claude Opus 4.7 锁到 $39/月 Pro+，旧 Opus 全部下架。
- **背景**: GitHub 官方明说："Agentic workflows have fundamentally changed Copilot's compute demands"——长时并行会话已超出原个人版的资源假设。
- **分析**: Agent 不是"聊得更长"，而是"算得更多更久"。平台从"按 token"转向"按会话/按任务"的混合计价是必然，个人版会被推向 Pro/Pro+ 这种高客单。Workspace Agents 把"治理 + 共享"做成默认，承认 Agent 是组织级资产、不是个人玩具。
- **影响与关注点**:
  - 团队内部的 coding agent 选型要重新算 TCO，别再以"个人 $20"做基线；
  - 自研产品如果走 agent loop，提前设"任务预算 / 中断 / 摘要续跑"机制；
  - 关注 Anthropic 后续是否同样对 Claude Code 个人定价"软着陆"。

### 3. Anthropic Claude Code 定价乌龙（一日反转）
- **来源**: [Simon Willison: Is Claude Code going to cost $100/month?](https://simonwillison.net/2026/Apr/22/claude-code-confusion/)
- **发生了什么**: Anthropic 4/22 静默更新定价页，把 Claude Code 从 $20 Pro 移除、改为 Max $100/$200 独占；几小时后回滚。
- **背景**: 与 GitHub Copilot 同日动作高度同构，都是"算力账单兜不住"的连锁反应。无公告 + 快速回退说明内部对定价策略并不一致。
- **分析**: 这种"试水→回滚"的剧本未来一年会反复上演——核心矛盾是"重度用户用 Pro 就把单价吃穿"。下一步大概率是引入软配额、按 agent-hour 计费、或把高级模型从基础订阅剥离（Copilot 已经这么做了）。
- **影响与关注点**:
  - 把 Claude Code / Codex 写进核心工作流前，至少留一个"切换底座"的抽象层；
  - 监控自己每月在 coding agent 上的真实小时数，提前知道哪个档位是"被涨价目标"。

### 4. Anthropic Claude Opus 4.7 与 Project Glasswing（本月在野余波）
- **来源**: [Claude Opus 4.7](https://www.anthropic.com/news/claude-opus-4-7) ｜ [Project Glasswing](https://www.anthropic.com/glasswing)
- **发生了什么**: 4/16 Opus 4.7 发布（编码/Agent/视觉/多步任务全面提升）；4/7 Glasswing 联盟（AWS/Apple/Google/Microsoft/NVIDIA/JPMC 等）共同保护"世界上最关键的软件"。
- **分析**: Opus 4.7 是当前 coding agent 默认底座（GitHub 的 Pro+ 锁定也印证）。Glasswing 是 AI-era 软件供应链安全的提前布局，工程上要开始把"AI 生成代码 + 关键基础设施"当作单独的威胁面。
- **影响与关注点**:
  - 关键服务的 CI 中加入针对 AI-generated patch 的额外门禁；
  - 关注 Glasswing 后续具体技术规范（SBOM / signing / runtime attestation）。
