# AI Daily — 2026-04-22

## 一句话总览
OpenAI 发布 ChatGPT Images 2.0、Claude Opus 4.7 落地后续发酵（tokenizer 变更引发约 40% 隐性涨价）、Qwen3.6-Max-Preview 登顶 HN，以及 Vercel 因一个 AI 工具+Roblox 外挂被拖垮的供应链事件——今天是"模型迭代 + AI 基础设施安全"双主题。

## 重点事件

### 1. OpenAI 发布 ChatGPT Images 2.0
- **来源**: [OpenAI 官方博客](https://openai.com/index/introducing-chatgpt-images-2-0/) / [Simon Willison 评测](https://simonwillison.net/2026/Apr/21/gpt-image-2/)
- **发生了什么**: 4月21日 OpenAI 推出 ChatGPT Images 2.0，分 Image / Classic 两种模式，主打 prompt 精度、跨语言文字渲染（日/阿/韩/印地/孟加拉等10种文字）、风格保真度（摄影、漫画、像素风、儿童绘本）和多图人物一致性。
- **背景**: 上一代 GPT-Image 在中文、阿拉伯文等非拉丁文字渲染长期被吐槽；此次升级直接对标 Midjourney v8 与 Google Imagen 4 在多语言海报场景的差距。
- **分析**: 一致性 + 多语言文字是当前文生图的真实生产力瓶颈，OpenAI 这波明显是奔着"取代设计外包"和"广告/电商素材"市场去的。配合 Anthropic 4月17日刚发的 Claude Design，可以看出大厂的统一信号：2026 下半年生成式 UI/视觉设计会从"玩具"变"工作流标配"。技术层面 ASCII art、复杂 macOS 桌面渲染等 demo 暗示底层模型对结构化布局的理解又进了一步。
- **影响与关注点**:
  - 内容/产品同学可以重测中文海报、电商主图工作流，预计能砍掉一轮人工返工
  - 关注 API 端是否同步开放；定价对比 Sora/Veo 系列
  - 做 AI 设计工具创业，正面竞争窗口正在关闭

### 2. Claude Opus 4.7 的"隐性涨价"被坐实
- **来源**: [Anthropic 公告](https://www.anthropic.com/news/claude-opus-4-7) / [Simon Willison 实测](https://simonwillison.net/2026/Apr/20/)
- **发生了什么**: 4月16日发布的 Opus 4.7 更换了 tokenizer，Anthropic 官方说同样输入会多 1.0–1.35×，Simon 用真实系统提示实测达到 1.46×。单价没变（$5/$25 每 M token），等于实际涨价约 40%。
- **背景**: Claude Opus 4.6 自年初以来是工程类 agent 任务的事实标准；4.7 在 coding/agent/vision 上有提升但不是代际跨越。
- **分析**: 这是"账单上看不见的涨价"，对长上下文/agent loop 类应用打击最大——一次工具循环可能多烧 40-50% 成本。结合上周 OpenClaw 第三方 CLI 被官方放行，Anthropic 显然在用"开生态 + 收价"的组合拳。短期内 Sonnet 4.6 + Opus 4.7 路由策略会成为成本优化的标配。
- **影响与关注点**:
  - 立即检查生产环境 Claude API 月账单基线，4.7 的迁移要算清楚 ROI
  - 对 token 敏感场景（长文档、agent）继续用 4.6 或路由到 Sonnet
  - 重新评估 Gemini 2.5 / GPT-5.4 / Qwen3.6 作为备选

### 3. Qwen3.6-Max-Preview 在 HN 登顶（695 pts）
- **来源**: [Qwen 博客](https://qwen.ai/blog?id=qwen3.6-max-preview)
- **发生了什么**: 阿里 Qwen 团队放出 3.6-Max-Preview，HN 投票 695、377 评论，是过去48小时 AI 板块最热帖第二名。
- **背景**: Qwen 系列 2025 年起在开源 LLM 榜单常年前三；Max 是闭源旗舰路线，对标 GPT-5.4 / Opus 4.7。
- **分析**: 海外开发者社区对中国闭源模型的关注度持续抬升。如果 API 价格还是熟悉的"1/5 Anthropic"打法，Claude 涨价窗口正好被它接住。
- **影响与关注点**:
  - 关注独立评测（SWE-bench、Aider、终端 agent）
  - 海外项目可考虑加 Qwen 路由分流
  - 留意是否同步放开 Apache 2.0 dense 版本

### 4. Vercel 平台被一个 AI 工具 + Roblox 外挂打瘫
- **来源**: HN 多篇热帖（合计千余评论） / Trend Micro 分析
- **发生了什么**: Vercel 经历 4月安全事件，OAuth 攻击链泄露平台环境变量，根因据报道是某个 AI 工具与 Roblox 作弊脚本组合滥用了 Vercel 的部署管道。
- **背景**: 2026 年 AI agent 大规模接入 CI/CD、env vars 已是常态；Vercel 的 v0 + 部署一体化是 vibe coding 的代表平台。
- **分析**: "AI agent 滥用引发平台级事故"的标志性事件。攻击面从代码扩展到了"agent 凭据 + 平台 OAuth scope"，传统 SAST/DAST 完全覆盖不了。预计后续半年所有 agent 平台都要重新审视 secret 管理与最小权限。
- **影响与关注点**:
  - 立刻 review 项目里 Vercel/Netlify/Cloudflare 的 token scope，关掉 agent 不必要的权限
  - 关注 Anthropic 牵头的 Project Glasswing（4月7日）后续动态
  - 内部 agent 跑生产部署一定要走人审 + 短期凭据

### 5. GitHub 假星经济被起底（HN 794 pts）
- **来源**: HN 第一名讨论 / awesomeagents.ai 调查报告
- **发生了什么**: 调查指出大量 AI/agent 类仓库存在批量刷星行为，今日 HN 第一。
- **背景**: 过去一年 AI 项目融资和招聘极度依赖 GitHub stars 作为信号。
- **分析**: 这事会反向影响投资人和招聘方对 stars 的信任度，以及 GitHub 自己是否会推"verified star"机制。
- **影响与关注点**:
  - 评估开源项目时叠加 commit 频率、issue 质量、贡献者多样性
  - 自家开源不要刷星，长期是负资产
