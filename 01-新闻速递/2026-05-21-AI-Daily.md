## 重点事件

### 1. OpenAI 模型证伪离散几何中心猜想
- **来源**: [openai.com](https://openai.com/index/) | [HN 讨论 1029pts](https://news.ycombinator.com/)
- **发生了什么**: OpenAI 公布一项研究，称其模型在离散几何领域反证（disprove）了一个长期被认为成立的中心猜想，HN 上 11 小时冲到 1029 分 752 评论。
- **背景**: 这是继 GPT-5 系列在 IMO/Putnam 上拿满分之后，AI 第一次在「研究级」未解问题上给出真正的反例构造，而不是定理重证。
- **分析**: 关键不在「AI 替代数学家」，而在反例可被人类验证——这意味着 LLM + 搜索/形式化验证的组合已经能在组合数学这种「构造性强、验证便宜」的领域贡献新结果。下一波最先被推平的将是组合优化、编码理论、SAT/SMT 调度。
- **影响与关注点**: ① 关注 OpenAI 是否会放出 reasoning trace / 形式化证明；② 关注 Lean/Coq 社区接入；③ 我们做 RL 训练时，「验证器便宜」的任务族（数学、代码、电路）值得优先 GRPO。

### 2. OpenAI 最快本周五递交 IPO（保密申报）
- **来源**: [CNBC](https://news.ycombinator.com/) | [WSJ 报道](https://www.wsj.com/tech/ai/openai-is-preparing-to-file-for-an-ipo-very-soon-0ec95af5)
- **发生了什么**: CNBC/WSJ 双源报道，OpenAI 最快本周五（即明日）以保密形式向 SEC 递交 S-1。
- **背景**: 同日 SpaceX 也提交了 S-1（HN 349pts）。AI 一线公司开始走向公开市场。
- **分析**: 保密递交后 15-30 天才会公开版本；估值预计破 5000 亿美金，将成为史上最大科技 IPO。这对二级市场 AI 板块是一个明确的「锚」——竞品（Anthropic、xAI）的下一轮一级估值都会被这条曲线重新校准。
- **影响与关注点**: ① 留意 S-1 中的训练成本、推理 gross margin、用户留存等首次公开披露；② 一级市场 AI infra 项目估值可能被拉高 1-2 个月窗口；③ 我们的 vendor 选择要把「IPO 锁定期内不会乱涨价/不会卖身」纳入考量。

### 3. Google I/O 余震：Gemini 3.5 Flash GA + Spark Agent + Antigravity 关闭开源
- **来源**: [Simon Willison 整理](https://simonwillison.net/)
- **发生了什么**: Gemini 3.5 Flash 取消 preview 标志正式 GA、价格上调；新发 Personal Agent「Gemini Spark」原生贯穿 Gmail/Calendar/Drive/Docs/YouTube/Maps；同时宣布 6 月 18 日停止维护开源 Gemini CLI（Apache 2.0 TS），用闭源「Antigravity」（Go CLI + VS Code Fork + Python SDK）替代。
- **背景**: Spark 直接对标 OpenAI 的 Operator / Anthropic Computer Use；闭源化是 Google 在 agent 平台上把生态收紧的关键信号。
- **分析**: 三件事连起来看就是 Google 切到「agent + 闭源 + 全家桶」打法——Flash 涨价是为给 agent 跑 inference 留毛利空间，Antigravity 关闭则是阻止社区拿开源 CLI 反向接入第三方模型。短期对 Cursor / Aider 之外的「中立 CLI 工具」生态是负面信号。
- **影响与关注点**: ① 6 月 18 日前把 Gemini CLI 相关脚本/工作流迁出或锁版本；② Spark 的 ephemeral VM 沙箱模型值得 Hermes Agent 学习；③ 评估把 Gemini 3.5 Flash 列入 Hermes 的 fallback provider 矩阵。

### 4. Anthropic 拿下 Colossus2 GB200 算力
- **来源**: [Tom Brown / X via HN 148pts](https://news.ycombinator.com/)
- **发生了什么**: Anthropic 宣布把训练集群扩展到 xAI/Memphis 系的 Colossus2，使用 NVIDIA GB200，规模未披露但被业内推测在数十万卡量级。
- **背景**: 此前 Anthropic 主要绑定 AWS Trainium + Google TPU 双栈，这次罕见地直接吃 NVIDIA 旗舰 + 第三方机房。
- **分析**: 这个动作背后是 Claude 5（或 Opus 5）训练需求超过 AWS/GCP 当前可交付窗口的信号。Anthropic 走「多机房 + 多硬件」路线，意味着它在押 frontier 模型还有 1-2 代的 scaling 红利；同时也是对 OpenAI IPO 资本叙事的对冲。
- **影响与关注点**: ① 关注 Claude 后续大版本释放节奏（推测 Q3）；② GB200 推理 vLLM/SGLang 适配是 infra 团队近期重点。

### 5. VS Code 恶意插件供应链攻击波及 3800 仓库
- **来源**: [BleepingComputer via HN 747pts](https://news.ycombinator.com/)
- **发生了什么**: GitHub 确认一个被植入恶意代码的 VS Code 扩展导致 3,800 个仓库 token 泄漏，疑似窃取 .env / SSH key。
- **背景**: 同期 OpenAI 也刚发布对 TanStack npm 攻击的响应（5/13），「IDE 插件 + AI Coding Agent」正在成为新的供应链攻击面。
- **分析**: AI Coding Agent 让开发者在 IDE 内授予的权限越来越大（terminal、git push、API key 调用），插件审核机制完全跟不上。这一波之后 VS Code Marketplace / Open VSX 会被迫加上 publisher 验证或沙箱。
- **影响与关注点**: ① 立刻审计本机 VS Code/Cursor 插件清单，移除不活跃 publisher；② 把 OPENAI_API_KEY 等长 token 改为短 TTL；③ 我们自研 agent 应默认禁用「读取整个 home 目录」类宽权限。
