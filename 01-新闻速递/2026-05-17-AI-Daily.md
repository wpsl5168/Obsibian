### 1. NVIDIA 开源 SANA-WM：2.6B 参数的分钟级 720p 世界模型
- **来源**: [NVlabs/Sana WM 项目页](https://nvlabs.github.io/Sana/WM/)
- **发生了什么**: NVIDIA 放出 2.6B 参数的世界模型 SANA-WM，单张 H100 即可生成 60 秒 / 720p / 可控相机轨迹的视频；蒸馏版加 NVFP4 量化后在 RTX 5090 上 34 秒出片，吞吐比上一代开源基线高 36×。
- **背景**: 训练只用 64 张 H100 跑 15 天，~213K 公开视频片段做训练数据，靠"帧级 Gated DeltaNet + 周期性 softmax"的混合线性注意力解决长上下文 OOM 问题；双分支 6-DoF 相机控制保证轨迹精度，再用一个 17B refiner 二阶段提质。
- **分析**: 这是开源世界模型第一次同时把"分钟级 + 单卡 + 真 6-DoF 相机控制"三个指标拉齐到工程可用区间，对比 Sora/Veo/可灵这种闭源、分钟级训练成本几百万美金的方案是结构性降本。混合线性注意力 + recurrent 长上下文这一招大概率会被后续开源视频模型集体抄走，softmax-only 在 60s+ 基本被淘汰。"两阶段：小模型骨架 + 大模型 refiner" 也开始成为视频/Agent 双双流行的标准范式。
- **影响与关注点**:
  - 单卡可跑的视频/世界模型权重一旦放出，国内研究/产品团队基本一周内出 demo，盯 HF/GitHub 权重首发
  - 6-DoF 控制 + 长片段 = 机器人/自动驾驶仿真训练数据合成的潜在新管线
  - 关注其 license 是否商用友好（NVlabs 历史偏研究 license，可能不能直接商用）

### 2. Frontier AI 把开放式 CTF 玩坏了
- **来源**: [kabir.au — The CTF scene is dead](https://kabir.au/blog/the-ctf-scene-is-dead)
- **发生了什么**: 知名 CTF 选手撰文宣布"开放格式 CTF（线上 jeopardy 类）已死"——前沿 LLM 可以在线下选手还没读完题目时就给出完整 exploit，比赛主办方再也无法用题目难度做差异化。
- **背景**: 过去一年 GPT-5.5/Claude Opus 4.7 这一档模型在 pwn/web/crypto 各方向都明显跨过了"中等 CTF 题目"的门槛，Reverse 和 Misc 同样开始被自动化攻破。
- **分析**: CTF 是"AI 在某个智力领域超过人类业余顶尖"最早被普通工程师能直观感受到的领域之一。这条更值得关注的不是"比赛死不死"，而是它给出了一个 leading indicator：当一个评测/竞赛被 LLM 通杀，相应行业的"防御侧基线"也基本跟着抬升——下一个被通杀的极可能是初级 SOC 分析、Bug Bounty 一类低复杂度搜寻型工作。线下、人机协作、动态题目（live CTF / attack-defense）会取代静态 jeopardy。
- **影响与关注点**:
  - 招人/培训路径要重估：传统刷 CTF 入门安全可能不再有效，需要直接练 agent + human-in-loop 形态
  - 任何"以静态题库为护城河"的考试/认证体系都要警惕（包括部分 LeetCode 风格面试）

### 3. OpenAI × 马耳他：把 ChatGPT Plus 发给全国国民
- **来源**: [OpenAI — Malta ChatGPT Plus 合作](https://openai.com/index/malta-chatgpt-plus-partnership/)
- **发生了什么**: OpenAI 与马耳他政府签署合作，给所有马耳他公民免费提供 ChatGPT Plus 订阅，由政府统一采购。
- **背景**: 马耳他人口约 55 万，是欧盟内最小成员国之一，也是 AI Act 落地试点国家之一。这是 OpenAI 首次"以国家为单位"批量铺 C 端订阅。
- **分析**: 真正的看点不是"免费送 Plus"，而是 OpenAI 在用小国家做模板：政府采购 + 全民覆盖 + 数据合规协同。一旦走通，可以低成本复制到爱沙尼亚、卢森堡这类国家，从国家级渠道反向挤压本土 AI 创业生态。对国内观察者来说这是一种新的"国家级渠道战"——主权 LLM vs. 美式 SaaS 全民订阅，未来三年欧洲会成主战场。
- **影响与关注点**:
  - 跟踪欧洲其他小国是否跟进，特别是是否绑定数据本地化条款
  - 国产模型出海要重估"政府订阅"作为获客渠道的可行性

### 4. Rust 写的 coding agent Zerostack 一夜爆红
- **来源**: [crates.io / zerostack 1.0.0](https://crates.io/crates/zerostack/1.0.0)
- **发生了什么**: 名为 Zerostack 的纯 Rust coding agent CLI 在 HN 拿到 415 分，自称"Unix 哲学"设计，对标 Claude Code / Codex 但坚持零依赖、可被脚本组合。
- **背景**: 过去半年 coding agent 进入"百 agent 大战"，从 Aider/Codex/Claude Code 到各种 wrapper 层出。Rust 版本的实现还很少，主要卖点是冷启动快、内存占用低、能塞进 CI/容器。
- **分析**: 对工程师向用户，这类"Unix 风" agent 的吸引力在于可以串进 shell pipeline，而不是抢占整个交互界面。它能否活下来取决于两点：(1) 是否做模型无关的真正"瑞士军刀"，(2) 能否吸引足够多的二级生态（插件/skill）。短期不会撼动 Claude Code 的位置，但会被 DevOps/SRE 群体青睐。
- **影响与关注点**:
  - 适合放进 CI runner 做自动化 review/refactor 场景测试
  - 与现有 Hermes/Codex 工作流并存，可以做对比基准

### 5. Anthropic 一周连签盖茨基金会 + PwC，企业渗透加速
- **来源**: [Anthropic Newsroom](https://www.anthropic.com/news)
- **发生了什么**: 5 月 14 日 Anthropic 一天内官宣两条：与盖茨基金会 2 亿美元合作（全球健康/发展中国家应用），与 PwC 扩展合作（Claude 进入 PwC 的客户咨询交付）；上周还发布了 Claude for Small Business。
- **背景**: Anthropic 在 4 月发布 Opus 4.7，企业侧今年明显加速，5 月还和 SpaceX 签了算力合作以提高速率上限。
- **分析**: Anthropic 的打法越来越清晰：消费端不做广告、不做免费墙，全部押注 B 端高 ARPU 客户 + 关键公共部门叙事（健康、安全、政府）。和 OpenAI 的"全民订阅 + 个人理财 + Codex 平台"路线形成鲜明分叉。对开发者来说，Claude 模型的稳定性、SLA、企业合规会持续优先于"炫技功能"。
- **影响与关注点**:
  - Opus 4.7 在 coding/agent 任务上比 4.5 提升明显，值得在自己的 Agent 栈里跑一轮 A/B
  - 关注 Anthropic 是否会推出针对发展中国家市场的低价/补贴版 API
