# AI Daily — 2026-04-25

## 一句话总览
DeepSeek V4 双模型空降把"前沿模型"价格击穿到 GPT-5.5 的 1/15，OpenAI GPT-5.5 同日开放 API，Anthropic 公开 Claude Code 三连问题复盘——开源/闭源/质量信任三条战线同一天爆点。

## 重点事件

### 1. DeepSeek V4 双模型发布：1.6T MoE，价格屠夫归来
- **来源**: [Simon Willison 评测](https://simonwillison.net/2026/Apr/24/deepseek-v4/) | [DeepSeek API 文档](https://api-docs.deepseek.com/) | [HN 1660 分](https://news.ycombinator.com/item?id=47884971)
- **发生了什么**: DeepSeek 发布 V4-Pro（1.6T 总参 / 49B 激活）和 V4-Flash（284B / 13B 激活）两个 MoE 模型，1M 上下文，MIT 许可，HF 权重已开放。Pro 成为目前**最大开源权重模型**，超过 Kimi K2.6（1.1T）和 GLM-5.1（754B）。
- **背景**: 距 V3.2（去年 12 月）约 4 个月。论文显示 V4-Flash 在 1M 上下文下 FLOPs 仅为 V3.2 的 10%、KV cache 7%——本次主打效率。
- **分析**: Flash 定价 $0.14/$0.28（输入/输出/M tokens）比 GPT-5.4 Nano 还便宜；Pro $1.74/$3.48 是所有"前沿级"模型里最低，仅为 GPT-5.5 的 1/15、Claude Opus 4.7 的 1/7。即使官方 benchmark 有水分，开源权重 + 1M 上下文 + MIT，足以让本地推理和私有部署链路被重新洗牌。MoE 激活参数小（13B/49B）意味着量化后单卡或 Mac Studio 也跑得动。
- **影响与关注点**:
  - 评估 V4-Flash 替换 RAG/批量推理链路上的 GPT-5.4 Nano / Haiku 4.5，纯成本可省 70%
  - 跟进社区量化（GGUF/AWQ）进度，Flash 160GB 是 Mac M5 128GB 的临界点
  - 关注 V4-Pro-Max reasoning 模式 benchmark 是否复现

### 2. OpenAI 发布 GPT-5.5，同日开放 API
- **来源**: [OpenAI 官方公告](https://openai.com/index/introducing-gpt-5-5/) | [HN 1503 分](https://news.ycombinator.com/item?id=47879092)
- **发生了什么**: 4/23 在 ChatGPT/Codex 上线 GPT-5.5 与 GPT-5.5 Pro，4/24 API 开放。Terminal-Bench 2.0 82.7%、Expert-SWE 73.1%、OSWorld 78.7%，多项 agentic / coding / computer-use 指标 SOTA。官方强调"per-token 延迟与 5.4 持平但更聪明，Codex 任务 token 消耗显著降低"。
- **背景**: 定位是"下一代办公电脑交互"，主推 agent 长链路任务（计划→工具→自查→继续）。同时附带新版 system card 与 cybersecurity / bio 红队评估。
- **分析**: 价格依旧贵（$5/$30），所谓"半价 SOTA"是和 Claude Opus 4.7 比，不是和 DeepSeek 比。和当日 DeepSeek V4 同框看，OpenAI 走"贵但收敛快、token 省"路线，DeepSeek 走"便宜大碗、自己拼工程"路线，开源 vs 闭源的成本差从 5x 拉到 15x。Simon Willison 已反向工程 Codex CLI 订阅做出 `llm-openai-via-codex`，订阅算力套利存在。
- **影响与关注点**:
  - Codex/Agent 类工作流可上 GPT-5.5；纯文本/RAG 不必跟
  - 留意 GPT-5.5 Pro API 何时正式放出
  - Codex CLI 订阅 + `llm-openai-via-codex`，对个人/小团队是性价比方案

### 3. Anthropic 罕见公开 Claude Code 质量复盘：三个独立 bug 叠加成"广泛降智"
- **来源**: [Anthropic 工程博客](https://www.anthropic.com/engineering/april-23-postmortem) | [HN 890 分](https://news.ycombinator.com/item?id=47878905)
- **发生了什么**: Anthropic 把过去一个月用户抱怨"Claude 变笨"溯源到三处：(1) 3/4 Code 默认 reasoning effort 从 high 调成 medium；(2) 3/26 一个本应只清理一次空闲 session 历史的 bug，每轮都触发清理→显得健忘；(3) 4/16 一条降啰嗦的 system prompt 反而压低了代码质量。三个修复 4/20 全部上线，4/23 重置所有订阅用户用量。
- **背景**: API 不受影响，仅 Claude Code / Agent SDK / Cowork 受影响；同日还有热文《I Cancelled Claude》冲到 HN 481 分，矛盾点正是 token 消耗和质量。
- **分析**: 罕见的高透明度复盘，工程姿态加分；但暴露 Anthropic 内部 eval 没能复现用户主观体验，对"产品层 prompt + 默认 effort"这种隐式变量缺乏回归。这是所有 agent harness 厂商通病：模型权重没改，但用户可见行为可以悄悄漂。
- **影响与关注点**:
  - 自己的 agent 链路也要做"端到端用户感知 eval"，不能只看 API 层指标
  - 关键 prompt / 默认参数变更走灰度 + 回归套件
  - 给客户做 SLA 时把 "harness 层变更" 纳入告知义务

### 4. Meta 宣布裁员 10%，"效率年"延续
- **来源**: [Bloomberg via HN](https://news.ycombinator.com/item?id=47879986)
- **发生了什么**: Meta 内部通告将裁员约 10%，理由仍是"效率"。
- **背景**: 与 2023 年那波"efficiency year"措辞一致；FAIR / Llama 是否波及尚未明确。
- **分析**: 大模型团队的人均产出被代码 agent 抬上去后，大厂都在重估非核心 AI 工程组织的必要规模。Infra / Research 短期不会大动，应用产品线和支撑岗会先挨刀。对人才市场是机会。
- **影响与关注点**:
  - 关注 FAIR / Llama 团队是否变动，影响开源节奏
  - 留意优秀 ML 工程师流向（创业 / DeepSeek 体系 / Anthropic 招人窗口）
