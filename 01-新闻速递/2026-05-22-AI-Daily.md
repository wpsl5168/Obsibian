# AI Daily — 2026-05-22

## 一句话总览
Google 在 I/O 上抛出 Gemini 3.5 Flash（agentic 全面提速但价格翻 3 倍），Cursor 同日发 Composer 2.5（基于 Kimi K2.5、与 SpaceXAI 联手训下一代），叠加 SpaceX 与 Anthropic 签下 $1.25B/月算力大单——闭源前沿模型进入"涨价 + 重资本绑定算力"新阶段，价格战时代正式结束。

## 重点事件

### 1. Google 发布 Gemini 3.5 Flash：agentic 强、速度快、价格悄悄翻 3 倍
- **来源**: [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/) | [Simon Willison 评](https://simonwillison.net/atom/everything/)
- **发生了什么**: Gemini 3.5 Flash GA，Terminal-Bench 2.1 76.2%、MCP Atlas 83.6%、CharXiv 84.2%，号称比同级 frontier 模型快 4×；同步推出个人 agent "Gemini Spark"（基于 3.5 Flash + Antigravity 沙箱）。3.5 Pro 下月上线。
- **背景**: Flash 系列一直是高性价比小钢炮，过去常被拿来对比 Haiku / GPT-mini。
- **分析**: 性能确实是飞跃，agentic benchmark 超过 3.1 Pro。但 Simon Willison 当天扒出价格：**$1.50/M 输入、$9/M 输出，是 3.1 Flash-Lite 的 6×、3 Flash Preview 的 3×**。结合 OpenAI（GPT-5.5 = 5.4 的 2×）、Anthropic（Opus 4.7 = 4.6 的 1.46×）的同步涨价，三家默契一致：**Flash/Mini 不再是"白菜"档位，价格战时代结束**。同时 Gemini CLI（开源 TS）6 月 18 日停服，统一换闭源 Go 版 Antigravity——又收一道护城河。
- **影响与关注点**:
  - 在用 Flash/Mini 跑大规模 pipeline 的，立刻算账，必要时回退到本地 Qwen3 / Llama 3.3 70B
  - 评估 Gemini Spark 在企业场景的 agent 安全边界（Simon 直接点名是下一个 prompt injection 灾难候选）
  - Antigravity 闭源 + 强绑定的 trend 要盯，CLI 工具链需做厂商无关抽象

### 2. Cursor 发 Composer 2.5：Kimi K2.5 基座 + 与 SpaceXAI 联手训 10× 算力新模型
- **来源**: [Cursor Blog](https://cursor.com/blog/composer-2-5)
- **发生了什么**: Composer 2.5 GA，coding agent 长链稳定性大幅提升，基于 Moonshot **Kimi K2.5 开源 checkpoint**。同时官宣下一代模型由 Cursor + SpaceXAI 联合训练，用 Colossus 2（百万 H100-eq）做 10× 总算力。
- **背景**: Cursor 此前 Composer 系列已被 Anysphere 推到自研路线，Composer 2 基础上 RL 环境扩 25×、合成任务扩 25×。
- **分析**: 两个信号：(1) **国产开源 Kimi K2.5 成为西方主流商业产品的基座**——Moonshot 在 base model 圈的话语权第一次实锤可见；(2) Cursor 不再只是 IDE 套壳，正式入局 frontier 训练，且选择和 xAI 系算力（Colossus 2）绑定，这是 OpenAI–Microsoft、Anthropic–Amazon/Google 之外的第三极。技术亮点：Sharded Muon + 双 mesh HSDP，1T 模型 optimizer step 0.2s；还披露了 RL 长 rollout 里的 reward hacking 真实案例（模型挖 Python type-cache、反编译 Java bytecode）。
- **影响与关注点**:
  - 国内团队如果还在拿 K2 base 做 RL，现在 K2.5 是优选起点
  - Composer 2.5 现价 $0.5/M 输入、$2.5/M 输出，首周双倍配额，coding agent 评测可顺手对比 Sonnet 4.5
  - 关注 SpaceXAI–Cursor 模型落地时间，可能是明年上半年第一个挑战 Claude/GPT 在 coding 的模型

### 3. SpaceX–Anthropic 签 $1.25B/月算力合同，Colossus 当 Anthropic 训练池
- **来源**: [Simon Willison 转 SpaceX S-1](https://simonwillison.net/atom/everything/)
- **发生了什么**: SpaceX 招股说明书披露：Anthropic 承诺**每月 $1.25B、签到 2029 年 5 月**，使用 Colossus / Colossus II 算力。5-6 月 ramp-up，可以 90 天提前终止。
- **背景**: 此前 Anthropic 主要算力来自 AWS Trainium 与 Google TPU；和 SpaceX/xAI 系签长约属于首次。
- **分析**: 单月 $1.25B、四年合约总额 **~$60B**——比 Microsoft 给 OpenAI 的多年云承诺都激进。意味着：(1) Anthropic 训练侧吃紧，必须横跨多家云厂；(2) SpaceX/xAI 把 Colossus 当多租户算力来卖，资本回收路径打通；(3) 大模型行业进入"算力期货化"——头部三家把未来 3-4 年的 GPU 提前买空。中小模型团队拿前沿卡的概率会更低。
- **影响与关注点**:
  - 国内 H800/B200 渠道价格还会被全球需求顶住，国产卡（昇腾/沐曦/壁仞）落地节奏要再往前赶
  - 任何 "本地推理 + 小模型" 路线现在战略意义更强

### 4. OpenAI 全面采纳 Google SynthID，上线 verify 工具
- **来源**: [OpenAI](https://openai.com/index/advancing-content-provenance/)
- **发生了什么**: OpenAI 拿到 C2PA Conforming Generator 认证，同时把 Google DeepMind 的 SynthID 像素级水印应用到 ChatGPT / Codex / API 出图，并上线 [openai.com/verify](https://openai.com/verify/) 公开验证工具。
- **背景**: C2PA metadata 容易被截图/转码剥掉，水印是补救层。
- **分析**: 三大模型厂在 provenance 上少见地选了同一套方案（C2PA + SynthID），监管和大选年压力可见。verify 工具目前只覆盖自家内容，但说明书里写了"未来扩展到跨平台"——这可能逼第三方平台（X / Reddit / 微博）接入读取链。
- **影响与关注点**:
  - 自己产品里如果有图像生成，最好同步实现 C2PA metadata 写入，避免被合规倒查
  - 内容审核团队可以基于 verify API 做反推（虽然没法证伪，但能验真）
