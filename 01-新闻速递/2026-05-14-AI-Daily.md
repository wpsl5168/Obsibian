## 重点事件

### 1. Anthropic 发布 Claude for Small Business
- **来源**: [anthropic.com/news/claude-for-small-business](https://www.anthropic.com/news/claude-for-small-business)
- **发生了什么**: 5/13 Anthropic 在 Claude Cowork 内推出"Claude for Small Business"，一键开启 15 个跨财务/运营/销售/HR 的 agentic workflow（payroll planning、month-end close、business pulse、campaign management 等），原生连接 PayPal、QuickBooks、HubSpot、Canva、Docusign、Google Workspace、Microsoft 365；任何"发送/张贴/付款"动作前必须用户审批。同时与 PayPal 合开免费 AI Fluency 课，并启动覆盖 10 个城市的线下 SMB Tour（首站芝加哥 5/14）。
- **背景**: SMB 占美国 GDP 44%、雇用近半私部门员工，但 AI 渗透率显著落后大企业；50% SMB 主把"数据安全"列为最大障碍，是这次产品定位的核心抓手。
- **分析**: 这不是新模型，是新分发——Anthropic 用 connector + skill + 现成 workflow 把 Claude 包装成"会算账会开月结"的虚拟员工，而不是"对话框 + API"。一旦把 QuickBooks/PayPal 这种 SMB OS 级工具的写权限拿到手，护城河比模型本身更深。这步也是直接对位 Microsoft Copilot 在 SMB 渠道（Copilot Pro / 365 Copilot）的渗透；同时为未来计费提价铺路（"会替你省下会计费用"的故事好讲）。
- **影响与关注点**:
  - Skill / connector 生态将变成各家 LLM 厂商的下一个主战场，关注 Anthropic 后续是否开放第三方 skill marketplace。
  - 国内类似垂直（金蝶/用友/微店/小鹅通做 connector）会很快跟进，老王这边自己的 skill 体系正好是这条路线。

### 2. Cactus 开源 Needle：26M 参数蒸馏 Gemini 3.1 的端侧函数调用模型
- **来源**: [github.com/cactus-compute/needle](https://github.com/cactus-compute/needle)（HN 678pt 197 评论，今日 #1）
- **发生了什么**: Cactus Compute 开源 26M 参数的 Simple Attention Network「Needle」，专为手机/手表/眼镜的 function calling 场景蒸馏自 Gemini 3.1。预训练 200B token（16 张 TPU v6e × 27h），post-train 仅 2B token × 45min；prefill 6000 tok/s，decode 1200 tok/s。在单轮函数调用 benchmark 上击败 FunctionGemma-270m、Qwen-0.6B、Granite-350m、LFM2.5-350m。MIT，权重和数据集生成代码全开。
- **背景**: 端侧"小而专"模型是 2025 年下半年开始的明显趋势（Gemma 3n、Qwen3 0.6B、LFM2.5），Needle 把蒸馏目标完全聚焦到 tool/function calling 这一个动作，体积小一个数量级。
- **分析**: 这是 agent 工程化路线的关键一格——Planner（云端大模型）+ Executor（设备端 26M 模型）的分工正在被验证。"Needle 能跑在 Cactus 推理引擎上"也强烈暗示 Cactus 在卖一个端侧 runtime 的故事，Needle 是 demo+引流。对国内做硬件 agent（手表、车机、AI 眼镜）的团队，这个思路（先蒸馏到只会 function call，再微调到自家 tool schema）比直接塞 1B+ 模型更现实。
- **影响与关注点**:
  - 跟进 Cactus 推理引擎是否开源、是否支持 Android NNAPI / Core ML / NPU。
  - 我们自己的 skill / tool 体系，可不可以拿一个 sub-1B 模型（Qwen3-0.6B 或 Needle）做本地 first-pass 路由，云端只兜底复杂规划？

### 3. Google DeepMind: 给 AI 时代重新设计鼠标指针
- **来源**: [deepmind.google/blog/ai-pointer](https://deepmind.google/blog/ai-pointer/)
- **发生了什么**: DeepMind 提出"AI Pointer"——把 Gemini 嵌入鼠标指针本身，让用户可以指着任意 app 里的 PDF/图表/代码块/视频帧，用自然语言"修这个、把那个搬过来"，无需切到 AI 窗口；已在 Chrome 落地，Googlebook 笔电会带"Magic Pointer"。AI Studio 上有 demo（编辑图片、地图找位置）。
- **背景**: 鼠标指针 50 年没大变；OpenAI Operator、Anthropic Computer Use、Apple Intelligence 的 selection-based AI 都在抢"系统级 AI 入口"。
- **分析**: 这是 OS 级 UX 的争夺，不是 demo。指针 = 上下文捕获器（视觉 + 语义 + 你正在看的元素），比聊天框天然多一维信息，能压缩 prompt 长度。Google 的优势是 Chrome + ChromeOS + 自家硬件三件套都能塞这套交互；Apple 走 Highlight + Writing Tools 路线、Microsoft 走 Copilot key + Recall 路线，三家终于把战线推到了"指针/选区/键"这种最底层 OS 元素。
- **影响与关注点**:
  - 短期内会反向倒逼 Web 应用提供更结构化的 DOM 标注（schema.org 类的"AI 元数据"）以便指针 AI 拿上下文。
  - 我们做 web/桌面工具时，可以提前考虑暴露"selection → action"这一层 API，避免被 AI 入口架空。

### 4. Simon Willison 速记：GitLab 重组 + Shopify "River" Agent 的反向洞察
- **来源**: [simonwillison.net](https://simonwillison.net/)
- **发生了什么**: (a) GitLab 宣布为"agentic era"瘦身：减 30% 小国家团队、砍最多 3 层管理、把研发拆成约 60 个独立小队；CEO 抛出"开发者平台月费正从几十美元飞向几千美元"的判断（注意：GitLab 股价一年从 $52 跌到 $26，立场有偏）。(b) Tobias Lütke 透露 Shopify 内部 coding agent "River" 只在公共 Slack channel 工作，明确拒收 DM——他叫这套范式"Lehrwerkstatt（教学工作坊）"，靠"被围观"产生组织性学习。
- **背景**: agent 产出代码量在涨，James Shore 的反向警告同步在传："如果产出翻倍但维护成本没减半，等于把临时加速换成永久债务"。
- **分析**: 这两件事拼起来很有意思——River 把 agent 强制公开化，本质是用"可见性"对冲"维护成本爆炸"风险（任何人都能学、能 review、能 debug）；GitLab 的小队化 + 砍管理层，对应的是"agent 让小团队拿到大团队产能后，中层不再必要"。如果这个范式成立，未来一年我们看到的不是"AI 替代程序员"，而是"AI 替代项目经理 + 中层管理"。
- **影响与关注点**:
  - 团队内部的 agent 输出，强制走公开 channel（飞书群 / Slack / Discord）而非私聊，是低成本高 ROI 的实践。
  - Code review 流程要把"维护成本"作为显式 metric（PR diff 行数 vs. 后 30 天 incident 数），否则 agent 加速 = 债务加速。
