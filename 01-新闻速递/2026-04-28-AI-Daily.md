# AI Daily — 2026-04-28

## 一句话总览
微软-OpenAI 排他协议正式终结、OpenAI 可上任意云、Anthropic 与 Amazon 再加 5GW 算力——AI 基础设施版图在今天进入「多云+多甲方」的新阶段；同时开源侧 Codex/Claude Code 工具链与开源语音模型（VibeVoice）继续狂飙。

## 重点事件

### 1. 微软-OpenAI 关系重构：排他结束、营收分成取消
- **来源**: [OpenAI 官方公告](https://openai.com/index/next-phase-of-microsoft-partnership/) ｜ [Bloomberg 报道](https://www.bloomberg.com/news/articles/2026-04-27/microsoft-to-stop-sharing-revenue-with-main-ai-partner-openai)
- **发生了什么**: 4/27 OpenAI 与微软签署修订协议：① 微软仍是「主要云伙伴」，但 OpenAI 产品可向任意云客户分发；② 微软对 OpenAI IP 的授权延至 2032 年，但**不再排他**；③ 微软**不再向 OpenAI 支付收入分成**；OpenAI 仍按比例向微软分成至 2030 年（设有总额上限）。
- **背景**: 此前 Azure 是 OpenAI 训练/推理的独家上游，且双向收入分成深度绑定。Anthropic 同期与 Amazon 扩展至 5GW、与 Google/Broadcom 合作多 GW 下一代算力，OpenAI 显然需要绕开 Azure 的供给瓶颈。
- **分析**: 这是 OpenAI 走向「云中立」的关键一刀。短期它能把推理流量分散到 Oracle/CoreWeave/Google，缓解 Azure 容量焦虑；长期则替 IPO 清障——排他条款在公开市场是估值毒药。微软这边也乐于松绑：自家 Phi/MAI 模型和 Anthropic 接入正在替代部分 OpenAI 流量，少付一笔分成等于变相涨利润。这是双赢式分手，但意味着「AI 双寡头深度联姻」的叙事结束，未来是「OpenAI vs Anthropic vs Google」三方各自抓多家云的开放战局。
- **影响与关注点**:
  - 关注 OpenAI 是否会很快宣布 GCP/AWS 上的 Responses API endpoint
  - Azure OpenAI Service 的差异化（独占模型？延迟？）会被稀释，企业选型将更看价格
  - 国内出海团队可借机谈到更便宜的 OpenAI 推理报价

### 2. GPT-5.5 上线，OpenAI 把 Codex 与主模型彻底合一
- **来源**: [OpenAI Introducing GPT-5.5](https://openai.com/index/introducing-gpt-5-5/) ｜ [Simon Willison 解读](https://simonwillison.net/)
- **发生了什么**: 4/23 GPT-5.5 在 API 开放，主打 agentic coding、computer use 与多步任务的稳健性提升。官方确认自 GPT-5.4 起 Codex 已与主模型统一为单一系统，「不再有独立编码线」。Prompting Guide 同步发布。
- **背景**: 自 GPT-5 起 OpenAI 一直在收敛「reasoning / coding / instant」三条产品线。Anthropic 4/16 刚发 Claude Opus 4.7（编码、agent、视觉全面增强），节奏直接对标。
- **分析**: 工程师视角：Prompting Guide 明确「不要把 5.4 的 prompt 直接搬过来」，要从最小可用 prompt 重新调 reasoning effort + verbosity。这是 OpenAI 第一次正式承认大版本之间 prompt 不兼容——意味着 prompt 资产进入「按模型代次维护」的时代，CI 里要为每个模型 pin 一套 eval。另一个细节：官方推荐的「多步任务前先发一段用户可见的 ack」是个工程小技巧，本质是用文本流降低用户「卡死了？」的焦虑。
- **影响与关注点**:
  - 检查现有 Codex 调用是否要切到 gpt-5.5（成本/延迟基准要重新跑）
  - prompt 仓库上 5.4 / 5.5 双版本，建立回归 eval
  - 关注 computer use 的实际成功率（HN 上还没看到大规模 benchmark）

### 3. Anthropic 算力大扩张 + 日本工程师军团
- **来源**: [Anthropic News](https://www.anthropic.com/news)
- **发生了什么**: 4/20 Anthropic 与 AWS 扩展合作，新增高达 5GW 算力；4/24 与 NEC 合作建设「日本最大 AI 工程师团队」；同期 4/16 发布 Claude Opus 4.7。
- **背景**: 在 OpenAI 与微软松绑的同一周，Anthropic 在云、地缘、人才三条线全开。
- **分析**: 5GW 是个什么概念——大约相当于今天美国所有头部 AI 实验室总耗电的 1/3 级别，单轮采购就把 Anthropic 推到与 OpenAI 同量级算力供应。叠加 Google/Broadcom 的下一代芯片合作，Anthropic 在「不依赖单一云、不依赖单一硬件」的多元化上比 OpenAI 还激进。NEC 合作则是抓日本企业 SI 市场——日本是 Claude 编程渗透率最高的非英语市场之一。
- **影响与关注点**:
  - Claude Sonnet/Opus 的 API 容量限制有望年内放宽
  - 日本市场 B2B AI 集成项目机会增加
  - 关注 Anthropic 自研芯片/Trainium2 上 Claude 的实际定价

### 4. 安全/治理：Mercor 4TB 语音数据泄露、中国否决 Meta 收购 Manus
- **来源**: HN 头条聚合（Bloomberg/CNBC/Reuters/BBC）
- **发生了什么**: ① Mercor（AI 标注/合同工平台）发生数据泄露，4 万名 AI 承包商的 4TB 语音样本被盗；② 中国监管否决 Meta 收购国产 Agent 公司 Manus。
- **背景**: 语音克隆+TTS 模型已经达到「3 秒样本就能复刻」的水平（参考 Microsoft VibeVoice 今天还在 GitHub Trending 第一梯队）。Manus 是去年爆红的通用 Agent。
- **分析**: 4TB 高质量配对语音是训练 voice clone / 反检测模型的金矿，黑产链路接下来 6 个月会出现一批针对企业语音验证（电话银行、客服）的攻击。Manus 案则进一步确认：中美 AI 资产的跨境收购窗口已基本关闭，国产 Agent/模型会被强制留在国内并购链里。
- **影响与关注点**:
  - 内部任何使用语音作为身份认证的环节立刻评估替换（活体+口令）
  - 出海产品里若用了 Mercor 标注，检查合同与数据脱敏条款
  - 投资视角：国产 Agent 公司估值受抑，但 IPO/被国央企并购的可能性上升

### 5. 开源工具链：Codex Skills 仓库与 Claude Code 镜像井喷
- **来源**: [GitHub Trending 今日](https://github.com/trending?since=daily)
- **发生了什么**: 今日 trending 前列：`ComposioHQ/awesome-codex-skills`（+637 stars/24h，Codex CLI 的实用 skill 集合）、`Alishahryar1/free-claude-code`（+2,973 stars/24h，「免费用 claude-code」镜像项目）、`microsoft/VibeVoice`（开源前沿语音模型）、`davila7/claude-code-templates`。
- **背景**: Codex CLI 与 Claude Code 已成为 AI 编程的事实标准入口；社区围绕「skill/template 复用」与「绕过付费」两条线快速生长。
- **分析**: `awesome-codex-skills` 这种聚合仓的爆发说明 Codex skills 已形成可复用的二级生态——和 Hermes Agent 的 skills 思路一致，工程界正在收敛到「procedural memory as files」。`free-claude-code` 这类项目则是灰色地带（多半基于逆向 token 或共享账号），不建议生产使用，但能反映用户对 Claude Code 价格的不满。VibeVoice 持续强势，开源 TTS/voice clone 已经追平闭源。
- **影响与关注点**:
  - 复盘自己的 Hermes skills，看哪些能直接吸收 awesome-codex-skills 的模式
  - 评估 VibeVoice 替换商用 TTS 的可行性（许可+延迟）
  - `free-claude-code` 类项目不要在公司机器上装，账号风险
