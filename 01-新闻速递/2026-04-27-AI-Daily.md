## 重点事件

### 1. Anthropic 发布 Claude Opus 4.7，把"过强能力"做减法
- **来源**: [CNBC 报道](https://www.cnbc.com/2026/04/16/anthropic-claude-opus-4-7-model-mythos.html)
- **发生了什么**: 4 月 16 日 Anthropic 发布 Opus 4.7，定位为"通用可用模型里最强"，但有意把 cyber 攻击相关能力训练成低于 Mythos Preview 的水平，并内置自动检测/拦截高危网络安全请求的安全护栏。价格与 Opus 4.6 持平，全平台（API + 三大云）同步上线。
- **背景**: Mythos Preview 此前只通过 Project Glasswing 给少数企业试用，已经触发美国政府/银行高管层关于"前沿模型该不该普及"的讨论。Opus 4.7 是 Anthropic 给出的一个折中样本：留住生产力，砍掉政策风险。
- **分析**: 这一手非常"Anthropic"——它在用产品行动把 RSP/能力门槛具象化，给监管侧一个可以指着说"看，可以这样做"的范本。坏消息是 cyber 能力做差异化降级会形成一个长期"双轨制"：高能力版只对白名单开放，普通开发者拿到的永远是"被削过的 Opus"。对比 OpenAI/Google 的"全量推送 + 事后过滤"路线，Anthropic 选了 capability-shaping。这也是为什么它在政企客户那边越来越吃香。
- **影响与关注点**:
  - 我们做 Agent 工具链时要预期：Claude 系列在涉及"渗透/逆向/exploit 生成"类提示上拒答率会更高，安全相关 Agent 流程要做模型路由 fallback。
  - 关注 Anthropic 后续会不会把 Opus 4.7 的护栏 API 化（让开发者能复用同一套"危险请求分类器"）。

### 2. OpenAI $122B 融资落地，"AI Superapp"路线明牌
- **来源**: [OpenAI 官方公告](https://openai.com/index/accelerating-the-next-phase-ai/)
- **发生了什么**: 3 月 31 日官宣 $122B 已承诺资本，post-money $852B。月营收 $20亿，ChatGPT 9 亿周活、5000 万付费订阅，Codex 周活 200 万、3 个月 5×增长。同时披露 Superapp 战略：单一系统，跨 app/数据/工作流执行用户意图。
- **背景**: 战略投资方继续 Microsoft + Nvidia + SoftBank + Amazon + a16z；硬件侧 Nvidia 仍是基座，但 AMD / AWS Trainium / Cerebras 与 Broadcom 自研芯片同步推进，云侧从 Azure 单边扩成 Azure+Oracle+AWS+CoreWeave+GCP 多边。
- **分析**: 钱不重要了，分布式算力布局才是重点——这是"再不能让任何单一供应商卡脖子"的明牌。Superapp 是 OpenAI 想拿走"操作系统级入口"的信号，比 GPT-5.x 模型本身更值得警惕。Codex 5× 增速+API 1500 万 tok/min 也说明：编码 Agent 是当下唯一被 Bigtech 验证的高 ARR 应用形态。Enterprise 占比 >40% 也意味着 OpenAI 的产品节奏会越来越偏 B 端。
- **影响与关注点**:
  - "Codex 正在变成 GitHub Copilot 真正的接班人"——独立工具厂商（Cursor / Cline 等）压力陡增，我们做 Hermes Agent 要警惕 OpenAI 把 Codex 的 backdoor API（参考下面 Simon Willison）逐步收紧。
  - Superapp 出来后 RAG/Memory/插件 中间层市场会被压缩，要么 vertical 化，要么走开源路线。

### 3. Google "Gemini Drop" 4 月版：把 NotebookLM 塞进 App，Mac 原生上线
- **来源**: [Google Blog](https://blog.google/innovation-and-ai/products/gemini-app/gemini-drop-april-2026/)
- **发生了什么**: 第 10 期 Gemini Drop 一次推 5 件套：Personal Intelligence + Nano Banana 个性化图像生成、Personal Intelligence 全球化（EEA/英/瑞/韩/澳/尼日利亚除外）、NotebookLM 整合进 Gemini App、原生 macOS 客户端、Lyria 3 Pro 免费 3 分钟音乐生成、对话内交互式可视化。
- **背景**: Google 正在把 Gemini 从"对话框"重塑为"个人 OS 层"；同月 Simon Willison 也提到 Gemma 4（2B/4B/26B-A4B MoE/31B）开源发布，多模态 + Per-Layer Embeddings 提效路线确立。
- **分析**: Google 的打法和 OpenAI 的 Superapp 殊途同归——都在打"用户上下文+原生入口"。NotebookLM 进 Gemini 是过去半年最被低估的整合，意味着"对话 + 文档项目空间"成为标配，单纯做笔记/RAG 的初创基本要被卷死。原生 Mac 客户端值得 dogfood 一下，Lyria 3 免费 3 分钟则是奔着 Suno / Udio 去的。
- **影响与关注点**:
  - 我们要把 Gemini 3.1 Pro / Flash-Lite 的价格 × 上下文重新评估一次，决定 Hermes 默认模型的路由策略。
  - 关注 Personal Intelligence 接入 Google Photos/Calendar 后产生的"上下文泄漏"问题，企业用户合规会有疑虑。

### 4. Simon Willison：通过 "Codex backdoor API" 测了 GPT-5.5
- **来源**: [Simon Willison 4/23](https://simonwillison.net/2026/Apr/23/gpt-5-5/)
- **发生了什么**: Simon 用一条半官方的 Codex 后门 API 路径跑通了 GPT-5.5，并用经典的"鹈鹕骑自行车 SVG"进行能力测试。同期他还在追 Gemma 4 全系本地推理（LM Studio GGUF 部分跑通，31B 当前有 bug）。
- **背景**: 围绕 Claude Code 是否要涨到 $100/月 也炒得很热（Simon 4/22 文章），开发者群体对 Agent 工具的定价/锁定开始警觉。
- **分析**: GPT-5.5 通过"非主入口"被验证存在，意味着 OpenAI 内部已经接近发布；从能力评估方法看，社区已经默认"鹈鹕骑车 SVG + pelicans_riding_bicycles"作为非污染基线测试，对我们做 eval 有借鉴价值。Gemma 4 的 26B-A4B MoE + PLE 路线如果稳定，会是本季度最强的本地推理选项。
- **影响与关注点**:
  - 准备好 GPT-5.5 上线时的快速基准脚本（pelican test + 我们自己的 Hermes Agent 任务集）。
  - Gemma 4 31B GGUF 等修复后再纳入本地默认推理候选。
