# AI Daily — 2026-05-13

今日AI圈三条主线：DeepMind把"鼠标指针"重新发明成AI入口；OpenAI Realtime API升级到GPT-5级语音推理；Anthropic拿到SpaceX的300MW算力，Claude Code限额翻倍——巨头们正在从"模型层"全面卷向"交互层+算力层"。

## 重点事件

### 1. Google DeepMind：重新定义"鼠标指针"为AI交互入口
- **来源**: [DeepMind Blog](https://deepmind.google/blog/ai-pointer/)（HN 210 points / 178 comments，今日热度第一）
- **发生了什么**: DeepMind 5月12日发布 "AI Pointer" 概念与 Chrome 集成版本，让 Gemini 通过指点+语音理解上下文（"Fix this", "Move that here"），把图片/PDF/代码块当作可操作实体，而非把用户拽进单独的 AI 对话窗口。
- **背景**: 2025年以来 ChatGPT/Claude/Gemini 都困在"独立窗口"的交互模式里——用户必须把上下文复制粘贴进去。Apple Intelligence 的 "Writing Tools" 算半个回应，但仍是模态弹窗。
- **分析**: 这是2026年最值得警惕的 UX 范式转移信号。"指哪打哪"+"this/that 指代"如果在 Chrome/ChromeOS 全面铺开，将直接侵蚀 Copilot/ChatGPT 桌面应用的入口位置。本质上 Google 在用 OS 级别的分发能力打 OpenAI 的产品壁垒——和当年 IE 打 Netscape 同款剧本。技术上没有新东西（多模态+grounding 都是2024年的），但产品形态足以重写竞争格局。
- **影响与关注点**:
  - 国内做 AI 助手类产品的需要尽快做"hover-to-act"的最小可用版本，否则2026下半年会被边缘化
  - 关注 ChromeOS 6月份的 Magic Pointer 配套硬件（Googlebook）
  - 评估对自家产品 grounding 数据管线的影响：从"对话级"上下文迁移到"光标级"上下文

### 2. OpenAI Realtime API 三连发：GPT-Realtime-2 + Translate + Whisper
- **来源**: [OpenAI Blog](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/)
- **发生了什么**: 5月7日发布 GPT-Realtime-2（首个 GPT-5-class 推理的语音模型，128K 上下文），Big Bench Audio +15.2%，Zillow 实测呼叫成功率从69%飙到95%。配套 Translate（70种入13种出）和 Whisper 流式版。定价 $32/1M 音频 in，$64/1M out。
- **背景**: GPT-Realtime-1.5 因为只有 32K 上下文+无 reasoning，落地客服场景很尴尬；同期 Anthropic 还没正式放出语音端到端模型。
- **分析**: 26点的呼叫成功率提升说明"语音+推理"的工程瓶颈被打通了，今年下半年将出现一批严肃的 voice agent 创业公司（不再是 demo 玩具）。Preambles（"让我查一下"）+ 可调推理强度（minimal→xhigh）是工程友好的设计，明显冲着替代传统 IVR/呼叫中心去的。$0.034/分钟的翻译定价低于 Deepgram，这是降维打击。
- **影响与关注点**:
  - 评估能否把客服/外呼场景从传统 ASR+LLM+TTS 三件套迁移到 Realtime API（延迟、成本、可控性三选二）
  - 翻译场景重新评估自研 vs API：$0.034/分钟基本判了大部分自研方案死刑
  - 国内合规场景仍需关注火山/通义的 Realtime 类产品对标进度

### 3. Anthropic × SpaceX：300MW 算力交易，Claude Code 限额翻倍
- **来源**: [Ars Technica](https://arstechnica.com/ai/2026/05/anthropic-raises-claude-code-usage-limits-credits-new-deal-with-spacex/)
- **发生了什么**: 5月6日 Code with Claude 大会上 Dario Amodei 宣布拿下 SpaceX 孟菲斯数据中心 300MW+ 容量（含 22万张 H100/H200/GB200 的 Colossus 1）。Pro/Max 用户的 Claude Code 5小时窗口限额翻倍，高峰期降速取消。马斯克从2月"Anthropic hates Western Civilization"180度转身。
- **背景**: 4月份 Anthropic 已拿到微软、谷歌（最高400亿）、亚马逊（50亿芯片）、英伟达的投资，但因为 OpenAI 军事合约风波导致用户大量迁移+多 agent 工作流爆发，算力赤字依然严重。
- **分析**: 这单交易最有意思的不是算力数字，而是马斯克的态度反转——侧面说明 xAI 自己的 Grok 在企业代码场景已经被 Claude Code 拉开差距，与其硬刚不如赚算力中间费。Anthropic 提到"轨道算力（多 GW）"是认真的，2027-2028年地面电力/冷却/土地确实会成为前沿模型训练的硬约束。短期内 Claude Code 用户体验回血，对 Cursor/Cline 这种依赖 Sonnet 的下游是利好。
- **影响与关注点**:
  - 重度 Claude Code 用户可以恢复积极使用，限额痛点缓解
  - 关注 Opus 4.7 API 限额提升的具体数字（公司博客有细节）
  - 长期：算力地缘政治进入新阶段，国产替代窗口期反而被放大

### 4. OpenAI 安全双更：GPT-5.5-Cyber + Codex 安全运行
- **来源**: [OpenAI News](https://openai.com/news/)
- **发生了什么**: 5月7-8日连发 "GPT-5.5 & GPT-5.5-Cyber: Scaling Trusted Access for Cyber" 和 "Running Codex safely at OpenAI" 两篇技术文，针对企业级网安和代码 agent 沙箱化做了系统性能力升级。
- **分析**: 这是对前几周 Anthropic Project Glasswing（联合 AWS/Apple/JPM 等做关键软件安全）的直接回应。安全是2026年企业 AI 落地的最后一公里——agent 跑起来谁都行，跑得安全才能签合同。
- **影响与关注点**:
  - 自建 coding agent 沙箱的团队建议参考 OpenAI Codex 安全设计文档（容器隔离、网络白名单、审计日志）
