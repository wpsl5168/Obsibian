# 角色赋能 — 五层用户的 AI 工具地图

> 不同层级、不同条线的用户，需要的 AI 形态不一样。**别想着"一个 ChatGPT 解决所有事"**。

## 五层用户

```
行领导    →  战略驾驶舱（聚合 + 趋势 + 跨条线 + 行业对标）
分行领导  →  分行驾驶舱（异常预警 + 下钻 + 业绩归因）
部门总    →  业务驾驶舱（客群分析 + 政策评估 + 资源调度）
支行长    →  支行驾驶舱（团队业绩 + 风险监控 + 重点客户）
客户经理  →  RM 副驾驶（拜访 + 申请 + 服务 + 学习）
```

## 客户经理 — RM 副驾驶（最值钱、最早见效）

**对标**：招行 AI 小招 / 建行帮得助理 / 民生慧销 / 光大对公 RM 助手

### 核心场景 20+

**拜访前 4 件套**
- 客户 360 画像（基础信息 + 持仓 + 资金流 + 关联企业 + 舆情）
- 上次拜访纪要 + 待办事项
- 行业研报摘要（基于客户所属行业）
- 产品匹配建议（基于客户需求洞察）

**拜访中**
- 语音转写 + 实时纪要
- 政策/产品速查（解答客户提问）
- 异议应对话术（合规库内）

**拜访后**
- 自动生成拜访纪要 + 客户标签更新
- 商机识别 + 工单生成
- 待办分派 + 跟进提醒

**业务办理辅助**
- 授信申请草稿（基于客户资料 + 历史批复模式）
- KYC 资料检查（缺什么、不规范的）
- 产品方案生成（综合营销方案）
- 标书辅助（平安已落地）

**学习与查询**
- 制度问答（贷款政策 / 反洗钱规则 / 合规要求）
- 产品速查
- 同业对标（公开信息）
- 历史相似案例

### 量化目标
- 触客次数 +14%（招行参考值）
- 单户管理上限：2k → 2 万（建行帮得助理）
- 工时节省：日均 1-2 小时
- 采纳率：>80%（民生 84%）

## 团队长 / 支行长 — 团队管理副驾驶

- **团队看板**：业绩进度 + 客户分布 + 风险预警
- **重点客户提醒**：大客户异动、高风险、流失风险
- **资源调度**：客户经理任务量均衡、案件分配建议
- **合规巡检**：自动扫描团队待办，标记合规问题
- **培训助手**：基于团队短板推送培训内容

## 部门总（对公部 / 风险部 / 零售部）— 业务驾驶舱

- **客群分析**：客户结构变化、行业分布、贡献度
- **政策评估**：新政策上线后业务指标变化、归因分析
- **资源调度**：分支机构业绩对比、人员/产品/费用配置建议
- **风险预警**：行业集中度、单一客户风险、合规事件
- **同业对标**：公开年报/研报数据汇总

## 分行领导 — 分行驾驶舱

- **本分行 vs 行平均**：所有 KPI 自动对标
- **异常预警 + 一键下钻**：哪个支行哪个产品掉得快？
- **业绩归因**：增长/下滑的因子分解
- **重大客户跟踪**：本分行 TOP100 客户全景
- **合规与监管动态**：本辖区监管要求变化

## 行领导 — 战略驾驶舱

- **全行 KPI 全景**（日/周/月/季）
- **跨条线对比**（对公 vs 零售 vs 同业）
- **趋势预警**（与历史/同业的偏离）
- **行业宏观联动**（GDP / 利率 / 政策）
- **战略议题深度报告**（按需生成，如"科创金融现状 + 同业对标"）
- **AI 摘要的董事会材料**

### 行领导级别的红线
- **结论 + 证据链** — 行领导不接受"模型说的"，必须能溯源到数据/制度/案例
- **审计完整** — 所有查询/生成全程留痕，5 年起
- **可解释优先** — 关键决策禁用纯生成式模型独立给结论

## 跨条线特殊场景

- **AI 合规官** — 全行政策/制度库 + 制度冲突检测 + 新规影响评估
- **AI 内审** — 异常交易检测 + 案例库 + 审计报告辅助
- **AI 数据分析师** — 自然语言问数（参考招行管理驾驶舱 Data Agent）
- **AI 战略研究员** — 行业报告生成 + 同业对标 + 趋势研判
