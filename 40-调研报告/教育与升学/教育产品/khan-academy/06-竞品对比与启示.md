# Khan Academy 竞品对比与做中文版的启示

## 1. 主流学习平台横向对比

| 维度 | Khan Academy | IXL | Brilliant | Coursera | Duolingo |
|---|---|---|---|---|---|
| **定位** | 免费 K-12 mastery + SAT | 付费 K-12 题海 + 自适应 | 付费 STEM 互动学习 | 大学 MOOC | 语言（数学新增） |
| **核心优势** | 免费、视频系统、SAT 官方 | 题量大、题型丰富、报告详细 | 互动可视化、培养思维 | 大学正规课程、证书 | 游戏化、习惯养成 |
| **核心劣势** | 概念浅、互动弱、视频老 | 纯刷题易枯燥、贵（\$13/月起） | 不对齐学校大纲 | 太难、不适合儿童 | 学术深度不够 |
| **价格** | 免费（Khanmigo \$44/年） | \$13-20/月 | \$13.49/月 | \$59/月 | 免费 / \$7/月 |
| **最佳搭配** | 初学 + SAT | 强化练习 | 8 年级以上拓展思维 | 大学预修 | 兴趣启蒙 |

### 典型搭配建议（综合 Studley AI、Brighterly 多篇对比）

- **K-5**：Khan Kids + IXL（IXL 题量补 Khan 不足）
- **6-8**：Khan Academy（讲解）+ IXL（练习）
- **9-12 STEM 拔高**：Brilliant + Khan
- **SAT 备考**：Khan Academy 官方练习（首选）
- **高阶数理**：MIT OCW、3Blue1Brown、Brilliant > Khan

## 2. AI Tutor 类产品对比

| 产品 | 定位 | 核心差异 |
|---|---|---|
| **Khanmigo** | K-12 全科 tutor + 教师助手 | 苏格拉底法、绝不给答案、和 KA 内容库强耦合、非营利、**安全护栏最完整** |
| **ChatGPT (Study Mode)** | 通用 LLM 学习模式 | 灵活但**默认给答案**，无内容 grounding，老师/家长无法监管 |
| **Photomath** | 拍照解数学 | 给完整解题步骤，**反 Khanmigo 哲学**——快速但易养成抄答案习惯 |
| **Brilliant + AI** | STEM 交互课程 | 课程驱动 + 偶尔 AI 答疑，不是 conversational tutor |
| **Duolingo Max (GPT-4)** | 语言学习 | "Explain my answer" + "Roleplay"，**也用了苏格拉底反问**，但仅限语言场景 |
| **猿辅导/作业帮 AI 答疑** | 中国 K-12 拍照答疑 | 偏 Photomath 路线——给详解，重知识图谱召回，弱对话引导 |
| **小猿口算 AI** | 低年级数学 | OCR + 步骤判错，少对话 |
| **学而思九章大模型** | 中国数学专用大模型 | fine-tune 路线，强在中文数学推理，产品形态仍以"批改+讲解"为主 |

## 3. 给老王做"中文版 Khanmigo"的 5 条核心启示

### 3.1 必须想清楚的产品根本问题

**①"不给答案"是灵魂，但与中国家长冲突**
中国家长/学生普遍要"快、准、直接给"——苏格拉底法在中国可能水土不服。
- **建议方案**：**双模式**——考前救急模式（给答案）vs 学习模式（苏格拉底）
- 让用户主动切换，避免一上来就反人性

**② B 端还是 C 端？**
Khanmigo 用 **B2B2C**（学校/老师免费当渠道）+ C 端订阅。
- 中国 K-12 **校内 AI 受双减 + 生成式 AI 备案限制**，校内渠道难
- **更可行**：**家长 C 端 + 教培机构 B 端**

**③ 定价锚点**
\$4/月 ≈ ¥29/月。
- 中国家长习惯**按科目/按课时**付费，订阅制接受度还要教育
- **建议**：按科目订阅（数学 ¥19、语文 ¥19、英语 ¥19）+ 全科套餐 ¥49

### 3.2 技术上可直接借鉴

- **Prompt as Product**：Khanmigo 没做 fine-tune，纯靠 system prompt + 内容 grounding 跑出 70 万用户。中文版基于 **DeepSeek / Qwen / GLM** 同样玩法
- **内容库是护城河**：没有 KA 那种 842 门课，就要找**强教材合作**（人教社、北师大版、五三、黄冈密卷数字化）
- **A/B 测试管线**：每个 prompt 迭代都 A/B 看下一题正确率，**这套机制比模型本身更重要**
- **角色扮演**：跟李白对话、跟王安石辩论变法、跟鲁迅论 AI——**中文文史场景比英文更有戏剧张力**
- **安全护栏**：必须有家长/老师可查全部对话 + moderation alert，这是 toC 教育产品的合规底线

### 3.3 中文市场差异化机会

| 机会 | 说明 |
|---|---|
| **中考/高考刚需** | 英文 Khanmigo 没有的"应试压力场景"——做苏格拉底式**真题精讲**有独特价值 |
| **作文批改** | 中文议论文/记叙文有明确的"立意-结构-论据-语言"四维，**比英文 essay 更可结构化反馈** |
| **多模态拍题** | 中国学生作业以纸质为主，**手机拍照 + 苏格拉底引导** 是 Khanmigo 还没真正攻下的形态 |
| **语音 tutor** | 低年级孩子怕打字，**语音对话是巨大空间**（参考 Sal Khan 自己也在押注 voice） |
| **家长 Dashboard 强需求** | 中国家长焦虑度远高于美国家长，**学情简报 + 学习建议 + 弱项推送** 可能比 tutor 本身更付费 |

### 3.4 主要风险

| 风险 | 说明 |
|---|---|
| **政策** | 生成式 AI 服务深度合成 + 教育数据出境监管严格，必须用境内大模型 + 私有化部署 |
| **未成年人保护** | 实名 + 防沉迷 + 不能算命/不良引导，**比美国还严** |
| **"作弊工具"标签** | 学校可能抵制，需要老师版作为切入点把校内当渠道 |
| **教培行业敏感** | 双减后家长付费意愿强但合规敏感，**避开学科辅导直接描述**，包装成"AI 学习伙伴" |

### 3.5 建议 MVP 路径（如果立项）

```
Phase 0（1 个月）：苏格拉底 prompt + DeepSeek API + 小学数学（人教版）
  → 邀请 20 个北京海淀家长测试 → 看下一题正确率 + 完成率

Phase 1（3 个月）：加作文批改 + 语音对话 + 家长 Dashboard
  → 公众号 + 视频号引流，付费转化测试

Phase 2（6 个月）：接入更多教材 / 加初中数学 / 拍照拍题
  → 教培机构 B 端合作探索

Phase 3（12 个月）：若 PMF 确认，模型私有化 + 算力赞助谈判
  → 走 SaaS 路线
```
