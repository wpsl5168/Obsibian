# Cool Math Games 调研

> 一个"靠 Flash 小游戏起家、被美国学生当上课摸鱼神器、活到 HTML5 时代的奇葩教育网站"。1997 年至今 29 年，2500+ 游戏，**Popular Mechanics 评其为"互联网史上 50 个最重要网站之一"**（2019）。

## 一句话定位

**不是"教数学"，是"用逻辑/策略/解谜小游戏顺带练脑子"**。Slogan: *Where logic & thinking meets fun & games*。

## 速览

| 项 | 信息 |
|---|---|
| 创立 | 1997（已 29 年） |
| 总部 | 纽约 |
| 母公司 | Sandbox Group（2018.11 从 H.I.G. Capital 收购） |
| 游戏数 | 2,500+ |
| 中文版 | 有简体（zh-hans）、繁体、日韩等多语言 |
| 商业模式 | 免费 + Google Ads，可订阅去广告 |
| 编程教育 | 2022.09 推出 Cool Math Coding（教 Roblox + Minecraft 编程） |
| Steam 扩展 | 2024.12 《Cool Math Games: The Game》上 Steam |

## 内容矩阵

- **真数学游戏**：加减乘除、应用数学、逻辑题（占比小但是核心定位）
- **大头是"广义脑力小游戏"**：策略、塔防、放置、解谜、消除、平台跳跃、计时挑战
- **特色系列**：Papa's Pizzeria 系列（14款，模拟经营）、Run 3、Fireboy & Watergirl、Moto X3M、Tiny Fishing、Cookie Clicker
- **金融素养专题**（亮点）：Investor Tower、Tax Season、Lemonade Stand、Don't Get Duped（防骗）
- **双人合作**：24+ 款双人游戏，Fireboy and Watergirl 经典
- **创意类**：绘画、音乐、虚拟宠物

## 安全设计（亮点）

- 所有游戏内部审查后上线，**严禁暴力/血腥/酒精药品/成人/宗教政治/脏话**
- **没有任何自由聊天**——多人游戏只允许 emoji 或预审短语
- 自动生成用户名，不要求真实姓名/邮箱
- **隐私保护严格**——这点比国内绝大多数小游戏站强

## 客观短板

1. **教育性被夸大**：本质是"附带数学标签的小游戏站"，真正训练数学能力的游戏占比小，**Common Sense Media 也只说"some" educational value**
2. **广告多**：免费版 Google Ads 频繁，影响低龄使用体验
3. **质量参差**：2500 款里大量平庸甚至粗糙的小游戏，需要家长筛选
4. **中文化只是 UI 翻译**：游戏本体大多是英文，对纯中文母语低龄孩子有阅读门槛
5. **没有学习进度/掌握度系统**：不像 Khan Academy 有 mastery learning 路径，玩完就玩完

## 对老王家娃判断

⚠️ **不要把它当"数学启蒙工具"**——它的真实价值是"**逻辑解谜小游戏的安全集合**"。

✅ **可以这样用**：
1. **课间/周末娱乐替代品**：比刷抖音/玩王者强（无诱导消费、无暴力、无社交风险）
2. **英语沉浸的副产品**：游戏文字虽不复杂，但能让孩子在玩中接触英文 UI、规则文本
3. **Papa's 系列模拟经营**：训练时间管理 + 顺序逻辑，4-5 岁起可玩
4. **Fireboy & Watergirl 双人**：陪孩子玩，亲子互动 + 协作思维

❌ **不建议**：
- 当数学课替代品（不行）
- 当主要英语启蒙（深度不够）
- 给 3 岁以下（广告 + 操作门槛）

## vs Khan Academy 关系

| 维度 | Khan Academy | Cool Math Games |
|---|---|---|
| **定位** | 体系化学习 | 娱乐为主，顺带练脑 |
| **学习效果** | 有 RCT 证据 | 无严肃学术研究 |
| **学习路径** | mastery learning 图谱 | 无 |
| **适合时段** | 正经学习时间 | 课间/周末摸鱼 |
| **替代品** | 网校（学而思网校） | 4399 + 国外质量版 |

**两者不冲突，是互补**：Khan 当主线，Cool Math Games 当娱乐放松。

## 国内类似产品

- **4399**：体量大、品类全，但内容质量参差、广告/弹窗严重、安全性远不如 Cool Math Games
- **7k7k / 17173 小游戏**：同 4399 类
- **微信小游戏**：质量高但社交诱导多，付费坑多
- **国内做"教育向"小游戏站的几乎没有** — 这是个市场缺口（但盈利模型不清晰）
