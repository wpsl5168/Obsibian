# 微软 AI Agent 全景与战略点评（2026-06）

> 信息截至 2026-06。优先官方源（microsoft.com/blogs、Build 2025、Ignite 2025、Learn、GitHub）。价格为美元官方挂牌价。Star 数为匿名 GitHub API 实时值。

---

## 0. 一句话结论

微软的 Agent 战略 = **「Open Agentic Web（开放协议）+ Frontier Firm（Agent 365 治理控制面）」**。最强护城河是**治理/身份**（Entra Agent ID + Agent 365 + Purview）和 **MCP 开放协议押注**；最大短板是**生产化鸿沟、自治度保守、落地率仅 16%、产品叙事/SKU 过载、模型战略动荡（OpenAI vs 自研 MAI）**。

产品线已铺到六层：消费级 Copilot → 通用 M365 Copilot → 低代码 Copilot Studio → 开发者 GitHub Copilot → 业务垂直 Copilot（安全/CRM）→ 平台治理层 Agent 365。底层由开源 Agent Framework（SK + AutoGen 收敛）+ Azure AI Foundry 托管支撑。

---

## 1. 产品全景（六层）

### 一、消费级 + 通用 Copilot 家族

- **Microsoft 365 Copilot（企业旗舰）**：grounded 在 Microsoft Graph（邮件/会议/文档）的工作助手。内嵌 Office 全家桶 + Copilot Chat；含 **Agent Mode in Office**、**Work IQ** 智能层、内置推理 agent **Researcher & Analyst**。**$30/用户/月**（企业，年付）；Business 版 $21/用户/月（≤300 用户）。2025-10 起 Sales/Service/Finance 角色型 Copilot 免费并入 $30 套餐。**GA，成熟**。
- **Microsoft 365 Copilot Chat**：面向全员的免费 chat 入口 + 按量（PAYG Copilot Credits）调用自建 agent。2025-01-15 发布。**GA**。
- **个人版 Copilot / Copilot Pro**：消费者 AI 助手（Copilot.com / Windows / 移动）。免费层 + **Copilot Pro $20/月**（解锁 Deep Research、优先模型）。**GA**。
- **Copilot Vision**：让 Copilot「看」屏幕/摄像头实时协助。2025-06-25 移动端美国免费上线。**GA（分区域滚动）**。
- **Windows Copilot / Copilot Actions**：从对话走向**桌面级 agentic 自动化**。**Copilot Actions** 在隔离的 **Agent Workspace**（独立 agent 账户）内代替用户开 app、点击、填表、操作本地文件；Agent connectors（MCP servers）桥接 Windows app。2025-11 起对 Insiders **实验性预览，默认关闭**。**非 GA**。

### 二、Copilot Studio（low-code agent builder）

低代码/专业代码 agent 构建平台，可建独立 agent、扩展 M365 Copilot、构建 **autonomous agents**（长时运行）。Build 2025 重大更新：
- **Multi-agent orchestration** — agent 跨 M365/Azure AI/Fabric 互相委派协作。
- **Autonomous agents** — Build 2025 宣布 GA。
- **Agent flows** — 确定性工作流 + AI agent 结合。
- **Computer use in agents** — AI 操作桌面/web UI，**2026-05-13 GA**（搭载 OpenAI CUA + Claude Sonnet 4.5，Key Vault 凭据 + Purview 审计 + human-in-the-loop）。
- **A2A 协议**预览；**Copilot Tuning**（企业数据微调）。

定价：M365 已授权用户内部 agent 用量 **included**；PAYG **$0.01/Copilot Credit**；容量包 **$200/月 = 25,000 Credits**；autonomous agent 每次触发约 25 credits。**GA，核心成熟**。

### 三、开发者级：GitHub Copilot（微软最成熟的 agent 线之一）

- **Agent Mode**（含 MCP）：单 prompt 完成多文件多子任务的 vibe coding。Visual Studio 2025-06 GA。
- **Copilot coding agent**（异步自主）：分派 issue → 后台自有环境开 draft PR → 请求 review。**2025-09-25 对所有付费订阅者 GA**。
- 定价 5 档（围绕 premium requests）：Free $0（50 req）/ Pro $10（300）/ Pro+ $39（1,500，超量 $0.04/req）/ Business $19/用户 / Enterprise $39/用户（叠加 GitHub Enterprise Cloud 实际约 $60）。**GA，高度成熟**。

### 四、业务线垂直 Copilot / Agents

- **Security Copilot**：内嵌 Defender/Entra/Intune/Purview/Sentinel。**12 个微软自建 agent** + 合作伙伴 agent（如 Phishing Triage Agent、Conditional Access optimization agent）。**SCU 消费模型 $4/小时**；Ignite 2025 起并入 M365 E5（每 1,000 E5 许可送 400 SCU/月）。
- **Dynamics 365 — Sales Qualification Agent（SQA）**：自主线索资格认定，Research-only / Research-and-engage 两模式。**2025-10 GA**，用 Copilot Credits 计费。
- **Dynamics 365 — Customer Service / Contact Center**：客服自主+辅助 agent（如 Customer Knowledge Management agent 自动生成知识库）。Contact Center Digital $95/用户/月；agent 走 Copilot Credits。
- **Power Platform agents**：Power Apps agent builder、Agent Feed、Agent Flows，复用 Copilot Studio Credits 体系。

### 五、平台治理层（Ignite 2025 新增）

- **Microsoft Agent 365**：企业 agent 的 **control plane**——统一 Registry（清点含 shadow/rogue agent）、Access control、Visualization、Interoperability、Security；内部 agent catalog 供员工「雇佣」已批准 agent；agent 像 user 一样有 owner + 审计轨迹 + 策略。**早期访问，非 GA**。
- **Microsoft Entra Agent ID**：给 agent first-class 身份与访问管理，把 Zero Trust 扩到 agent。**新发布滚动中**。
- 配套：Windows 365 for Agents、Copilot in Intune、Foundry Local（本地模型）。

### 六、底层平台与框架

- **Azure AI Foundry Agent Service**（原 Azure AI Agent Service）：云上托管的企业级 Agent 平台。约 **2026-03 随 Foundry 整体 GA**。Connected Agents、可托管外部开源框架（Agent Framework / LangGraph）、Bing grounding、Logic Apps/Fabric/SharePoint 工具。按 token + 工具连接计费。
- **Microsoft Agent Framework**（`microsoft/agent-framework`，★10,954）：2025-10 公开预览的新开源统一 SDK（Python + .NET），官方定位「**不是新框架，而是 SK + AutoGen 的一次大版本升级**」。内置 Sequential/Concurrent/Magentic/Handoff 编排 + Workflow + MCP。**主推方向**。
- **Semantic Kernel**（★28,026）：生产级 LLM 编排 SDK，**未废弃，演进合并入 Agent Framework**。老项目继续用，新项目直接上 Agent Framework。
- **AutoGen**（★58,619，微软 Agent 系最高）：多智能体框架，首创 GroupChat + event-driven runtime。**已宣布合并入 Agent Framework**，仓库仍在但方向转移，提供迁移指南。
- **Magentic-One / Magentic-UI**（`microsoft/magentic-ui` ★9,882）：Microsoft Research 多智能体系统，Orchestrator 指挥 WebSurfer/FileSurfer/Coder。已作为「Magentic」编排模式内置进 AutoGen 和 Agent Framework；Magentic-UI 为实验性应用，正演进为 MagenticLite。
- **协议层**：MCP 全栈集成（Agent Framework 原生 + Foundry + NLWeb）；A2A 支持中；**NLWeb**（`nlweb-ai/NLWeb` ★6,217，非 microsoft org）把任意网站变成可对话的 MCP endpoint，官方类比「NLWeb 之于 MCP，如 HTML 之于 HTTP」。

## 3. 战略与愿景

**Satya Nadella（Build 2025）** —— **「the open agentic web」**：把互联网重构成 agent 可读、可交易、可协作的层。类比 HTTP/HTML 时代，主张用开放协议（MCP / A2A / NLWeb）避免 agent 生态碎片化。agent 跨 individual / team / org / business 四层运行。

**Charles Lamanna（CVP, Business & Industry Copilot）** —— 主打 **multi-agent orchestration**，反复强调 orchestration 是关键。2025-11 组织调整后，Suleyman 接管 frontier model，Lamanna 留在 Copilot 应用层。

**Mustafa Suleyman（CEO, Microsoft AI）** —— 2025-11 组建 MAI Superintelligence Team，「Humanist AI」路线，2026-04 发布自研 MAI 模型（Transcribe-1 / Voice-1 / Image-2），目标 2027 文本/图像/音频全 frontier。

**Build → Ignite 路线图主线**：
1. **开放协议三支柱**（Build）：MCP 第一方支持 + MCP Server Registry + NLWeb。
2. **治理 day-one**（Ignite）：Agent 365 control plane + Entra Agent ID + Foundry Control Plane（build 阶段直接 toggle Purview/Defender/Entra）。
3. **三层 IQ 智能结构**（Ignite）：Work IQ（工作图谱）+ Fabric IQ（业务语义/本体）+ Foundry IQ（托管知识/推理层，非简单 RAG）。
4. **Agent Factory / Frontier Firm** 叙事：单一计费计划度量 agent ROI。

## 4. 行业评价（批判维度）

**Gartner —— 采用率冷水**
- 「Copilot and agent strategy is moving faster than most organizations can accommodate」（战略跑得比客户消化能力快）。
- **~80% 企业在 pilot，仅 16% 进入全规模生产**。
- **#1 障碍是 security & governance**；专门发文「How to Mitigate the Risks of M365 Copilot Agent Sprawl」（数据泄露、misinformation、agent hijacking、runaway cost）。第三方治理厂商（Zenity 等）兴起，反证 native 控制不足。

**Forrester（Ignite 2025）** —— 承认 demo 印象深但口吻保留，指出未来在 custom agents + multiagent，而非现成 Copilot。

**Marc Benioff（Salesforce CEO）** —— 把 Copilot 比作 **「Clippy 2.0」**、「science project」，批客户没获得价值、缺 context/skills/adaptability。中立分析师（Valoir/Rebecca Wettemann）：部分属实（效果一般、部署客户不多），但很多 Salesforce 客户本就跑在 Azure 上，攻击有水分。

**与 OpenAI 关系（战略级变量）**
- 2025 renegotiation 解除「微软不得自研 broadly capable model」限制；OpenAI 占微软 cloud backlog 约 45%。
- 2026-04 微软发布自研 MAI 模型，被 Wedbush 的 Dan Ives 称「tightrope walk」。
- 战略含义：agent 栈从「OpenAI 独家」转向 **model-diverse**（Foundry 1,900+ 模型、Grok、Model Router），既是对冲也是与 OpenAI 的潜在竞争。

## 5. 竞争对比：四大 Agent 栈

- **定位** — 微软：横向（M365 生产力 + 开发者全栈）｜ Google：开发者优先 + Gemini 多模态 ｜ AWS：开发者基础设施 ｜ Salesforce：纵向 CRM-native
- **目标用户** — 微软：业务用户(no-code)+开发者 ｜ Google：开发者 ｜ AWS：开发者(无 no-code) ｜ Salesforce：CRM 业务线
- **自治度** — 微软：human-augmentation（人最终决策）｜ Salesforce：fully autonomous（无逐步签字）｜ Google/AWS：开发者编排
- **模型** — 微软：GPT + Foundry 1,900+ + 自研 MAI ｜ Google：Gemini ｜ AWS：Claude/Llama/Titan ｜ Salesforce：Atlas Reasoning Engine
- **数据地基** — 微软：Microsoft Graph + 600~1,200 connectors ｜ Google：BigQuery/Workspace ｜ AWS：OpenSearch/Aurora ｜ Salesforce：Data Cloud/CRM
- **多 agent** — 微软：SK+AutoGen 合并 SDK ｜ Google：ADK + A2A（开源，强）｜ AWS：有限 ｜ Salesforce：Topics & Actions
- **互操作协议** — 微软：MCP 第一方全栈 + A2A + NLWeb ｜ Google：A2A 主推 ｜ AWS/Salesforce：跟随
- **治理身份** — 微软：Entra Agent ID + Agent 365（最完整）｜ Google：较弱 ｜ AWS：Guardrails/PII ｜ Salesforce：平台内合规
- **定价** — 微软：~$0.01/msg；M365 Copilot $30/用户/月 ｜ Google/AWS：per token + infra ｜ Salesforce：$2/对话，$125~550/用户/月

## 6. 综合判断（点评）

**优势**
- **治理控制面是四家中最成体系的**：Entra Agent ID + Agent 365 + Purview，正面回答「谁来管这些 agent」。
- **开放协议押注**：MCP 几乎成事实标准，微软是主推方之一，给生态护城河。
- **横向覆盖广**：M365 触达 90% Fortune 500，分发渠道无对手。
- **开发者线最成熟**：GitHub Copilot coding agent 是已落地、已 GA、已收费的真实 agent 产品，不是 demo。

**短板（核心批评）**
1. **生产化鸿沟** — Copilot Studio 做 FAQ bot 一下午，做真实业务流要几个月定制工程；Studio 与 Foundry 间存在能力断层。
2. **自治度保守** — 相比 Agentforce 的端到端 autonomous execution，Copilot 仍是 augmentation，在客户面/高 ROI 自动化场景吃亏。
3. **落地率低** — Gartner 16% 生产化、governance 头号障碍，印证 Benioff「science project」批评有现实根据。
4. **叙事过载** — Work IQ / Fabric IQ / Foundry IQ / Agent 365 / Agent Factory / Frontier Firm 一堆新品牌，SKU 与计费复杂，客户消化困难。
5. **模型战略动荡** — OpenAI 依赖 + 自研 MAI 并行，产品层模型策略仍在重整，长期一致性存疑。

**数据引力定律**：平台选择本质由「数据在哪」决定——Microsoft-first 选 Copilot，Salesforce-first 选 Agentforce。搬数据到非原生平台是架构级负债，这削弱任一厂商「通吃」的叙事。

---

## 7. 未来规划要点

- **Open Agentic Web 落地**：MCP Server Registry + NLWeb 推动「网站即 agent 端点」，把 agentic web 做成基础设施层。
- **Agent 365 从早期访问走向 GA**：企业 agent 治理控制面是下一阶段商业化重心。
- **三层 IQ 深化**：Work/Fabric/Foundry IQ 构成「知识与推理地基」，从 RAG 升级到托管推理层。
- **自治度提升**：computer-use agents（2026-05 GA）+ Copilot Actions 桌面自动化，逐步逼近端到端自治。
- **Model-diverse**：自研 MAI + Foundry 多模型路由，降低对 OpenAI 单一依赖。
