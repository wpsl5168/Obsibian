# 主流绘画风 / 涂鸦风设计 token 调研

> 目标：把 Gemini / NotebookLM 等主流 AI 绘图风格拆成**可复现的设计 token**（配色/笔触/形状/字体），直接喂给 `wp-tech-diagram` 的 SVG 流水线，而非新闻转述。

## 一句话结论
- **NotebookLM ＝ 风格的"事实标准"**：视觉风格全由 **Nano Banana（Gemini 2.5 Flash Image）** 驱动，分两条产品线——Video Overview 的 **6 风格**、Infographic 的 **10 风格**。这 16 个名字就是 2026 当前最主流的"风格菜单"，照抄即可对齐用户预期。
- **涂鸦风不是一个风格，是三层光谱**：①白板手绘（Whiteboard / Sketch Note，最克制）→ ②xkcd/Excalidraw 抖动线（程序可生成，本 VM 能做）→ ③Doodle 自由涂鸦（最放飞）。技术图表用 ①②，娱乐内容用 ③。
- **本 VM 能 100% 复现的**：Whiteboard、Sketch Note、xkcd 抖动、Corporate Memphis、Bento Grid、Blueprint。**做不了的**：Watercolor / Clay / Anime / Heritage（需扩散模型，得走 Gemini API 出图，非 SVG）。

## 二、可复现设计 token（直接喂 SVG）

### 1. Whiteboard 白板风 ★技术图首选
```
背景    #ffffff 或 #f7f7f5（极浅暖灰）
主线    #1a1a1a 黑马克笔，stroke-width 2.5~3，线帽 round
强调    荧光块：#fff176(黄) #80d8ff(蓝) #b9f6ca(绿) #ff8a80(红)，opacity .35 当高亮
字体    手写感优先；无字体时用 sans + 轻微 feTurbulence 抖动
笔触    feTurbulence(baseFrequency .02) + feDisplacementMap(scale 2~3) → 线条微抖
箭头    手绘折线箭头，非规整 marker
留白    元素间距大，像板书一块一块
```

### 2. Sketch Note 手绘笔记风 ★涂鸦主力
```
背景    #fdfcf7 米黄纸 / 可加 5% 点阵网格
线条    #2b2b2b，粗细不均（2~3.5 抖动），feDisplacementMap scale 3.5~4
配色    主黑线 + 2~3 个高饱和点缀（橙 #ff7043 / 蓝 #29b6f6 / 黄 #ffca28）
高亮    马克笔色块（同上 opacity .3），手写下划线（波浪/双线）
图标    简笔涂鸦：灯泡/箭头/星/对勾/感叹号，全部线稿
标题    手写体或加粗 + 手绘下划线 / 圈选
布局    自由但有视觉动线，箭头串联，非网格
```
→ 已落地为 `wp-tech-diagram/references/style-8-handdrawn.md`

### 3. xkcd 程序抖动风（matplotlib `plt.xkcd()` 同源）
```
原理    线条点位加随机扰动 + Humor Sans 字体
SVG 等价 feTurbulence type=fractalNoise baseFrequency .015~.025
        + feDisplacementMap scale 2~4（数值越大越抖）
适用    数据图表、流程图的"轻松化"，不适合严肃汇报
注意    文字不要套 displacement 滤镜（会糊），只抖线条/形状
```

### 4. Corporate Memphis / Alegria（大厂扁平人物）
来源：Wikipedia + controlaltachieve。2017 Facebook 委托 Buck Studios 做的 Alegria 系统，成大厂标配。
```
人物    扁平、四肢细长可弯、躯干小、五官极简或无脸
肤色    非写实（蓝/紫）求"普世感"，或写实肤色求多样性
形状    大色块几何、无渐变、无描边或极细描边
配色    2~4 主色高饱和 + 中性背景，色块不叠加混色
适用    Landing page 插画、信息图配角，技术图谱较少用
评价    被批"千篇一律/虚假乐观"，慎用于追求差异化的场合
本地    SVG 可做（纯路径+色块），但人物造型需手工或模板
```

### 5. Bento Grid 便当网格（Apple 同款）
```
卡片    圆角 16~24px，不等大小拼贴铺满
背景    深色 #0a0a0a 或浅 #f5f5f7
卡内    单一焦点：一个数字/一个图标/一句话
间距    统一 gap 12~16px，对齐严格
强调    个别卡用品牌色/渐变/大字突出
适用    产品特性罗列、数据看板、能力总览
本地    ✅ SVG/HTML 网格直出，最易复现
```

### 6. Gemini（Nano Banana）图像风格 4 档
来源：simplifyaitools。**这些是出图风格，需走 Gemini API，非 SVG**：
- `Cinematic Ultrareal`：暖高光+深阴影+浅景深，电影感
- `Pastel Dreamcore`：粉彩雾化+柔光晕，缩略图/角色
- `Analog Film 35mm`：胶片颗粒+漏光+哑光，怀旧
- `Soft Pastel Illustration`：水彩柔影+圆形+绘本感，教育/友好
> 用法：当用户要"配图/插画"而非"图表"时，把这些 tag 拼进 Gemini 出图 prompt。

## 三、决策树：什么场景用什么风格

```
要图表（架构/流程/ER/时序）
├─ 严肃汇报/学术    → Scientific / Minimalist / Professional（规整风, Style 1）
├─ 轻松/教学/笔记   → Sketch Note / Whiteboard（涂鸦风, Style 8）★
├─ 产品能力罗列     → Bento Grid
└─ 工程蓝图感       → Blueprint（深蓝底白线）

要插画/配图（人物/场景/封面）
├─ 大厂扁平         → Corporate Memphis（SVG 模板）
├─ 真实出图         → Gemini API + 4 档 tag（非 SVG）
└─ 视频解说         → NotebookLM Video Overview 6 风格（产品内生成）
```

## 四、对 wp-tech-diagram 的落地建议
