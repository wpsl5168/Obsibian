# 07 移植到个人咨询(占位)

> ⏳ 待 workshop。本文件留作占位,等老王和大秘一起对话产出"老王 FDE Bootcamp"产品定义。

---

## Workshop 议程(待执行)

### 1. 目标客户画像
- 中型民营企业 vs SMB vs 个体?
- 行业聚焦?(金融/制造/零售/医疗/教育?)
- 决策人画像(老板亲自?CIO?业务 VP?)

### 2. 价值主张
- 解决什么具体问题?(不是"用 AI 提效",要具体到 use case)
- 5-10 个候选 use case 是哪些?
- 哪些可以做成 Hermes 标准 skill,哪些必须每次定制?

### 3. 交付模式
- 1 天调研 + 3 天 Bootcamp + 1 天交付?
- 还是 1 周调研 + 2 周交付 + 1 个月陪跑?
- 远程为主 vs 驻场为主?

### 4. 定价
- Bootcamp 单价 ¥5万 / ¥10万 / ¥20万?
- 后续月度运维 ¥3千 / ¥1万 / ¥3万?
- 怎么设计 outcome 奖金条款让客户能接受?

### 5. 获客
- 朋友圈/案例 / 微信群 / 极客公园活动 / 公众号?
- 第一批 3-5 个种子客户哪里来?
- 是否需要做"老王 FDE Bootcamp" 品牌(公众号 + 案例库)?

### 6. Ontology 等价物
- Hermes 的哪些资产可以跨客户复用?
  - 通用 skill 库(知识库、对外触达、内部审批、客户服务、数据分析)
  - cron 任务模板
  - memory schema
  - prompt 库
- 怎么从每个项目里抽 30% 回流?
- 1-2 年后这层资产怎么变现?(培训?许可?平台?)

### 7. 自我替代路径
- 老王一个人能跑多少客户?(估算 5-10 个)
- 第几个客户开始招"小老王"?
- 怎么把 SOP 沉淀到能让 junior 跑?

### 8. 风险与退出
- 如果一年内没起色,什么信号停止?
- 失败后能否退回到独立咨询/接单?
- 成功后能否做成小型咨询公司(5-15 人)?

## 已知输入

参考 [[06-阴暗面与批评#6. 给老王的诚实判断]]:

1. **你不是 Palantir,没有 5 年烧钱耐心** — 每个项目必须前期就有正毛利
2. **国内 outcome 付费几乎不存在** — 必须设计混合定价
3. **客户依赖陷阱对你是机会也是负担** — 需要培养"小老王"
4. **你的 Ontology 复利还没建起来** — 头 1-2 年必须刻意 30% 时间投入资产沉淀
