# 主题地图（Topic Map，可扩展）

> 目标：不把知识库锁死在“固定 10 个 topic”。我们保留一套**核心骨架**，其余按需扩展。

## 核心骨架（必须掌握，适合快速落地）
1) Workflow/Orchestration：图编排、状态、重试、checkpoint、预算
2) Tools & Integration：工具接入、权限、数据源（含 MCP）
3) Observability & Evals：tracing、回归评测、质量门禁
4) Security & Governance：prompt injection、防滥用、审计、HITL
5) Coding Agents：Claude Code / PR 闭环 / repo 操作

## 扩展主题（按你的项目需要再开坑）
- Data Agents：SQL Server / BI / 指标口径 / 报表自动化
- Knowledge Base：RAG、引用溯源、文档治理
- Enterprise Architecture：多租户、权限体系、合规、发布流程
- Performance/Cost：缓存、路由、模型选择、预算策略
- Agent UX：交互形态、反馈闭环、可控性

## 开 topic 的规则（保持“浅显易懂 + 可落地”）
每个新 topic 页固定 6 段：
- 一句话结论
- 解决什么问题（落地场景）
- 最小可行实现（MVP）
- 常见坑（企业/银行视角）
- 时间线（技术/人物/企业/背景）
- 一手来源（官方 + 顶流原创）

## 与原“10 大主题”的关系
- 10 大主题仍然保留为“第一版骨架”，但不再当作上限。
- 后续新增主题会更新这里（Topic Map）并在 Index 里露出入口。
