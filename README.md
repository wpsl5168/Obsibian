# Obsidian（知识库系统目录）

> 目标：把 AI Agent 相关的碎片信息，沉淀成“可导航、可复用、可演进”的话题页 + 时间线。

## 入口（先从这里开始）
- [[AI-Agent-Index]]：AI Agent 总索引（入口页）
- [[10-Topics/AI-Agent/主题地图]]：Topic Map（决定开什么坑、怎么开）
- [[20-Claude-Code/00-Overview]]：Claude Code 落地概览

## 目录结构（约定）
- `00-Inbox/`：临时碎片（尽快归档/搬运到 Topic/Daily）
- `AI-Agent-Daily/`：每日简报（官方更新 + 顶流原创 + 我的解读）
- `10-Topics/`：话题页（每个 topic 固定：一句话结论 / 场景 / MVP / 坑 / 时间线 / 一手来源）
- `20-Claude-Code/`：Claude Code 专区（更偏实操与最佳实践抽取）
- `90-Templates/`：写作风格/模板
- `99-Governance/`：治理、规则、记忆副本（可恢复性优先）

## 写作风格
- [[90-Templates/Writing-Style]]（中文优先；少堆链接，回答“是什么/为什么重要/怎么用”）
- [[90-Templates/Diagram-Style]]（配图/架构图强约束：严谨对齐正文、禁止发散、NotebookLM 极简白板风）
