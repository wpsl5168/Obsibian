# 老王的知识库

从 [[index|知识库首页]] 开始，按问题找资料，不必记住目录编号。

## 放在哪里

- [[00-收件箱/README|00-收件箱]]：待归类素材。
- [[05-个人/README|05-个人]]：家庭、旅行与个人执行。
- [[10-知识库/README|10-知识库]]：原理、教程与复用手册。
- [[20-项目/README|20-项目]]：有对象与交付的项目资料。
- [[40-调研报告/README|40-调研报告]]：证据、对比与决策研究。
- [[50-日报与动态/README|50-日报与动态]]：新闻、课程更新与巡检流水。
- [[90-治理/README|90-治理]]：规范、审计与迁移记录。

## 使用与维护

- 一份正文一个归属，多主题通过索引交叉引用，不复制文章。
- 家庭执行、客户交付、研究证据、每日流水分开；旧版本保留而不冒充当前事实。
- 系列章节保留编号；小项目保持紧凑，不为整齐建空目录。
- 新稿先读 [[90-治理/目录路由与写入规范]]，再更新最近的专题README；首页不追加全部日报。
- 移动文件必须检查WikiLink、锚点、附件和写入任务；删除/批量拆章/Git推送另获授权。
- 规则见 [[SCHEMA]]；本轮记录见 [[90-治理/迁移记录/2026-09-09-目录重组/README]]。
