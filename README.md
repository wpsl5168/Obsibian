# 老王的知识库 (Obsidian Vault)

本知识库采用结构化与双向链接体系，旨在沉淀成完整的知识图谱，而非碎片化信息。

## 目录索引结构

### 1. 新闻速递 (`01-新闻速递/`)
- **定位**：AI及AI Agent相关行业重大新闻、RSS推荐、重要事件及里程碑。
- **形式**：每日简报形式整理，沉淀为历史档案。

### 2. AI知识星球 (`02-AI知识星球/`)
- **定位**：体系化AI知识图谱（非碎片知识）。
- **内容**：从AI整体架构入手，细化到各个产品的AI Agent、各个模块。
- **维度**：架构 -> 具体模块功能 -> 处理方式 -> 技术路径 -> 产品对比 -> 优劣对比。

### 3. 日常灵感 (`03-日常灵感/`)
- **定位**：伴随每日聊天的技术与想法汇总沉淀。
- **案例**：SQL Server 加密处理、数据库性能优化等。

### 4. 项目开发 (`04-项目开发/`)
- **定位**：实战项目管理与 Vibe Coding 试水。
- **结构**：每个项目独立建目录。
- **包含**：项目需求规划、可行性分析、技术方案、验收标准、项目总结等。

### 5. 日常笔记 (`05-日常笔记/`)
- **定位**：记录个人心得与日常随笔。
